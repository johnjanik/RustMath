### 2.1 n1 in detail

Code. `tried()` returns `tried: v2 #Jac(F_p^k) and v2 #Jac'(F_p^k) for every k | N_max`,
then `; skipped, only v2 >= 128 seen: ...` when `skipped_bounds` is not empty. The claim is
true of `analyse` (`two_torsion.rs:609-625`): it takes every divisor `k` of `N_max`, and for
both twists it pushes either a bound or a skipped pair. The JSON rows confirm it: 8 bounds at
`N_max = 14` (4 divisors, 2 twists), 12 at `N_max = 12`. `order_text` is used only by
`format_row` (`m23.rs:628`), so the JSON does not change. The Decided texts and `reason()` are
unchanged. With an analysis error the column still shows `error: ...` (the `None` arm of the
`tried()` match is unreachable, since `order_text` returns early on an error; harmless).

The test. `c5_order_text_says_what_was_tried` pins the Decided texts at X 11 and 17, the new
text at X 7 (`k | 14`) and X 107 (`k | 8`), the non-Weil text, and the skipped case. `N_max`
at X 7 and X 107 equals `jac2_v2_pari.txt` (`X 7 0 N=14`, `X 107 0 N=8`). The old text
`Unresolved: 7 or 14` is in review 2's runs (`review2/run_x_5_73.txt`, 7 rows; and
`Unresolved: 6 or 12`, 3 rows), so the test fails on the old code.

The skipped case, `P = T^2 - 2T + q`, `q = 21 * 2^128 + 1`:

- `gp -q skipped_ec.gp` (PARI/GP 2.15.4) rerun: output byte-identical to
  `skipped_ec_pari.txt` (sha256 `f3ec0faf...`, equal to the README). The script's sha256 is
  `052479414c...` as in the report. `isprime` proves `q` prime, and the loop finds the least
  `k`. Over a prime field every `|a| <= 2 sqrt(q)` is a trace (Deuring, Waterhouse), and
  `a = 2` is prime to `q`, so `P` is the Frobenius polynomial of an ordinary curve.
- By hand: on `Z[x]/(P)`, multiplication by `x - 1` has the matrix `[[-1, -q], [1, 1]]`
  (Smith form `1, q - 1`: valuations 0 and 128, so the bound is skipped), and by `x^2 - 1` the
  matrix `[[-(q+1), -2q], [2, 3 - q]]` (all entries of valuation 1, determinant
  `(q - 1)(q + 3)`: valuations 1 and 129, skipped). The twisted values are
  `v_2(q + 3) = 2` and `v_2((q - 1)^2 + 4) = 2`. `P mod 2 = (x + 1)^2`, `N_max = 2`. Both types
  `[2]` and `[1, 1]` satisfy S2 and have `dim ker(F^k - 1) <= 2` at `k = 1, 2`, so the orders are
  `{1, 2}`. This equals the test (`skipped_bounds = [(1, false), (2, false)]`, bounds
  `(1, true, 2)`, `(2, true, 2)`, `order_candidates: [1, 2]`). `Unresolved` is the honest answer:
  the discriminant `-4(q - 1)` has a large 2-part, so curves with this `P` can have different
  `E(F_q)[2]`.
