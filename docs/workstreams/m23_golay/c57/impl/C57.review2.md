## 5. Minor items (none blocks)

**n1. The text of an Unresolved order does not say what was tried.** REQUESTS Section 4 asks
for "`Unresolved` with what was tried". The column reads `Unresolved: 7 or 14`; the old text
named the bound (`multiple of 7, divides 14`). The JSON has the full list (`bounds`,
`skipped_bounds`), so nothing is lost for the owner's scripts. Suggested: append the bounds
used, for instance `Unresolved: 7 or 14 (rank bounds at every k | 14, both twists)`.

**n2. Stale line references for the Docs phase.** Report Section 10.1 gives the new tracker
row as `two_torsion.rs:396,606`; the final code has `analyse` at `:537` and `lagrangian_types`
at `:747`. FR1.5 updates only `base_change` (`:394`) and `two_torsion_frobenius_order`
(`:455`); the others in 10.1 and Section 1.1 also moved: `jacobian_order` `:404` (report
`:399`), `twisted_jacobian_order` `:410` (`:405`), `two_torsion_analysis` `:430` (`:425`),
`mod2_bound` `:468` (`:461`), `ORDER_OVERFLOW` `:534` (`:527`), `lcm` `:536` (`:529`),
`order_of_x_mod2` `:542` (`:535`). The Docs phase must take every `file:line` from the final
code.

**n3. Carry-over of m4.** The header of `two_torsion.rs` points to
`docs/workstreams/m23_golay/c57/design/C57.md`. The Docs phase of the same PR must create that
file (the design and its review), or the path in the header is dangling at merge.

**n4. Wording of the module header.** Line 3 says each result is "decided only when every type
allowed by `P` agrees". The code applies S1, S2 and the rank bounds only, not every constraint
that `P` imposes (the `Z_2[F]`-lattice condition of design 2.8 is a follow-up). The doc of
`TwoTorsionOrder::DeterminedByTwoRank` is precise ("every module type allowed by the rank
bounds and the Weil pairing"); the header could say the same.

Observation, not an item: `lagrangian_types` does one LR lookup per (W type, candidate) pair,
so its cost is not bounded by `MAX_LR_SIZE` alone at large genus. The rank bounds prune the
candidates hard in practice (genus 40 in 0.3 s in my probe), and the M23 layer is genus 4.
