## 1. The criterion against its proof

Lemma 9.1 (`\label{lem:reduction}`, read in `f9/lemma_9_1.tex`) needs: `F` primitive of
bidegree `(a, b)`; `F mod p` of bidegree `(a, b)`; `F mod p` absolutely irreducible; the delta
invariants over `F_p-bar` adding up to `(a - 1)(b - 1) - g`.

The proof in design 2.2 to 2.4 is correct. I checked each step.

- Step 1 (`check_line_components`, `irreducible.rs:234`). `gcd_i c_i(Y) = 1` with some `c_i` of
  degree `b`, and the same for the `r_j(X)`. This excludes every factor in one variable,
  including `X0` and `Y0`, so "keeps its bidegree" is exactly covered. A failure exhibits a
  factor, so a refusal (`FibreComponent`) is right.
- Step 2 (`fibre_irreducible`, `search_fibre`). A factorization over `F_(p^d)` restricts to the
  fibre over a point of degree `d`. The full-degree test is `rdeg == n`, and irreducibility is
  "squarefree and one DDF block of degree n" (`factor_degrees`, `residue.rs:494`). That function
  returns `None` when `gcd(f, f') != 1`, which also covers `f' = 0` (a p-th power), so an
  inseparable fibre is never taken as irreducible. The fibre over infinity uses the reversed
  columns; rows are rectangular, so this is the top coefficient in the base variable.
- Step 3, Claim B (`coprime_part`, `Bidegree { gcd }`). Over `F_(p^d)` the `m` conjugates fall
  into `gcd(m, d)` orbits; `m | gcd(a, b)` and `gcd(m, d) = 1` give `m = 1` exactly when every
  prime of `gcd(a, b)` divides `d`. `settles = coprime_part(n, d) == 1` is this test. At `d = 1`
  it is `n == 1`.
- Step 3, Claim C (`smooth_rational_point`). The pass covers the four charts of
  `P^1 x P^1 (F_p)`. It is used only after a fibre has shown `F_p`-irreducibility, as the claim
  needs.
- The search (`irreducibility_search`, `irreducible.rs:431`) follows design 2.7. When no fibre
  has been found yet, no degree is skipped, so `NoIrreducibleFibre` really means that every
  degree `1..=4` was searched (up to 64 points per ruling and degree, as the label says).
- `certify` (`certify.rs:231`) runs, in order: the bidegree, `singular_locus`, `genus <= p_a`,
  step 1, the delta tally, then steps 2 and 3. The only `ReductionStatus::Decided(..)` in the
  crate is built at `certify.rs:307`, after all of them. `Certificate` variants are
  `#[non_exhaustive]`, so no other crate can build one. No other workspace crate uses the
  changed API (`grep`).
- Primitivity. Locally at p it means `F mod p != 0` (`FormModP::new`, `ZeroForm`). Over Z,
  `reduce_primitive` checks it, and `x_row` uses it. For `calf_mod` the doc cites HJLPPZ's header
  of `polynomial_calF.m`; I read that header (first line only, not copied): it says the
  coefficients generate the unit ideal of `O_L`. The genus is a trusted input, recorded in the
  certificate.

"Reached the search" counts the calls where the delta tally matched and only the irreducibility
check stood between the input and a Decided status. The `m = 3` norms never reach it, as the
genus count predicts (`g = m(a'-1)(b'-1) - m + 1 < 0` for `a' = 1`), but
`absolute_irreducibility` was called on each and never said `Absolute`; this exercises the
`d = 3` branch of Claim B. As a sanity check on completeness, 197 of 200 random forms were shown
absolutely irreducible.

The named curves were built for this review with PARI/GP 2.15.4 (`f9/rev1/gp/`):

- **A1, A2** (`adv_corners.gp`, `.out.txt`): `F = E E^sigma` over `F_13`, `E` over
  `F_169 = F_13(w)`, `w^2 = 2`, with the four corner coefficients zero. So `E` and `E^sigma` both
  pass through `(0,0)`, `(0,inf)`, `(inf,0)`, `(inf,inf)`. PARI: `F` irreducible over `F_13`, two
  (2,2) factors over `F_169`, `E` smooth, `#V(F)(F_13) = 4`, none smooth. This is the case
  that probes Claim C in the charts at infinity: a wrong gradient in a reversed chart would
  report a smooth corner and give a wrong `Decided`. The code says
  `NoSmoothRationalPoint { x-fibre over y = 1, gcd 4 }`, in all eight chart transforms.
- **B** (`adv_43.gp`, `.out.txt`): `F = G H` over `F_13`, `G` smooth of bidegree (2,1), `H`
  smooth of bidegree (2,2), `Res_x(G, H)` squarefree of degree 6. `F` has bidegree (4,3), so
  `gcd = 1`; genus input 0 makes the delta-sum 6 = `p_a - g`. This checks that the gcd-1
  shortcut never skips the fibre test. The code says `NoIrreducibleFibre`.
