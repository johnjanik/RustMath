**Foundation notes:** Existing PrimeField/ExtensionField implement Ring/CommutativeRing/Field from rustmath-core but not the rest of the tower (Magma..Group, EuclideanDomain, Module/VectorSpace) and do not use parent.rs Parent/Element or unique_representation. No unsafe required; large finite fields need only BigInt (rustmath-integers), not arbitrary-precision reals.
