## Scope and overview

Chapter 117 describes methods for generating graded rings that correspond to polarised algebraic
varieties of various types. The chapter covers subcanonical curves (curves polarised by a divisor
dividing their canonical class), K3 surfaces, Fano 3-folds, and Calabi–Yau 3-folds. Of these, K3
surfaces are the most fully developed, with a database of 24,099 surfaces shipped with Magma.

The central idea is that a polarised variety X, A is essentially equivalent to its total graded ring
R(X, A) = ⊕_{n≥0} H^0(X, O_X(nA)), which is generated by finitely many sections, and the Hilbert
series P_R(t) = Σ (dim R_n) t^n of this ring encodes all the numerical data of the family to which
X belongs. The Hilbert series is computed via a Riemann–Roch (RR) formula appropriate to the
class of variety (e.g. Altinok's RR for K3 surfaces, Suzuki's RR for Fano 3-folds, Buckley's RR
for Calabi–Yau 3-folds). The output is a family invariant: a single set of invariants specifies a
whole family of varieties, not one particular member.

**Key limitation (most important).** There is in general no criterion to determine whether a
particular set of RR inputs actually corresponds to some existing polarised variety. The output
should be understood as a candidate graded ring, and existence must be verified separately (e.g.
by exhibiting a quasi-smooth member in the predicted weighted projective space).

Four further points govern interpretation: (1) all ambient spaces are weighted projective spaces
(wps); (2) no base field is assigned (k = C is a useful mental model); (3) the total graded ring of
A — not the hyperplane-section embedding — is the object stored; (4) only weak numerical data
(the Hilbert series) is recorded, not explicit equations.

## 117.2 Hilbert Series and Graded Rings

The Hilbert polynomial p(t) of a graded k-algebra R = ⊕R_n satisfies dim R_n = p(n) for all
sufficiently large n. The Hilbert series P(R) = Σ_{n≥0} (dim R_n) t^n is a rational function.
When the RR data includes quotient singularities or fractional divisors, the grading may be
periodic: the n-th coefficient is given by p_i(n) where i = n mod r, so one stores a sequence of
Hilbert polynomials p_0, …, p_{r-1}. Standard references: Matsumura **[Mat89]** §13;
Zariski–Samuel; Eisenbud.

### 117.2.1 Hilbert Series and Hilbert Polynomials

To determine the Hilbert series P one must supply the Hilbert polynomial p (or a sequence of
polynomials Q covering each residue class) together with a finite list V of initial coefficients
that lie outside the range where p is valid.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `HilbertFunction(p,V)` | The Hilbert function (a function Z → Z) determined by a univariate polynomial `p` (the Hilbert polynomial) and a sequence of initial values `V`. | Piecewise: use `V[n+1]` for small `n`; evaluate `p` for large `n`. |
| `HilbertFunction(Q,V)` | As above, but `Q` is a sequence of univariate polynomials; the n-th value is given by `Q[n mod r + 1]` for large `n`. | Periodic Hilbert polynomial evaluation. |
| `HilbertSeries(p,V)` | The Hilbert series (a rational function in one variable) determined by a univariate polynomial `p` and initial values `V`. | Closed-form rational reconstruction from polynomial + initial segment. |
| `HilbertSeries(Q,V)` | As above with a sequence `Q` of Hilbert polynomials for a periodic grading. | Periodic rational reconstruction. |

*Worked examples: H117E1 (genus-4 hyperelliptic curve: computing `HilbertFunction`, `HilbertSeries`, `HilbertSeriesMultipliedByMinimalDenominator`, and `HilbertNumerator` to identify C_{10} ⊂ P(1,1,5) and B_{6,6} ⊂ P(1,2,3,3)).*

### 117.2.2 Interpreting the Hilbert Numerator

The Hilbert series of X ⊂ P(w_0,…,w_N) defined by equations of degrees d_1,…,d_r takes the
form P(t) = (1 − t^{d_1} − … ± t^k) / ((1−t^{w_0})⋯(1−t^{w_N})). The numerator of this expression
with respect to weights w_0,…,w_N is the **Hilbert numerator**. Low-degree negative terms of the
numerator encode equation degrees; the next band encodes syzygy degrees, and so on. See
**[Rei00]** §3 and **[ABR02]** §4.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `HilbertSeriesMultipliedByMinimalDenominator(p,V)` | Given a Hilbert polynomial `p` and initial values `V`, returns the numerator polynomial `g` and the sequence of factors `1−t^d` of the minimal-denominator expression `g(t)/Π(1−t^d)` for the Hilbert series. | Rational function reconstruction; denominator minimised by cancellation. |
| `HilbertSeriesMultipliedByMinimalDenominator(Q,V)` | As above for a periodic sequence `Q` of Hilbert polynomials. | As above. |
| `HilbertNumerator(g, D)` | Computes the product `g × Π_{d∈D}(1−t^d)`, assuming the result is a polynomial. Typically `g` is a Hilbert series and `D` is a proposed weight set. | Direct polynomial multiplication. |
| `FindFirstGenerators(g)` | Returns a sequence of generator weights obtained by a greedy scan of the coefficients of `g`: advance degree by degree, adding one generator for each unit of positive coefficient; stop at the first negative coefficient. Returns a subset of weights that must occur for any realising variety. | Greedy generator-degree extraction; not guaranteed complete. |
| `ApparentCodimension(f)` | For a polynomial `f` in the alternating-sign form 1 − (negative terms) + (positive terms) − …, the apparent codimension is the number of sign-change levels. | Read off from the sign pattern of `f`. |
| `ApparentEquationDegrees(f)` | The degrees `i` for which the first-negative-band coefficient of `f` is nonzero (with multiplicity equal to the coefficient); these predict the equation degrees of the variety. | Read off from `f`. |
| `ApparentSyzygyDegrees(f)` | The degrees `i` for which the second-positive-band coefficient of `f` is nonzero (with multiplicity); these predict the syzygy degrees. | Read off from `f`. |

*Worked examples: H117E1 (as above); H117E2 (`FindFirstGenerators` on the genus-4 series, recovering weights [1,1,5]).*

## 117.3 Baskets of Singularities

Singularities enter the Riemann–Roch formula as a **basket**: a collection of point or curve
singularities whose RR contributions are summed. The basket need not match the actual
singularities of the variety exactly — it represents the ideal singularity contributions. Only
cyclic quotient singularities (point type 1/r(a_1,…,a_k)) and 3-fold curve singularities (following
Buckley **[Buc03]**) are supported. RR for dimensions above 3 is not yet implemented.

### 117.3.1 Point Singularities

A point singularity is a finite cyclic quotient singularity. In dimension 2, the symbol 1/r(a,b)
denotes the singularity C^2/G where G acts by (x,y) ↦ (λ^a x, λ^b y) for a primitive r-th root
of unity λ. Similarly 1/r(a,b,c) in dimension 3, and 1/r(a_1,…,a_k) in general. The **index** of
p is r; the **polarisation** is [a_1,…,a_k]. When the local polarisation (eigenspace) n of the
polarising divisor A matters, the singularity is written 1/r(a_1,…,a_k)_n; the default is n = −1.

Four key types appear in practice:
- Gorenstein surface: 1/r(a, r−a), r coprime to a (K3 surfaces, Du Val).
- Terminal 3-fold: 1/r(a, b, r−b), r coprime to a and b (Fano 3-folds).
- Isolated canonical 3-fold: 1/r(a,b,c), a+b+c ≡ 0 mod r, r coprime to each of a,b,c (Calabi–Yau).
- Non-isolated canonical 3-fold: 1/r(a,b,c), a+b+c ≡ 0 mod r, no three of r,a,b,c share a factor.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Point(r,n,Q)` | The point singularity 1/r(Q[1],…,Q[k])_n with index `r`, polarisation sequence `Q`, and local polarisation `n`. No quasi-reflections allowed (no integer k>1 may divide r and all but one element of Q). `n mod r` must be a unit mod r. | Constructor; validates no quasi-reflection condition. |
| `Point(r,Q)` | As above with default eigenspace n = −1. | As above. |
| `Dimension(p)` | Dimension of the variety on which the singularity `p` lies (= length of polarisation sequence). | — |
| `Index(p)` | The index r of the point singularity `p`. | — |
| `Polarisation(p)` | The polarisation sequence [a_1,…,a_k] of `p`. | — |
| `Eigenspace(p)` | The eigenspace (local polarisation) n of `p`. | — |
| `p eq q` | True iff `p` and `q` have equal dimension, index, polarisation, and eigenspace. | — |
| `IsIsolated(p)` | True iff `p` is an isolated singularity, i.e. every element of its polarisation is coprime to its index. | GCD test on each polarisation element. |
| `IsGorensteinSurface(p)` | True iff `p` is of the form 1/r(a, r−a) with gcd(r,a) = 1. | Structural check. |
| `IsTerminalThreefold(p)` | True iff `p` is isolated, dimension 3, and the polarisation is (up to permutation) of the form (a, b, r−b). | Permutation search on polarisation. |
| `TerminalIndex(p)` | The integer `a` when the polarisation is a, b, r−b (up to permutation); requires `p` to be a terminal 3-fold point. | — |
| `TerminalPolarisation(p)` | Polarisation reordered as (a, b, r−b) with b ≤ r/2; error if `p` is not a terminal 3-fold point. | — |
| `IsCanonical(p)` | True iff the sum of the polarisation is ≡ 0 mod the index. | Modular arithmetic check. |

*Worked examples: H117E3 (creating `Point(7,[3,4])` and `Point(5,2,[1,2,3])`; checking `IsGorensteinSurface`, `IsTerminalThreefold`, `Eigenspace`).*

### 117.3.2 Curve Singularities

Curve singularities (following Buckley **[Buc03]**) are always 3-dimensional: a one-dimensional
singular locus C ⊂ X of a polarised 3-fold. The **degree** of C is the intersection number AC.
At a general point of C the transverse section is a Gorenstein surface singularity 1/r(a,r−a)
(the **transverse type**; r is the **transverse index**). Two further invariants N (normal bundle
splitting type) and t (index; GCD of the t_i where special points have indices rt_i) appear in
RR only through their ratio N/t, the **magic number**.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Curve(d,p,m)` | The 3-fold curve singularity of degree `d`, transverse type (surface point) `p`, and magic number `m = N/t` (sets `t = 1`). | Constructor. |
| `Curve(d,p,N)` | As above with normal number `N` specified (so magic number = N, t = 1). | Constructor. |
| `Curve(d,p,N,t)` | As above with normal number `N` and index `t` specified. | Constructor. |
| `Degree(C)` | The degree of the curve singularity `C`. | — |
| `TransverseType(C)` | The transverse type of `C`: a surface point singularity 1/r(a,r−a). | — |
| `TransverseIndex(C)` | The transverse index r of `C`. | — |
| `NormalNumber(C)` | The invariant N of `C`. | — |
| `Index(C)` | The invariant t (= τ) of `C`. | — |
| `MagicNumber(C)` | The magic number N/t of `C`. | — |
| `Dimension(C)` | The dimension of `C` (currently always 3). | — |
| `IsCanonical(C)` | True iff the transverse type of `C` is a canonical (Du Val) surface singularity. | Delegates to `IsGorensteinSurface` of transverse type. |
| `C eq D` | True iff `C` and `D` have equal dimension, degree, transverse type, and magic number (equivalently N and t). | — |

*Worked examples: H117E4 (`Curve(1/3, Point(3,[1,2]), 4, 3)`, checking `TransverseIndex`, `IsCanonical`, `MagicNumber`).*

### 117.3.3 Baskets of Singularities

A basket is a collection of point and curve singularities representing the ideal singularity

| Intrinsic | Description | Algorithm |

### 117.3.4 Curves and Dissident Points

Dissident points are special points along a curve singularity C that do not have the generic
transverse type. They are forced by the invariants of C and must be accounted for in the basket.
The following intrinsics generate candidate sets of dissident points for a given curve singularity,
to assist in constructing valid baskets.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `CanonicalDissidentPoints(C)` | A sequence of sequences of points, each of which minimally accounts for the index of `C` (further curves may still be needed). | Enumeration of minimal index-covering point sets following **[Buc03]**, **[SB]**. |
| `SimpleCanonicalDissidentPoints(C)` | A sequence of sequences of points, each minimally accounting for the index of `C` and not allowing further curves to meet C. | As above with additional simplicity constraint. |
| `PossibleCanonicalDissidentPoints(C)` | A sequence of all individual points that may appear on `C` as a dissident point. | Enumeration from transverse type data. |
| `PossibleSimpleCanonicalDissidentPoints(C)` | A sequence of individual points that may appear on `C` as a dissident point but are not at the intersection of C with another curve. | As above with simplicity constraint. |

## 117.4 Generic Polarised Varieties

A polarised variety X, A (regarded interchangeably as: a polarised variety; the total graded ring
R(X,A); an embedding X ⊂ P^N(w_0,…,w_N) by all multiples of A) is stored by its dimension,
weight sequence W, and Hilbert numerator n(t), so that the Hilbert series is P(t) = n(t)/Π_{w∈W}(1−t^w).

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `PolarisedVariety(d,W,n)` | The polarised variety of dimension `d`, weight sequence `W`, and Hilbert numerator polynomial `n`. (Little-used generic constructor; the type-specific constructors below are preferred.) | Constructor; does not run RR. |

### 117.4.1 Accessing the Data

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Weights(X)` | The weight sequence of the polarised variety `X`. | — |
| `Degree(X)` | The degree of the polarised variety `X`. | Computed from Hilbert series and dimension. |
| `Basket(X)` | The basket of singularities of `X`. | — |
| `RawBasket(X)` | The basket of `X` in raw sequence format: each singularity 1/r(a,b,c) is [r,a,b,c]; 1/r(a,r−a) is abbreviated [r,a]. Local polarisation n is not included (default −1 assumed). | — |
| `Dimension(X)` | The dimension of `X`. | — |
| `Codimension(X)` | The codimension of `X` (= length of weight sequence − dimension). | — |
| `HilbertNumerator(X)` / `Numerator(X)` | The numerator f(t) of the Hilbert series, expressed as P(t) = f(t)/Π_{w∈W}(1−t^w). | — |

| `ApparentCodimension(X)` | The apparent codimension from the sign pattern of the Hilbert numerator (number of sign-change levels). | Read off from numerator. |

### 117.4.2 Generic Creation, Checking, Changing

Procedural intrinsics modify polarised varieties at the generic level while preserving any subtype
(K3, Fano, etc.). Functional variants exist only for specific types.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `X eq Y` | True iff `X` and `Y` have equal dimension, weights, basket, and Hilbert numerator (which implies equal Hilbert series). | Component-wise equality. |
| `CheckCodimension(X)` | True iff the codimension of `X` equals its apparent codimension (from the Hilbert numerator). | Comparison of `Codimension` and `ApparentCodimension`. |
| `FirstWeights(X)` | Weights assigned during construction that carry relevance; returns usual weights if none were specially assigned. | — |
| `IncludeWeight(~X,w)` | Includes positive integer `w` among the weights of `X`, adjusting the Hilbert numerator and all other derived data accordingly. Procedural (in-place). | Multiply numerator by (1−t^w); update weight list. |
| `RemoveWeight(~X,w)` | Removes weight `w` from `X` (must appear and its removal must keep the Hilbert numerator a polynomial). Procedural. | Divide numerator by (1−t^w); error if not exact. |
| `MinimiseWeights(~X)` | Removes all weights from `X` whose presence is not required to keep the Hilbert numerator a polynomial. Procedural. | Iterative `RemoveWeight` until stable. |

## 117.5 Subcanonical Curves

A subcanonical curve is a polarised variety (C, D) where C is a nonsingular curve of genus g ≥ 2
and D is a divisor with K_C = kD for some positive integer k. The Hilbert polynomial of such a
curve is p(t) = deg(D)·t + 1 − g.

### 117.5.1 Creation of Subcanonical Curves

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `SubcanonicalCurve(g,d,Q)` | The subcanonical curve (C, D) with genus `g`, degree `d`, and initial Hilbert series coefficients `Q`. | Applies RR formula for curves; constructs graded ring data. |
| `IsSubcanonicalCurve(g,d,Q)` | Returns true and the curve if `g`, `d`, `Q` pass basic consistency checks for a subcanonical curve of genus `g` and degree `d`; false otherwise. | Runs RR checks; second return value is the curve if valid. |
| `HilbertPolynomialOfCurve(g,m)` | The Hilbert polynomial mt + 1 − g of a degree-m divisor on a genus-g curve. | Riemann–Roch formula for divisors on curves. |
| `IsEffective(C)` | True iff the polarising divisor of the subcanonical curve `C` is effective; equivalently iff the Hilbert series begins 1 + p_1 t + … with p_1 > 0. | Check first coefficient of Hilbert series. |

### 117.5.2 Catalogue of Subcanonical Curves

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `EffectiveSubcanonicalCurves(g)` | A sequence of data records for all effective subcanonical curves of genus g ≥ 3. | Systematic RR enumeration. |
| `EffectiveSubcanonicalCurves(g,d)` | As above, restricted to those polarised by a divisor of degree `d`. | As above, filtered by degree. |
| `IneffectiveSubcanonicalCurves(g)` | A sequence of data records for all ineffective subcanonical curves of genus g ≥ 3. | Systematic RR enumeration. |
| `IneffectiveSubcanonicalCurves(g,d)` | As above, restricted to those polarised by a divisor of degree `d`. | As above, filtered by degree. |

## 117.6 K3 Surfaces

K3 surface computations are based on **Altinok's Riemann–Roch formula [Alt98]** for polarised
K3 surfaces with Du Val singularities. The basic RR input is: genus g ≥ −1 (where p_1 = g+1 is
the coefficient of t in the Hilbert series) and a basket of Gorenstein surface (Du Val) singularities.

### 117.6.1 Creating and Comparing K3 Surfaces

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `K3Surface(g,B)` | A K3 surface with genus `g` and basket `B` (a basket type or raw format [[r,a],…]). | Altinok's RR formula **[Alt98]** applied to genus and basket. |
| `K3Copy(X)` | A new K3 surface carrying exactly the same data as `X`. | Copy constructor. |

### 117.6.2 Accessing the Key Data

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Genus(X)` | The genus of the K3 surface `X`: p_1 − 1 where p_1 is the coefficient of t in the Hilbert series. | Read off Hilbert series. |
| `TwoGenus(X)` | The 2-genus: p_2 − 1 where p_2 is the coefficient of t^2. | Read off Hilbert series. |
| `SingularRank(X)` | The sum Σ(r − 1) over all singularities 1/r(a, r−a) in the basket of `X`. | Sum over basket. |
| `AFRNumber(X)` | The number assigned to `X` in the low-codimension K3 lists of Altinok–Fletcher–Reid. | Database lookup. |

### 117.6.3 Modifying K3 Surfaces

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `IncludeWeight(X,w)` | Returns a new K3 surface equal to `X` but with weight `w` added and all derived data adjusted. (Functional, not procedural — returns a new object.) | Multiply Hilbert numerator by (1−t^w). |
| `RemoveWeight(X,w)` | Returns a new K3 surface equal to `X` but with weight `w` removed (must be removable without destroying the polynomial property of the numerator). | Divide Hilbert numerator by (1−t^w). |

## 117.7 The K3 Database

The K3 database contains 24,099 K3 surfaces. All K3 surfaces of genus g = −1, 0, 1, 2 are
included (4281, 6479, 6627, 6628 surfaces respectively). For higher genus, only those with
codimension at most 7 and genus 3–9 are included, since the data propagates predictably from
genus 2. The database is indexed primarily by the first five coefficients of the Hilbert series
(excluding the constant term). Note that the t-coefficient equals genus + 1, so a genus-g
search uses the integer g+1.

### 117.7.1 Searching the K3 Database

| `Number(D,X)` | The integer n and K3 surface Y such that Y = K3Surface(D, Genus(X)+1, n) has the same Hilbert series as `X`. Returns (0, —) if not found. | Index lookup by Hilbert series within the genus block. |
| `Index(D,X)` | The integer i and K3 surface Y such that Y = K3Surface(D, i) has the same Hilbert series as `X`. Returns (0, —) if not found. | Global index lookup by Hilbert series. |

*Worked examples: H117E5 (opening the database; retrieving genus-0 K3 surface no. 3 with basket 1/2(1,1), 1/3(1,2), 1/9(1,8); multi-genus search for surfaces with p_1=0, p_2=1, p_3=3; weight-based lookup). H117E6 (`Number` vs `Index` for a high-codimension K3 surface; comparing the database version in codimension 17).*

## 117.8 Fano 3-folds

Fano 3-fold computations are based on **Suzuki's Riemann–Roch formula [Suz]** for polarised
Fano 3-folds with terminal singularities. The Fano index f ≥ 1 and a basket of terminal 3-fold
point singularities provide the basic RR data. Singularities must be polarised by fA (so their
index r must be coprime to f and their weights of the form (f, a, r−a)).

### 117.8.1 Creation: f = 1, 2 or ≥3

|-----------|-------------|-----------|
| `Fano(f,B,g)` | A Fano 3-fold with Fano index f ≥ 1, Fano genus g ≥ 0, and basket `B` of terminal singularities. `B` may be in raw sequence format [[r,a,b,c],…]. | Suzuki's RR formula **[Suz]**. |
| `Fano(f,B)` | A Fano 3-fold with Fano index f ≥ 3 and basket `B` (f < 3 requires a genus argument). | Suzuki's RR formula **[Suz]** (genus determined by index). |
| `FanoIndex(X)` | The Fano index f of `X`. | — |
| `FanoGenus(X)` | The Fano genus of `X`: h^0(X, A), the dimension of sections of the polarising divisor. | Read off Hilbert series. |
| `FanoBaseGenus(X)` | The smallest possible Fano genus of `X`. | Minimum allowed by RR and basket. |
| `BogomolovNumber(X)` | The intersection number A(c_1(X)^2 − 3c_2(X)) for the Fano 3-fold X, A. | Intersection formula. |
| `IsBogomolovUnstable(X)` | True iff the Bogomolov number of `X` is strictly positive. | Sign of `BogomolovNumber`. |

*Worked examples: H117E7 (two Fano 3-folds with the same basket `MakeBasket([[3,1,2,2]])` and Fano index 2 but genus 2 and 3 respectively; `FanoGenus`, `FanoBaseGenus`).*

## 117.9 Calabi–Yau 3-folds

Calabi–Yau 3-fold computations are based on **Buckley's Riemann–Roch formula [Buc03]** for
polarised Calabi–Yau 3-folds with canonical singularities. The basket may include both point
and curve singularities. The normal number N of each curve singularity is determined by
`FindN` — the first non-negative value of NC_i consistent with the Hilbert series.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `CalabiYau(p1,p2,B)` | The Calabi–Yau 3-fold X, A with h^0(X, A) = p_1, h^0(X, 2A) = p_2, and basket `B`. | Buckley's RR formula **[Buc03]**. |
| `FindN(X)` | The first non-negative value of NC_i (C_i = i-th curve of the basket of `X`) and the gap between successive solutions. Returns (0, 0) if none found below `MaximumN` (default 100). Parameter: `MaximumN`. | Search over non-negative integers; checks each value against RR. |
| `FindN(p1,p2,B)` | As above, for a Calabi–Yau with given plurigenera `p1`, `p2` and basket `B` (may include both point and curve singularities). Parameter: `MaximumN` (default 100). | As above. |

## 117.10 Building Databases

This section describes the construction of Magma binary databases for large lists of polarised
varieties. The facility is intended for databases of up to a few tens of thousands of elements
(not Kreuzer–Skarke **[KS00]** scale).

### 117.10.1 The K3 Database

The K3 database is built in two steps: (1) enumerate all required K3 surfaces and write them as
abbreviated records to text files; (2) load those files and write binary data and index files
(K3S.dat, K3S.ind). During step (1), projection analysis (Types I and II) is used to set weights
and any inconsistencies between different projections are reported.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `CreateK3Data(g)` | Creates a sequence of all K3 surfaces of genus g ≥ −1. Results ordered by natural numerical order on Hilbert series coefficients. Applies Type I/II projection analysis to set weights. | Systematic enumeration via RR + Altinok's formula **[Alt98]**. |
| `CreateK3Data(g,r)` | As above, restricted to K3 surfaces with singular rank at most `r`. | Filtered enumeration. |
| `CreateK3Data(g,B)` | As above, restricted to baskets in the sequence `B` of baskets. | Filtered enumeration. |
| `K3SurfaceToRecord(X)` | A record in K3 record format encoding a subset of the data of `X` from which all attributes can be recomputed. | Serialisation to abbreviated record. |
| `K3Surface(x)` | The K3 surface whose data is stored in the K3 record `x` (overload for record type). | Deserialise from record. |
| `WriteK3Data(Q,F)` | Writes the K3 surfaces in sequence `Q` to the file named by string `F` as a Magma source file. When loaded, it creates a sequence `data` of K3 records. | Text serialisation. |
| `K3SurfaceRaw(D,i)` | The i-th element of the K3 database `D` as a raw tuple (fast, no translation overhead). | Binary read without translation. |
| `K3SurfaceRaw(D,Q,i)` | As above but among surfaces whose Hilbert series coefficients (of t^1…t^5) match the integer sequence `Q` (length ≤ 5). | Indexed binary read. |
| `K3Surface(x)` | The K3 surface corresponding to the raw tuple `x` from the binary K3 database format (overload for tuple type). | Deserialise from raw tuple. |

### 117.10.2 Making New Databases

New databases of polarised varieties can be built following a seven-step procedure:
1. Prepare a directory and copy the six template package files (data_spec.m, write.m,
   init_info.m, write_tools.m, write_func.m, create_ind_func.m); edit data_spec.m and write.m.
2. Decide the record format and the up-to-5 indexing parameters in data_spec.m.
3. Update the writing functions in write.m.
4. Collect all data as records in one or more files, in increasing index order.
5. Build the binary data and index files by loading writek3db.m (adapted).
6. Copy the binary files to the Magma data libraries.
7. Write cosmetic wrapper and search intrinsics and document them.

*(No new intrinsics defined in this subsection.)*
