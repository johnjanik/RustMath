**Handbook part:** VII — Local Arithmetic Fields

## Scope and overview

Chapter 48 introduces Magma's facilities for computing with **Galois rings**. The
features documented here are described as basic, with advanced features (subrings,
compatible embeddings, lattices of embeddings analogous to those for finite fields,
and linear codes over Galois rings) planned for the near future.

A Galois ring R in Magma is a finite algebraic extension of Zpa (where p is prime)
by a monic polynomial D ∈ Z[x] that is irreducible modulo p. R is presented as the
polynomial quotient ring

  Zpa[x]/⟨D⟩

and is written GR(pa, d), where d is the degree of D. Its cardinality is pad.

R has a unique maximal ideal generated by p. The quotient R/⟨p⟩ is a finite field
isomorphic to Zp[x]/⟨D⟩ (coefficients reduced mod p), called the **residue field**
of R. The subring Zpa generated by 1 is called the **base ring**.

For a non-zero element x of R, the **valuation** of x is the largest power of p
dividing its coefficients (viewing x as a polynomial in Zp[x]/⟨D⟩). x is a unit if
and only if its valuation is zero. Because of this valuation, Galois rings are
Euclidean rings and may be used wherever Magma accepts a general Euclidean ring —
including matrix and module functions and the computation of Gröbner bases.

## 48.2 Creation Functions

### 48.2.1 Creation of Structures

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `GaloisRing(q, d)` / `GR(q, d)` | Given integers q, d ≥ 1 with q = pa (p prime, a ≥ 1), create the default Galois ring GR(pa, d). The defining polynomial is the one used for Fpd, lifted to Zpa. **Note:** if p is very large, prefer the `(p, a, d)` form since Magma must first factor q. Angle-bracket notation assigns a name to the generator: `R<w> := GaloisRing(2, 3)`. | Default defining polynomial lifted from Fpd. |
| `GaloisRing(p, a, d)` / `GR(p, a, d)` | Given a prime p and integers a, d ≥ 1, create the default Galois ring GR(pa, d). The defining polynomial is the one used for Fpd, lifted to Zpa. Parameter `Check` (BoolElt, default `true`): by default p is tested as a strong pseudoprime for 20 random bases b with 1 < b < p; set `Check := false` to skip the primality test (useful when p is very large). | Default defining polynomial lifted from Fpd. |
| `GaloisRing(q, D)` / `GR(q, D)` | Given integer q = pa (p prime, a ≥ 1) and a monic polynomial D over Z that is irreducible mod p, create R = GR(pa, D). Coefficients of D are reduced modulo pa; R behaves as Zpa[x]/⟨D⟩. Prefer the `(p, a, D)` form for very large p. | Polynomial quotient ring construction. |
| `GaloisRing(p, a, D)` / `GR(p, a, D)` | Given a prime p, integer a ≥ 1, and a monic polynomial D over Z irreducible mod p, create R = GR(pa, D). Coefficients of D are reduced modulo pa; R behaves as Zpa[x]/⟨D⟩. Parameter `Check` (BoolElt, default `true`): same primality check as above. | Polynomial quotient ring construction. |

### 48.2.2 Names

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `AssignNames(~R, [f])` | Procedure to change the name of the generating element of R to the string f. When R is created, the name defaults to `R.1`. Does not create an identifier f — use angle brackets at creation or an explicit assignment for that. Because this is a procedure modifying R, a reference `~R` is required. | — |
| `Name(R, 1)` | Return the named generator of R, i.e. the element R.1. | — |

### 48.2.3 Creation of Elements

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `R . 1` / `Generator(R)` | The generator of R as an algebra over its base ring Zpa. Viewing R as Zpa[x]/⟨D⟩, this corresponds to x. | — |
| `R ! a` | Coerce a into R. a may be: (i) an element of R; (ii) an integer (identified with a mod pa); (iii) an element of the base ring Zpa; (iv) a sequence [a0, …, an−1] of base-ring elements, yielding a0 + a1·w + … + an−1·w^(n−1) where w = R.1. | — |
| `One(R)` / `Identity(R)` | Return the multiplicative identity 1 of R. | — |
| `Zero(R)` / `Representative(R)` | Return the additive identity 0 of R. | — |
| `Random(R)` | Return a pseudo-random element of R. | — |

### 48.2.4 Sequence Conversions

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `ElementToSequence(a)` / `Eltseq(a)` | Given an element a of GR(pa, d) = Zpa[x]/⟨D⟩, return the sequence [a0, …, ad−1] of coefficients in Zpa such that a = a0 + a1·w + … + ad−1·w^(d−1), with w = R.1. | — |

*Worked examples: H48E1 (creating GR(23, 2) with `GaloisRing(2^3, 2)`, verifying characteristic 8 and the relation w2 + w + 1 = 0, listing all 64 elements, creating elements via `R ! [1, 2]` and recovering coefficients with `Eltseq`).*
