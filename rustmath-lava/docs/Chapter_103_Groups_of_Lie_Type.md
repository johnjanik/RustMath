## Scope and overview

Chapter 103 describes Magma's facilities for computing with groups of Lie type. The
implementation covers reductive Lie groups (when the ring is **R** or **C**), reductive algebraic
groups (when the ring is an algebraically closed field), and finite groups of Lie type (when
the ring is a finite field). Both split and twisted forms are supported.

**Steinberg presentation [Ste62].** Computations in split groups are based on the Steinberg
presentation. Given a split group G with root datum R over ring k, the group is generated by
root elements x_r(t) for t in k (plus extra torus generators in the non-semisimple case). The
torus is represented as the abelian group Y ⊗ k×, where Y = Z^d is the coroot space. Weyl
group representatives n_r are included as redundant generators. Because the generating set is
parameterised by field elements, groups of Lie type form their own Magma category `GrpLie`
(not `GrpFP`). Groups are designed for exact fields; rounding-error behaviour over real/complex
fields is not controlled.

**Bruhat normalisation [Car93].** Every element g of a split group over a field k can be
written in Bruhat normal form g = u h ẇ u′, where u is a unipotent element (product of root
elements for positive roots), h is a torus element, ẇ is a Weyl group representative (reduced
word), and u′ is a product of root elements whose roots are sent from positive to positive by w.
The optional parameter `Normalising` (default `true`) controls whether products are
automatically placed in this form. Setting `Normalising := false` makes multiplication mere
word concatenation.

**Twisted groups [Hal05].** Twisted forms are constructed via Galois cohomology. If G is a
connected reductive linear algebraic group over k and K/k is a finite Galois extension, twisted
forms of G correspond one-to-one to 1-cocycles of Γ = Gal(K:k) on Aut_K(G). A quasisplit
group is determined by its extended root datum together with the Γ-action on K. The general
case requires a cocycle.

**Unipotent arithmetic [CHM08].** Multiplication of unipotent elements uses one of several
configurable algorithms (collection from left, collection from outside, classical formulas for
sparse root data, symbolic methods via Hall polynomials). The `Method` parameter selects the
algorithm; `"Default"` picks the best automatically.

## 103.1 Introduction

### 103.1.1 The Steinberg Presentation

The Steinberg presentation **[Ste62]** provides the generating relations for a split group of
Lie type. Root elements x_r(t) for roots r and ring elements t, torus elements (vectors in k^d
with invertible entries), and Weyl group representatives n_r together define the group. See the
scope section above for details.

### 103.1.2 Bruhat Normalisation

The Bruhat decomposition **[Car93, Chapter 2]** gives the normal form u h ẇ u′ described
above. Intrinsics controlled by this normalisation appear throughout §§103.5–103.6.

### 103.1.3 Twisted Groups of Lie Type

Twisted forms of a split group G are in bijection with H¹(Γ, Aut(G)); two forms are conjugate
iff the cocycles are cohomologous. The implementation follows **[Hal05]**. See §103.2.2–103.2.3.

### 103.2.2 Galois Cohomology

If G is a linear algebraic group over k with algebraic closure L, then Γ = Gal(L:k) acts on G
and on Aut(G). The twisted forms of G correspond to H¹(Γ, Aut(G)), with forms conjugate iff
their cocycles are cohomologous. In practice, one computes the cohomology of Gal(K:k) on
Aut_K(G) for a finite Galois extension K of k. These functions are based on **[Hal05]** and
currently work over finite fields only.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `GammaGroup(k, G)` | Returns the group of Lie type `G` as a Γ-group with Γ = Gal(K:k), where K is the base field of `G`. The field `k` must be a subfield of K. | Galois cohomology framework **[Hal05]**. |
| `GammaGroup(k, A)` | Returns the automorphism group A = Aut_K(G) of the group of Lie type `G` as a Γ-group with Γ = Gal(K:k). | As above. |
| `ActingGroup(G)` / `ActingGroup(A)` | Given a Γ-group `G` or automorphism Γ-group `A`: returns Γ = Gal(K:k) together with the map m from the abstract Galois group Γ to the set of field automorphisms. | — |
| `ExtendGaloisCocycle(c)` | Given a cocycle c in H¹(Γ, A/A₀) where A = Aut_K(G) and Γ = Gal(K:k), extends it to a cocycle in H¹(Γ, A). Params: `GBAl` (Gröbner basis algorithm, default `"Walk"`), `Printeqs` (print the polynomials, default `false`). Finite fields only. | Gröbner basis computation **[Hal05]**. |
| `GaloisCohomology(A)` | Computes H¹(Γ, Aut_K(G)) where `A` is the Γ-group of automorphisms returned by `GammaGroup`. Params: `GBAl` (default `"Walk"`), `Printeqs` (default `false`), `Recompute` (default `false`). Finite fields only. | Gröbner basis computation **[Hal05]**. |
| `IsInTwistedForm(x, c)` | Returns `true` iff the element `x` of a group of Lie type is contained in the twisted form defined by the cocycle `c`. | Membership test via cocycle **[Hal05]**. |

*Worked example: H103E2 (Galois cohomology of A3(5²), constructing the two cohomology classes, verifying elements in the twisted form ²A3(5)).*

## 103.5 Constructing Elements

Elements of a group of Lie type G over ring R are constructed from lists whose entries may be:
1. A tuple `<r, t>` with r ∈ {1,…,2N} and t ∈ R — the root element x_r(t).
2. A sequence of such tuples.
3. A sequence `[t₁,…,t_N]` of ring elements — the unipotent element x₁(t₁)⋯x_N(t_N).
4. An integer r ∈ {1,…,2N} — the Weyl group representative n_r.
5. A Weyl group element (word or permutation) — the representative ẇ.
6. A vector v ∈ R^d with every entry invertible — a torus element.
7. An element of G.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `elt< G \| L >` | Construct an element of `G` from list `L` of the forms above. | Steinberg presentation **[Ste62]**. |
| `Identity(G)` / `Id(G)` / `G ! 1` / `elt< G \| >` | The identity element of `G`. | — |
| `TorusTerm(G, r, t)` | The torus term h_r(t) = α*_r ⊗ t in `G`, where r is the coroot index and t is a base-ring element. | — |
| `CoxeterElement(G)` | The representative of the Coxeter element (product of all simple reflections) in the Weyl group of `G`. | — |
| `Random(G)` | A random element of the finite group of Lie type `G` (base ring must be finite). Param: `Uniform` (default `true`; if `false`, each Borel double coset occurs with equal frequency — much faster but not uniform). | Double-coset sampling. |
| `Eltlist(g)` | The list corresponding to element `g`. | — |
| `CentrePolynomials(G)` / `CenterPolynomials(G)` | A set of polynomials satisfied by the coordinates of a torus element h iff h is in the centre of `G`. | — |

*Worked examples: H103E7 (constructing elements of A5 over Q from tuples, integers, sequences, and torus vectors); H103E8 (centre polynomials of B3 over Q, computing central elements via rational points of an affine scheme).*

## 103.8 Roots, Coroots and Weights

## 103.12 Twisted Tori

For a finite untwisted group of Lie type G(k), a twisted torus T_w(k) is the subgroup
{t ∈ T(K) | t^(σw) = t} of the standard K-split torus T(K), where K is the smallest field
extension of k making this possible, σ is the generator of Gal(K:k), and w is an element of
the Weyl group. The algorithms are based on **[Hal05]**.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `TwistedTorusOrder(R, w)` | Given root datum `R` and Weyl group element `w`, computes the orders of the cyclic components of the twisted torus T_w(k) ⊂ G(R,k) as a sequence of polynomials in q (the field order). | Twisted torus order formula **[Hal05]**. |
| `TwistedToriOrders(G)` / `TwistedToriOrders(R)` | For each conjugacy class of the Weyl group of `G` (or `R`), takes a representative w and computes `TwistedTorusOrder(R, w)`. Returns a sequence of lists [TwistedTorusOrder(R,w), w] for each class. | As above. |
| `TwistedTorus(G, w)` | Computes the twisted torus T_w(k) of `G` for Weyl group element `w`. Returns a list of: sequence of orders of cyclic parts, sequence of generators, and w. | Constructive twisted torus algorithm **[Hal05]**. |
| `TwistedTori(G)` | Computes one twisted torus T_w(k) per conjugacy class of the Weyl group of `G`. Returns a sequence. | As above. |

*Worked examples: H103E20 (all twisted tori of A1(5), showing the second torus lives over the quadratic extension); H103E21 (orders of maximal tori of G2(q) as polynomials in q).*

## 103.13 Sylow Subgroups

Sylow subgroup computation for finite groups of Lie type. A prime p is classified as: "GOOD"
if p equals the characteristic; "good" if the Sylow subgroup is abelian (contained in a torus);
"bad" if the Sylow subgroup is non-abelian (not contained in a torus). The algorithms are
based on **[Hal05]**.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `PrintSylowSubgroupStructure(G)` | Prints a list of all primes p dividing |G|, their "goodness", the exponent of p in |G|, and a sequence describing the structure: positive integers give orders of cyclic components of a torus T_w containing the Sylow p-subgroup of ⟨T_w, C_W(w)⟩; a negative number gives the p-part from C_W(w). One line per qualifying torus. | Sylow structure via twisted tori **[Hal05]**. |
| `SylowSubgroup(G, p)` | Computes a p-Sylow subgroup S of the finite group of Lie type `G`. Returns a list of two sequences: the first gives orders of generators (positive for torus elements, negative for the order of ⟨g⟩/(⟨g⟩ ∩ T_w) for non-toral generators); the second gives the generators themselves. | Sylow subgroup construction via twisted tori **[Hal05]**. |

*Worked example: H103E22 (Sylow subgroup structure of G2(5); computation of the 2-Sylow subgroup).*
