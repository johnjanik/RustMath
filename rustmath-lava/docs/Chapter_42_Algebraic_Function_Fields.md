# Chapter 42 — Algebraic Function Fields

**Handbook part:** VI — Global Arithmetic Fields
**Handbook pages:** 1087–1186 (PDF pages 1212–1321)

---

## Scope and overview

This chapter covers algebraic function fields in one variable and their computational infrastructure as implemented in Magma, based on the KANT Version 4 system. An algebraic function field F/k is a finite field extension of k(x) for some element x transcendental over k. The Magma type is `FldFun` with elements of type `FldFunElt`. Three distinct ring types are treated: function fields (`FldFun`), orders of function fields (`RngFunOrd`), and fields of fractions of orders (`FldFunOrd`).

Fields can be represented either as algebraic extensions k(x, α₁, …, αₙ) (the form with the most functionality, supporting orders, series rings, Galois groups, and subfields), or as quotients of k[x, y] (curve-style, no orders). Non-simple extensions (adjoining roots of several polynomials at once) are supported but lack primitive elements and some differential functions. Relative extensions have the same functionality as non-simple extensions except series rings, Galois groups, and subfields.

The algorithmic highlights of the chapter are: maximal order / normalisation (Round 2 and specialised algorithms for Kummer, Artin–Schreier, and radical extensions), Galois groups of polynomials over rational function fields (Stauduhar–Geißler–Klüners–Fieker–Sutherland, no degree limit), subfield computation (Klüners **[Klü02]** over Q(t); Klüners–van Hoeij–Novocin **[vHKN11]** over Fq(t)), automorphisms (Heß **[Heß04]** for general isomorphisms; classical Klüners for base-field-fixing automorphisms), divisor class group (index calculus, randomised subexponential **[Heß99]**), Riemann–Roch space / short basis (**[Heß99]**), Weil descent / GHS attack (**[Gau00, Bla05]**), Cartier operator, Tate–Lichtenbaum pairing, and the L-polynomial / zeta function.

Special functions for rational function fields are described in Chapter FldFunRat.

## 42.1 Introduction

### 42.1.1 Representations of Fields

All function fields in Magma can be represented as k(x, α) where x is transcendental and α is algebraic. This representation supports the most functionality. Alternatively a field may be represented as a quotient of k[x, y] (no orders). Relative extensions and non-simple extensions have restricted functionality as noted above.

## 42.5 Galois Groups

Finding Galois groups (of normal closures) of polynomials over rational function fields over k ∈ {Q, Fq} uses the method of Stauduhar as extended by Klüners–Geißler **[GK00, Gei03]**, Fieker **[FK12]**, and Sutherland **[Sut]**. There is no longer any degree limit as the classification of transitive groups is not required. The algorithm provides the explicit action on the roots (as power series in an unramified p-adic or finite field extension) and depends on the corresponding problem being implemented for the residue class field. For imprimitive fields the starting point in the subgroup lattice is improved using subfield computation; for primitive fields a combination of Stauduhar and the absolute resolvent method **[SM85]** is used.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `GaloisGroup(f)` | For a separable polynomial f(t, x) of degree n over the rational function field k(t), k ∈ {Q, Fq} (or an extension thereof when k = Fq): returns a permutation group (Galois group of the splitting field), a sequence of roots expressed as power series (second return), and GaloisData (third return). Parameters: `Prime`, `NextPrime`, `ProofEffort` (RngIntElt, default 10), `Ring` (GaloisData), `ShortOK` (BoolElt, default false), `Old` (BoolElt, default false — use old ≤degree-23 version), `Verbose GaloisGroup`. | Stauduhar extended by Klüners–Geißler–Fieker–Sutherland **[GK00, Gei03, FK12, Sut]**; imprimitive case uses subfield computation; primitive case uses absolute resolvent **[SM85]**. |
| `GaloisGroup(F)` | For a function field F defined by one polynomial over a rational function field or a global algebraic function field: the Galois group of the normal closure of F. Same parameters as `GaloisGroup(f)` except no `Old`. | Same Stauduhar extension **[GK00, Gei03, FK12, Sut]**. |

*Worked examples: H42E13 (degree-15 polynomial over Q(t), group 1/2[S(5)³]S(3)); H42E14 (polynomials over Fq(t), two examples).*

## 42.6 Subfields

For finite extensions L of Q(t), Fq(t), or extensions K of Fq(t), Magma can compute all intermediate fields. Subfield computation is independent of Galois groups.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|

*Worked example: H42E15 (degree-14 polynomial over Q(t); one non-trivial degree-7 subfield found).*

## 42.7 Automorphism Group

For K a finite extension of the rational function field over a finite field, the rationals, or a number field, there are two natural notions: automorphisms fixing the base field (analogous to the number field case, implemented by Klüners) and arbitrary automorphisms which may also induce non-trivial maps of the constant field (implemented by Heß **[Heß04]**).

### 42.7.1 Automorphisms over the Base Field

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Automorphisms(K, k)` | All Q(t)-automorphisms of the absolute finite extension K that fix k (k must be Q(t)). | Klüners's base-field-fixing automorphism method. |
| `AutomorphismGroup(K, k)` | The group of k-automorphisms of K (k must be Q(t)) as a finitely presented group, together with the map from the group to the automorphism sequence. | Klüners's method. |
| `IsSubfield(K, L)` | Given two absolute finite extensions K and L of Q(t), decide if L is an extension of K; if so return the embedding map K → L. | — |
| `IsIsomorphicOverQt(K, L)` | Given two absolute finite extensions K and L of Q(t), decide if L is Q(t)-isomorphic to K; if so return the isomorphism K → L. | — |

*Worked example: H42E16 (degree-7 extension of Q(t); 7 automorphisms; cyclic group confirmed via GenericGroup and AutomorphismGroup); H42E17 (IsSubfield, IsIsomorphicOverQt for x⁴ − t³).*

### 42.7.2 General Automorphisms

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Isomorphisms(K, E)` | A list of at most `Bound` field isomorphisms from K to E. ## 42.16 Weil Descent

Weil descent transfers problems about the Jacobian of a curve C over L to the Jacobian of a higher-genus curve D over a subfield K ⊆ L. The GHS attack (see **[Gau00]** and the chapter by F. Heß in **[Bla05]**) specialises to ordinary elliptic curves in characteristic 2. The functions below implement the GHS Weil descent in a general characteristic-p setting.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `WeilDescent(E, k)` | Main function. E must be an Artin–Schreier function field over K (finite extension of k): base field K(x), generator satisfying yᵖ − y = c/x + a + b·x for a, b, c ∈ K with b, c ≠ 0 and at least one of: Tr_{K/k}(b) ≠ 0, Tr_{K/k}(c) ≠ 0, Tr_{K/Fp}(a) = 0. Returns the Weil descent function field F over k and a map from divisors of E to divisors of F representing Jac(C)(K) → Jac(D)(k). | GHS Weil descent **[Gau00, Bla05]**. |
| `ArtinSchreierExtension(c, a, b)` | Convenience: create the function field extension of K(x) by yᵖ − y − c/x − a − bx (K = parent of a, b, c; p = characteristic of K). | — |
| `WeilDescentDegree(E, k)` | Degree of the descended function field F over k(x), computed from the Frobenius action on a, b, c only (no actual descent). | — |
| `WeilDescentGenus(E, k)` | Genus of the descended function field F, computed from the Frobenius action only. | — |
| `MultiplyFrobenius(b, f, F)` | Convenience: compute f(F)(b) = a₀b + a₁F(b) + a₂F(F(b)) + … for polynomial f = Σaᵢxⁱ over a subring of R, F a map R → R, b ∈ R. Useful for generating K-elements with prescribed Frobenius minimal polynomial. | — |

*Worked example: H42E45 (descent over a degree-31 extension in characteristic 2, yielding genus-31 hyperelliptic field; and a characteristic-3 example producing a degree-27, genus-78 field).*
