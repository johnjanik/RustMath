# Chapter 19 — Integer Residue Class Rings

**Handbook part:** III — Basic Rings
**Handbook pages:** 331–348 (PDF pages 462–481)

---

## Scope and overview

This chapter presents the machinery provided in Magma for computing in quotient rings of the
ring of integers Z, that is, integer residue class rings. The chapter covers four main areas:

1. **Ideals of Z** — the general ideal machinery applied to Z, including construction and membership tests.
2. **Z as a number field order** — functions that make Z behave like an order of a number field, enabling compatibility with number field computations.
3. **Residue class rings Z/mZ** — creation, coercion, invariants, structure operations, and arithmetic in the ring Z/mZ for m > 1.
4. **Dirichlet characters** — homomorphisms ε : (Z/NZ)∗ → R∗, extended to all of Z by setting ε(x) = 0 when gcd(x, N) ≠ 1. Covers creation of Dirichlet groups, properties, evaluation, and arithmetic.

When m is prime, Z/mZ is a field; however, Magma's dedicated finite field machinery (Chapter 21)
should be used instead for such computations, as it exploits the special structure of finite fields
for superior performance. Magma maintains at most one copy of Z/mZ per modulus m at any time,
saving memory and avoiding confusion between isomorphic copies.

No bibliography is provided in this chapter; the intrinsics are standard and rely on elementary
number-theoretic algorithms.

## 19.1 Introduction

This chapter presents the machinery provided in Magma for computing in quotient rings of the
ring of integers Z. The first half covers operations with ideals of Z and their quotient rings;
the second half provides an introduction to computing with Dirichlet characters.

## 19.2 Ideals of Z

The theory of ideals of Z is very elementary; for completeness the general machinery for ring
ideals applies. Such ideals have type `RngInt`, the same type as the ring of integers itself.
In Z any subring is an ideal, so the `sub<>` constructor creates the same object as `ideal<>`.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `ideal< R \| a >` | Given the ring of integers Z and an integer `a`, return the ideal of Z generated by `a`. | — |

*Worked example: H19E1 (constructing ideals of Z, membership tests, verifying Z = ideal<Z\|1>).*

## 19.3 Z as a Number Field Order

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Decomposition(R, p)` | Returns the ideal decomposition of the prime `p`, i.e. the list `[< ideal<Z\|p>, 1 >]` as in the number field case. | — |
| `Generator(I)` | A generator for the given ideal `I`. | — |
| `RamificationIndex(I, p)` / `RamificationIndex(I)` | The ramification index of `I` over Z, which is always 1. | — |
| `Degree(I)` | The inertia degree of the ideal `I`, which is always 1. | — |

| `Valuation(x, I)` | The valuation of the integer `x` at the prime ideal `I`. | — |
| `ClassRepresentative(I)` | The representative of the ideal `I` of Z in the basis of the class group. | — |

## 19.4 Residue Class Rings

The ring Z/mZ consists of representatives for the residue classes of integers modulo m > 1.
Magma maintains at most one copy of Z/mZ per modulus during a session. If m is prime, Z/mZ
forms a field, but the finite field functions of Chapter 21 should be preferred for such cases.

### 19.4.1 Creation

In addition to the general quotient constructor, several abbreviations create residue class rings.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `quo< Z \| I >` | Given the ring of integers Z and an ideal `I`, create the residue class ring modulo that ideal. | — |
| `quo< Z \| m >` | Given the ring of integers Z and a nonzero integer `m`, create the residue class ring Z/mZ. | — |
| `ResidueClassRing(m)` / `IntegerRing(m)` / `Integers(m)` / `RingOfIntegers(m)` | Given an integer greater than zero, create the residue class ring Z/mZ. | — |
| `ResidueClassRing(Q)` / `IntegerRing(Q)` / `Integers(Q)` | Create the residue class ring Z/mZ where `m` is the integer corresponding to the factorization sequence `Q`. More efficient than creating the ring by `m` alone, since the factorization is stored for reuse. | — |

*Worked example: H19E2 (residue ring modulo the largest prime ≤ 2^16; finding x such that x^3 = 23).*

### 19.4.2 Coercion

Automatic coercion takes place between Z/mZ and Z so that a binary operation like `+` applied
to an element of Z/mZ and an integer results in a residue class from Z/mZ. Using `!`, elements
from a prime field Fp can be coerced into Z/pZ and vice versa. Transitions between Z/mZ and
Z/nZ can be made using `!` provided m divides n or n divides m. When there is a choice — such
as coercing an element r ∈ Z/mZ into Z/nZ with m | n — the result is the residue class
containing the representative for r.

*Worked example: H19E3 (coercion of 5 mod 3 = 2 into Z/6Z, showing representative 2 is mapped, not 5).*

### 19.4.6 Homomorphisms

Ring homomorphisms with domain Z/mZ are completely determined by the image of 1. The general
homomorphism constructor requires no arguments (since it maps 1 to 1).

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `hom< R -> S \| >` | Given a residue class ring R and a ring S, create a homomorphism from R to S determined by f(1_R) = 1_S. The user is responsible for verifying that the map defines a valid homomorphism. | — |

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|

## 19.8 Dirichlet Characters

Let R be a ring. A Dirichlet character over R of modulus N is a homomorphism
ε : (Z/NZ)∗ → R∗, extended to all of Z by ε(x) = 0 when gcd(x, N) ≠ 1. The conductor of ε
is the smallest positive integer M such that the homomorphism (Z/NZ)∗ → R∗ factors through
(Z/MZ)∗ via the natural map (Z/NZ)∗ → (Z/MZ)∗.

### 19.8.1 Creation

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `DirichletGroup(N)` | The group of Dirichlet characters modulo N with image in RationalField(). This group has exponent at most 2. | — |
| `DirichletGroup(N, R)` | The group of Dirichlet characters modulo N with image in the ring R. Here R can be the integers, rationals, a number field, or a finite field. | — |
| `DirichletGroup(N, R, z, r)` | The group of Dirichlet characters mod N with image in the order-`r` cyclic subgroup of R generated by the root of unity `z`. Here `z` must be an element of R of exact order `r`. | — |
| `FullDirichletGroup(N)` | The group of Dirichlet characters modulo N taking values in the m-th cyclotomic field, where `m` is the exponent of the unit group modulo N. Shortcut for `DirichletGroup(N, R, z, r)` with appropriate cyclotomic data. | — |
| `BaseExtend(G, R)` / `BaseExtend(G, R, z)` | The group of Dirichlet characters corresponding to `G` with values in the ring R. In the second form, the distinguished root of unity of the base ring of `G` is identified with the given element `z`. | — |
| `AssignNames(~G, S)` | Assign names to the generators of the Dirichlet group G. | — |

### 19.8.2 Element Creation

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Elements(G)` | A sequence containing all Dirichlet characters in the Dirichlet group G. | — |
| `Random(G)` | A random element of the Dirichlet group G. | — |
| `G . i` | The i-th generator of the group G. | — |
| `G ! x` | Coerces the given element `x` into the Dirichlet group G. Here `x` may be a Dirichlet character from a different group, or a sequence of integers specifying an element of the AbelianGroup of G. | — |
| `KroneckerCharacter(D)` / `KroneckerCharacter(D, R)` | The Kronecker character n ↦ (d/n), where `d` is the fundamental discriminant associated to integer D. When a ring R is given, the character is returned with values in R. | — |
