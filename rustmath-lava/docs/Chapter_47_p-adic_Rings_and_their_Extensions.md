## Scope and overview

Chapter 47 covers Magma's implementation of finite extensions of the ring **Z**_p of p-adic integers and the field **Q**_p of p-adic numbers, collectively called *local rings* and *local fields*. Two distinct computational models are provided:

1. **Fixed precision rings** (`RngPadRes`, `RngPadResExt`, elements `RngPadResElt` / `RngPadResExtElt`): work in finite quotients L/π^k L; the quotient is exact but precision management is left to the user — dividing may silently return a result at full ring precision even when the true answer has fewer significant digits.

2. **Free precision rings** (`RngPad`, `FldPad`, elements `RngPadElt` / `FldPadElt`): each element carries its own precision; arithmetic automatically propagates precision loss. Recommended for general use unless raw speed is critical. Can be bounded or unbounded (elements carry arbitrarily large but finite precision).

All precision is measured with respect to the *uniformizer valuation* v_π of the current ring. A precision-k element of a base ring maps to precision ek in a ramified extension of degree e, which can be surprising. Extensions must be either **unramified** (defined by an inertial polynomial — irreducible over the residue class field) or **totally ramified** (defined by an Eisenstein polynomial — leading coefficient a unit, constant term of valuation 1, all intermediate coefficients of valuation ≥ 1). Towers of such extensions are supported.

Key algorithms attributed in the chapter: **Hensel lifting** for root and factor lifting; the **Newton polygon** for computing root valuations; **R4-methods of Pauli** [Pau01b] for polynomial splitting fields; **Harley's iterative lifting** [C+05] for Teichmüller lifts; and **Pauli's enumeration of local extensions** [Pau01a] and **construction of class fields** [Pau06].

## 47.1 Introduction

Magma supports finite extensions of **Z**_p and **Q**_p. Two models exist: fixed precision (`RngPadRes`/`RngPadResExt`) and free precision (`RngPad`/`FldPad`). For a different category of local fields admitting extensions by arbitrary irreducible polynomials, see Chapter 51.

---

## 47.2 Background

The p-adic field **Q**_p arises as the completion of **Q** with respect to |x|_p = p^{−v_p(x)}. Its ring of integers **Z**_p has unique maximal ideal (p) and residue class field **Z**_p / p**Z**_p ≅ **F**_p. Elements can be written as power series Σ a_i p^i. For a local field L, an extension L_2 = L_1[α] (α a root of an irreducible polynomial) is also local. The ramification degree e and inertia degree f satisfy ef = n = [L_2 : L_1]. Unramified extensions are unique up to isomorphism (generated by a (p^n − 1)-th root of unity, Galois with cyclic Galois group generated by the Frobenius σ : ζ ↦ ζ^p). Cyclotomic representations make Frobenius computation efficient but are expensive to construct.

## 47.3 Overview of the p-adics in Magma

### 47.3.1 p-adic Rings

The fixed precision model works in L/π^k L; operations that lose precision (e.g. division) still return results to full ring precision. The free precision model lets each element carry its own precision, relieving the user of precision bookkeeping at the cost of inexactness (no exact zero element exists).

### 47.3.2 p-adic Fields

A local field is the field of fractions of a local ring. Elements are stored as x = π^v u + O(π^{v+k}); operations with elements whose unit parts do not overlap can yield zero known digits.

### 47.3.3 Free Precision Rings and Fields

Bounded free precision structures cap element precision at k; unbounded structures allow arbitrary (but finite) precision. Bounded free precision rings are "inexact" versions of fixed precision rings. Unbounded precision is recommended for most applications.

### 47.3.4 Precision of Extensions

Precision is always measured in the current ring's valuation. If L_1/L_2 has ramification degree e, a precision-k element of L_2 has precision ek in L_1.

A local ring is constructed either as a p-adic ring or as an extension (unramified or totally ramified) of an existing local ring. The user specifies fixed or free precision and (for bounded structures) a precision bound. For local rings, precision is absolute; for local fields, precision is relative (the precision of the unit part).

## 47.8 Operations on Elements

### 47.8.1 Arithmetic

For local ring elements, the precision of a result is the minimum of (v_1 + k_2, v_2 + k_1) for multiplication and the minimum of the absolute precisions for addition/subtraction. Division yields a result in the field of fractions unless `div` is used. For local field elements, multiplication/division precision is min(k_x, k_y); addition/subtraction precision is min(v_x + k_x, v_y + k_y) − v(x ± y), which may be 0.

## 47.9 Linear Algebra

All linear algebra over local rings and fields is performed internally using the fixed precision model: linear algebra over free precision structures is reduced to an appropriate quotient ring. This allows exact algorithms (e.g. echelon forms over finite rings), but the answer may be returned to less precision than is theoretically achievable.

### 47.11.2 Roots of Polynomials

#### 47.11.2.1 Hensel Lifting of Roots

Roots are found by: (1) determining root valuations via the Newton polygon; (2) finding a first approximation over the residue class field; (3) refining until the Hensel condition v(f(a)) > 2v(f'(a)) is satisfied.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `NewtonPolygon(f)` | The Newton polygon of f = Σ c_i x^i: the lower convex hull of the points (i, v(c_i)). The slopes give the valuations of roots in a splitting ring; the horizontal width of each face gives the number of roots with that valuation. Faces accessed via `Faces`, `GradientVector`, `EndVertices`. | Newton polygon construction (see also Chapter 46). |
| `ValuationsOfRoots(f)` | Sequence of pairs (valuation, count) for the roots of f. | Newton polygon. |
| `HenselLift(f, x)` / `HenselLift(f, x, k)` | Lift the approximate root x of f to a root with precision k (or the default precision of the structure). Error if the Hensel condition v(f(x)) > 2v(f'(x)) is not satisfied. | **Hensel lifting**. |

*Worked examples: H47E16 (Newton polygon of a degree-10 polynomial over Z_3 whose roots have valuations 0, 1, 2, 3, 6; Faces/GradientVector/EndVertices recover root counts; ValuationsOfRoots gives the same result directly); H47E17 (Hensel lifting to compute square roots in a degree-4 extension of Z_3 and Z_2; for p = 2 a better approximation via brute-force search is needed before lifting).*

#### 47.11.2.2 Functions Returning Roots

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Roots(f)` / `Roots(f, R)` | Roots of f over local ring/field R (default: coefficient ring of f) as a sequence of (root, multiplicity) tuples. Parameter `IsSquarefree` (default `false`): setting to true may speed computation. | Factorization then extraction of linear factors. |
| `HasRoot(f)` | Returns true and a root if f has a root over its coefficient ring; otherwise returns false. | As above. |

*Worked examples: H47E18 (classifying ramified extensions of Z_2 of degree 2 by looping over Eisenstein polynomials with small coefficients and using `HasRoot` to check whether a new polynomial defines a new extension; obtains all 6 ramified quadratic extensions).*

### 47.11.3 Factorization

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `HenselLift(f, s)` | Given a sequence s of monic pairwise coprime polynomials (mod π) whose product is congruent to f (mod π), lift to polynomials t such that f ≡ Π t[i] (mod π^k) where k is the minimum precision of the coefficients of f. | **Hensel lifting** (multivariate/factored form). |
| `IsIrreducible(f)` | True iff f is irreducible over its local ring or field L. Currently works over p-adic rings and their unramified and totally ramified extensions (and towers thereof). | — |
| `SquareFreeFactorization(f)` | Sequence of (polynomial, multiplicity) pairs, squarefree, whose product is f (to some precision). Same ring restrictions as `IsIrreducible`. | — |
| `Factorization(f)` / `LocalFactorization(f)` | Factorization of f into irreducibles as (factor, multiplicity) pairs. Precision of the input must meet or exceed `SuggestedPrecision(f)` for success; multiple factors are returned at reduced precision. Parameters: `IsSquarefree` (default `false`), `Certificates` (default `false` — if true, compute irreducibility certificates usable for p-maximal order computation), `Ideals` (default `false`), `Extensions` (default `false` — if true, certificates include the extension defined by each factor). | Newton polygon factorisation followed by **Hensel lifting**; see also **[Pau01b]**. |
| `SuggestedPrecision(f)` | A lower bound on the precision at which `Factorization(f)` is Hensel-liftable to a correct factorization. The bound may still be insufficient. Same ring restrictions as `IsIrreducible`. | — |
| `IsIsomorphic(f, g)` | For two irreducible polynomials over the same p-adic field, test if the extensions they define are isomorphic. | — |
| `Distance(f, g)` | For two Eisenstein polynomials of the same degree and discriminant, the minimal weighted valuation of the difference of coefficients. | — |

*Worked examples: H47E19 (HenselLift for factorizations: lifting a 2-adic factorization of (x−1)···(x−8) from mod 2 to exact); H47E20 (SuggestedPrecision and Factorization on polynomials over degree-4 extensions; factorization of a degree-12 polynomial over ramified extensions of Z_3 at precisions 20 and 25); H47E21 (factoring x^5 − x + 1 over Z_2, Z_3, Z_7 reveals cycle types 2+3, 5, 2+3, so Galois group contains elements of orders 2, 3, 5, 6, hence is S_5).*

## 47.12 Automorphisms of Local Rings and Fields

The automorphisms of a local ring or field are completely determined by images of the generators, and all necessary computations can be performed within the local ring itself.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Automorphisms(L)` | All automorphisms of L over its p-adic subfield **Q**_p as a sequence of maps L → L. | Automorphisms of local fields via their action on generators; all computations in the local ring. |
| `Automorphisms(K, k)` | All k-automorphisms of K (automorphisms fixing k) as a sequence of maps K → K. | As above, relative version. |
| `AutomorphismGroup(L)` | Automorphism group of L over its p-adic subfield as a permutation group (regular action), plus the map from the permutation group to the explicit automorphisms. | — |
| `AutomorphismGroup(K, k)` | Automorphism group of K over k as a permutation group (regular action), plus the connecting map. | — |
| `IsNormal(K)` | True iff K is normal over its prime field **Q**_p (i.e., K admits exactly [K : **Q**_p] automorphisms). | — |
| `IsNormal(K, k)` | True iff K is normal over the subfield k. | — |
| `IsAbelian(K, k)` | True iff the automorphism group of K over k is abelian. | — |
| `Continuations(m, L)` | For an automorphism m of the p-adic subring of L, computes all possible extensions of m to L. | — |
| `IsIsomorphic(E, K)` | Tests whether two p-adic rings or fields are isomorphic over **Q**_p. | — |

*Worked examples: H47E22 (extension of Z_2 with ramification degree 2 and inertia degree 2; all 4 automorphisms computed, with their images on generators a and b; AutomorphismGroup as a permutation group of degree 4).*

| Intrinsic | Description | Algorithm |

| `LocalRing(P, k)` | The completion of the order of P at P with fixed precision k, plus the embedding of the order. | — |

## 47.14 Class Field Theory

Local class field theory classifies abelian extensions of local fields via *norm groups* (images of the norm map in the multiplicative group), in contrast to the ideal/divisor class groups of global class field theory. The multiplicative group of a local field is well understood and explicitly computable.

### 47.14.1 Unit Group

Unit group algorithms are by S. Pauli **[Pau06]**. All unit group functions operate on **fixed precision** rings only.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `PrincipalUnitGroupGenerators(R)` | Generators for the group of principal units 1 + π**Z**_R of the p-adic ring or field R. | Pauli's unit group algorithm **[Pau06]**. |
| `PrincipalUnitGroup(R)` | Abstract abelian group isomorphic to the principal unit group of R, plus an explicit isomorphism (map between the abstract group and R). | Pauli's unit group algorithm **[Pau06]**. |
| `UnitGroup(R)` | Abstract abelian group isomorphic to the unit group of fixed precision p-adic ring R, plus the explicit map. | Pauli's unit group algorithm **[Pau06]**. |
| `UnitGroup(F)` | Abstract abelian group isomorphic to the multiplicative group of fixed precision p-adic field F, plus the explicit map. | Pauli's unit group algorithm **[Pau06]**. |
| `UnitGroupGenerators(R)` | Generators for the unit group of a fixed precision p-adic ring R. | Pauli's unit group algorithm **[Pau06]**. |
| `UnitGroupGenerators(F)` | Generators for the multiplicative group of a fixed precision p-adic field F. | Pauli's unit group algorithm **[Pau06]**. |
| `pSelmerGroup(p, F)` | The p-Selmer group F*/F*^p of an l-adic field F as an abstract group, with the map F* → abstract group. | — |

### 47.14.2 Norm Group

Given p-adic fields F/k, the norm group of F in k is the image of N_{F/k} : F* → k*. Functions take the map returned by `UnitGroup` as input, encoding the multiplicative group as a finitely generated abelian group.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `NormGroup(R, m)` | Image of the norm map N_{R/S} as a subgroup of the abstract unit group of S, where m encodes the unit group of S (as returned by `UnitGroup`). Also returns the subgroup embedding map. | Local class field theory norm computation. |
| `NormEquation(R, m, b)` | For p-adic ring R over S, unit group map m of S, and b ∈ S: attempt to find a ∈ R with N(a) = b. Returns a as a second value if it exists. | — |
| `NormEquation(m1, m2, G)` | Given p-adic rings R and S with unit group maps m1 : U_R → R and m2 : U_S → S and a subgroup G < U_S: compute the preimage of G under the norm map on unit groups. | — |
| `Norm(m1, m2, G)` | Given p-adic rings R and S with unit group maps m1 : U_R → R and m2 : U_S → S and a subgroup G < U_R: compute the image of G under the norm map on unit groups. | — |
| `NormKernel(m1, m2)` | Given p-adic rings R and S with unit group maps m1 and m2: compute the kernel of the norm map from U_R to U_S as a subgroup of U_R. | — |

### 47.14.3 Class Fields

Abelian extensions are parameterized by their norm groups. Pauli **[Pau06]** gives explicit algorithms to recover defining equations from a norm group.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `ClassField(m, G)` | For p-adic field S with multiplicative group U_S encoded by map m : U_S → S and a suitable subgroup G < U_S: compute for each cyclic factor of U_S/G an explicit defining equation for the corresponding class field. | Explicit local class field theory, **[Pau06]**. |
| `NormGroupDiscriminant(m, G)` | For p-adic field S, map m, and suitable subgroup G: compute the valuation of the discriminant of the extension parameterized by G without constructing explicit equations. | Explicit local class field theory, **[Pau06]**. |

## 47.15 Extensions

By a classical theorem, p-adic fields admit only finitely many extensions of bounded degree. Pauli's thesis **[Pau01a]** developed explicit methods to enumerate all extensions.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `AllExtensions(R, n)` | All extensions of degree n of the p-adic ring or field R as explicit defining equations. Optional parameters: `E` (ramification index, 0 = no restriction); `F` (inertia degree, 0 = no restriction); `D` (valuation of the discriminant, 0 = no restriction); `j` (discriminant valuation via formula D = d + j − 1, where d is the degree of R; default −1); `Galois` (if true, restrict to normal extensions only). | Enumeration of local extensions, **[Pau01a]**. |
| `NumberOfExtensions(R, n)` | The number of degree-n extensions of R (without constructing them). Same optional parameters as `AllExtensions`. | Enumeration of local extensions, **[Pau01a]**. |
| `OreConditions(R, n, j)` | For p-adic ring or field R and positive integers n and j, test whether there exists an extension of R of degree n with discriminant valuation n + j − 1. | Ore's theorem / local extension theory. |
