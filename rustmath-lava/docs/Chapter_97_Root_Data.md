# Chapter 97 — Root Data

**Handbook part:** XIII — Lie Theory
**Handbook pages:** 2853–2900 (PDF pages 2982–3033)

---

## Scope and overview

Chapter 97 describes Magma's functions for computing with (extended) root data, the fundamental combinatorial objects underlying Lie algebras (Chapter 100) and groups of Lie type (Chapter 103). A **split root datum** R = (X, Φ, Y, Φ★) consists of two free Z-modules X and Y with a perfect pairing, together with finite sets of roots Φ ⊆ X and coroots Φ★ ⊆ Y closed under the respective reflections. The description of split reduced root data follows **[Dem65]** and **[Car93]** (with reflections acting on the right, as is Magma's convention); nonreduced root data follow **[Bou68]**; and extended root data follow **[Sat71]**, **[Sch69]**, and **[Hal05]**.

An **extended root datum** augments a split root datum with a permutation group Γ acting compatibly on X and Y. This captures the notion of a twisted or quasi-split algebraic group: the Γ-orbits on roots classify into positive, negative and zero orbits; the zero-orbit submodule X₀ gives the anisotropic subdatum; and the quotient X̄ = X/X₀ carries the **relative root system**. The twisted Cartan name ᵐXₙ,ₑ encodes the split Cartan name Xₙ, the index m of the kernel of [Γ] in Γ, and the relative rank e.

The chapter covers eight main topics: constructing root data (dense and sparse); operations and scalar attributes; structural properties; roots, coroots, weights and their reflections; building new root data from old (subdata, sums, dual, twisting); morphisms; Lie-algebra structure constants; and linkage to related structures (root systems, Coxeter groups, Lie algebras, groups of Lie type).

**Sparse root data** (type `RootDtmSprs`, a subcategory of `RootDtm`) use a compact internal representation that is less memory-expensive and faster to create. Sparse representation is restricted to classical types A, B, C, D with connected Coxeter diagram, and cannot be twisted; the algorithms are from **[CHM08]**.

## 97.1 Introduction

### 97.1.1 Reflections

Let X and Y be free Z-modules with bilinear pairing ⟨·,·⟩: X × Y → Z identifying Y with the dual of X. For nonzero α ∈ X and α★ ∈ Y the maps xsα = x − ⟨x, α★⟩α (on X) and ys★α = y − ⟨α, y⟩α★ (on Y) are **reflections** when ⟨α, α★⟩ = 2. Magma uses right actions throughout; functions for reflections as standalone objects appear in Chapter 99.

### 97.1.2 Definition of a Split Root Datum

R = (X, Φ, Y, Φ★) is a **split root datum** when: (1) each pair (α, α★) gives a reflection; (2) Φ is closed under every sα; (3) Φ★ is closed under every s★α. A root datum is **reduced** if α, β ∈ Φ with β a scalar multiple of α implies α = ±β.

### 97.1.3 Simple and Positive Roots

A **simple system** Δ ⊆ Φ is a basis for QΦ such that Φ = Φ⁺ ∪ Φ⁻ where Φ⁺ is the set of non-negative integer combinations of Δ and Φ⁻ = −Φ⁺. The **rank** is |Δ|; the datum is **semisimple** when rank = dimension. A reduced root datum is determined (up to the choice of bases for X and Y) by the matrices A (rows = simple roots) and B (rows = simple coroots); the Cartan matrix is C = ABᵀ.

### 97.1.4 The Coxeter Group

The group W generated by the simple reflections is a finite Coxeter group. The **Coxeter form** is a W-invariant bilinear form on X, normalised so that short roots in each irreducible component have length 1.

### 97.1.5 Nonreduced Root Data

A root α is **reduced** if 2α ∉ Φ, and **divisible** if ½α ∈ Φ. A nonreduced irreducible root datum of rank n has indivisible subsystem of type Bₙ and Cartan type BCₙ. The Cartan and Coxeter matrix/diagram/group are the same for R and its indivisible subsystem; the set of nonreduced fundamental roots must be specified explicitly when constructing such data.

### 97.1.6 Isogeny of Split Reduced Root Data

Two root data with isomorphic Dynkin diagrams are **Cartan equivalent**. Within a Cartan equivalence class the isomorphism class is determined by the position of X between the root lattice ZΦ and the weight lattice Λ, i.e. by the **isogeny group** X/ZΦ inside the **fundamental group** Λ/ZΦ. The fundamental groups of the irreducible Cartan types are: Aₙ: Z/(n+1); Bₙ, Cₙ, E₇: Z/2; Dₙ: Z/4 (n odd) or Z/2 × Z/2 (n even); E₆: Z/3; E₈, F₄, G₂: trivial. X = ZΦ is **adjoint**; X = Λ is **simply connected**. The **coisogeny group** is Y/ZΦ★.

### 97.1.7 Extended Root Data

An **extended root datum** pairs a split root datum R with a permutation group Γ acting on X and Y compatibly with the pairing. Each Γ-orbit on Φ is positive, negative, or zero (its root-sum is zero). The anisotropic subdatum R₀ = (X₀, Φ₀, Y₀, Φ★₀) lives inside X₀ = {χ ∈ X | Σ_{γ∈Γ} χγ = 0}. The relative root system Φ̄ lives in X̄ = X/X₀. The [Γ]-action on Δ is via Dynkin diagram symmetries; orbits not in X₀ are **distinguished**. The datum is **inner** if [Γ] is trivial, **outer** otherwise, and **twisted** if Γ acts non-trivially. The twisted Cartan name ᵐXₙ,ₑ encodes the split type Xₙ, the index m, and the relative rank e.

## 97.2 Constructing Root Data

Several optional parameters are shared by all construction functions:

- **Isogeny** (default `"Ad"`): specifies the isomorphism class within the Cartan equivalence class. Accepts `"Ad"` (adjoint), `"SC"` (simply connected), an integer (size of the isogeny subgroup), or an injection of an abelian group into the fundamental group. For compound types, a list of per-component values is accepted.
- **Signs** (default `1`): a sequence of ±1 of length `NumExtraspecialPairs(R)` fixing the extraspecial signs (see Section 97.8), or ±1 for a constant sequence.
- **Twist** (default `1`): defines the Γ-action for extended root data. Accepts: an integer (order of Γ); `<D, i>` (set D of distinguished orbits plus diagram-symmetry order i); `<Γ, ims>` (group plus permutation images of simple or all roots); `<Γ, imsR, imsC>` (group plus matrices acting on root/coroot spaces); or a homomorphism Γ → Sym(2N).
- **Nonreduced** (default `{}`): set of indices of nonreduced simple roots (cannot be combined with Twist).

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `RootDatum(N)` | Root datum with Cartan name given by string N (see Section 95.6). Accepts "Tn" toral components in N (for input only). Errors if the corresponding Coxeter group is infinite affine. Params: `Isogeny`, `Signs`, `Twist`. | Cartan-matrix construction from name; **[Dem65, Car93]**. |
| `RootDatum(C)` | Semisimple root datum with crystallographic Cartan matrix C. Errors if Coxeter group is infinite. Params: `Isogeny`, `Signs`, `Twist`, `Nonreduced`. | — |
| `RootDatum(D)` | Semisimple root datum with Dynkin digraph D. Errors if Coxeter group is infinite. Params: `Isogeny`, `Signs`, `Twist`, `Nonreduced`. | — |
| `RootDatum(A, B)` | Root datum with simple roots as rows of A and simple coroots as rows of B. Requires: A and B integral with same number of rows and columns; number of columns ≥ number of rows; ABᵀ is the Cartan matrix of a finite Coxeter group. Params: `Signs`, `Twist`, `Nonreduced`. | — |
| `IrreducibleRootDatum(X, n)` | The irreducible root datum with Cartan name Xn. Params: `Signs`, `Twist`. | — |
| `StandardRootDatum(X, n)` | The standard root datum with Cartan name Xn, with standard inner product equal to the Coxeter form up to a constant. Only available for classical types A, B, C, D. (Not semisimple for type An.) Params: `Signs`, `Twist`. | — |
| `ToralRootDatum(n)` | The toral root datum of dimension n (no roots or coroots). Param: `Twist`. | — |
| `TrivialRootDatum()` | The trivial root datum of dimension 0. | — |

*Worked examples: H97E1 (adjoint/SC irreducible data; non-irreducible isogeny as list; D6 with three index-2 isogeny classes via injections into Z/2×Z/2); H97E2 (extended root data: 2A5, 2D4, 3D4, 6D4 via integer, permutation, and orbit-set twists); H97E3 (nonsemisimple G2 from matrices A, B; nonreduced BC2×B2 from Coxeter matrix); H97E4 (IrreducibleRootDatum in a loop); H97E5 (toral root datum, twisted toral root datum).*

## 97.5 Roots, Coroots and Weights

Roots are stored as an indexed set {@ α₁, …, αN, αN₊₁, …, α₂N @} where α₁, …, αN are positive roots ordered by height and αN₊ᵢ = −αᵢ. Simple roots are α₁, …, αn (n = rank).

Many functions in this section accept an optional parameter **Basis** with values:
- `"Standard"` (default): standard basis for the (co)root space.
- `"Root"`: basis of simple (co)roots.
- `"Weight"`: basis of fundamental (co)weights.

## 97.6 Building Root Data

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `sub< R \| a >` | The root subdatum of R generated by the roots {αa₁, …, αaₖ} where a = {a₁, …, aₖ} is a set of integers. | — |
| `sub< R \| s >` | The root subdatum of R generated by the roots {αs₁, …, αsₖ} where s = [s₁, …, sₖ] is a sequence. The roots must be simple in the resulting subdatum (none may be a summand of another), otherwise an error is raised; the simple roots appear in the subdatum in the given order. | — |
| `R1 subset R2` | Returns true iff R1 is a subset of R2; if true, also returns an injection as a sequence of root indices. | — |
| `R1 + R2` / `DirectSum(R1, R2)` | The external direct sum of R1 and R2. The full (co)root space of the result is the direct sum of the full (co)root spaces of R1 and R2. | — |
| `R1 join R2` | The internal direct sum of R1 and R2. R1 and R2 must have the same full (co)root space (which will also be the result's full (co)root space) and disjoint (co)root spaces. | — |
| `DirectSumDecomposition(R)` / `IndecomposableSummands(R)` | Returns a sequence Q of irreducible root data, a root datum S which is the direct sum of Q, and an isogeny map φ: S → R. R must be semisimple. Note: a semisimple R need not be a direct sum of simple data, but is isogenous to one. | — |
| `Dual(R)` | The dual of R (swap roots and coroots); second return is the dual morphism R → Dual(R). | — |
| `SimplyConnectedVersion(R)` | The simply connected version of R. If R is semisimple, also returns the injection of the SC version into R. | — |
| `AdjointVersion(R)` | The adjoint version of R. If R is semisimple, also returns the projection R → adjoint version. | — |
| `IndivisibleSubdatum(R)` | The root datum consisting of all indivisible roots of R. | — |
| `Radical(R)` | The radical of R: the toral subdatum whose root (resp. coroot) space consists of vectors perpendicular to every coroot (resp. root). | — |
| `TwistedRootDatum(R)` | Create a twisted root datum from the (split) root datum R. The twist may be specified via the `Twist` parameter as: an integer (order of twist), a permutation (action on primitive roots), `<D, i>` (distinguished orbits D and diagram symmetry order i), `<Γ, Q>` (group and permutation images for its generators), or a homomorphism Γ → Sym(#roots). | — |
| `TwistedRootDatum(N)` | Create a twisted root datum from the semisimple root datum with Cartan name N. Same `Twist` parameter options. | — |
| `UntwistedRootDatum(R)` / `SplitRootDatum(R)` | The split (untwisted) version of the (twisted) root datum R. | — |

*Worked examples: H97E26 (sub with sequence and set constructors for A4; error when roots are not simple in subdatum); H97E27 (R1+R2 vs R1 join R2 for subdata of A1A1); H97E28 (DirectSumDecomposition for SC A4B5; non-decomposable A1A1 with non-standard isogeny; sum of two direct sum decompositions with toral/BC components); H97E29 (Dual giving C4 from B4; IndivisibleSubdatum of BC2 giving B2; Radical of standard A3); H97E30 (TwistedRootDatum for D4 via integer/permutation/orbit-set/group twists; for A4 and E6 via Γ with generators).*

## 97.7 Morphisms of Root Data

Morphisms are currently only defined for **split** root data. A morphism φ: R1 → R2 consists of Z-linear maps φX: X1 → X2 and φY: Y1 → Y2 with φX(Φ1) ⊆ Φ2 ∪ {0} and φY(α★) = φX(α)★. A **fractional morphism** uses Q-linear maps on the (co)root spaces. A **dual morphism** maps X1 → Y2 and Y1 → X2 (equivalent to a morphism into the dual of R2). A morphism also stores a sign for each simple root of R1; this affects homomorphisms of associated Lie algebras and groups of Lie type but not the root/coroot action.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `hom< R -> S \| phiX, phiY >` | Construct a (fractional) morphism R → S from linear maps or matrices phiX, phiY. | — |
| `hom< R -> S \| Q >` | Construct a (fractional) morphism R → S from a sequence Q of root images. Q has length 2N and entries in [0, …, 2M] (N, M the numbers of positive roots of R, S). R must be semisimple. | — |
| `Morphism(R, S, phiX, phiY)` | Construct a (fractional) morphism R → S from linear maps; same as `hom` but with optional params. Params: `SimpleSigns` (sequence of signs for simple roots, or ±1; default 1), `Check` (default true; if false, skips the check that maps send (co)roots to (co)roots). | — |
| `Morphism(R, S, Q)` | Construct a (fractional) morphism R → S from sequence of root images Q (length 2N, entries in [0, …, 2M]). R must be semisimple. Params: `SimpleSigns`, `Check`. | — |
| `DualMorphism(R, S, phiX, phiY)` | Construct a (fractional) dual morphism R → S from linear maps. Param: `Check` (default true). | — |
| `DualMorphism(R, S, Q)` | Construct a (fractional) dual morphism R → S from sequence of root images Q. R must be semisimple. Param: `Check` (default true). | — |
| `RootImages(phi)` | The indices of the root images of the (dual) (fractional) morphism φ. | — |
| `RootPermutation(phi)` | The indices of the root images of the automorphism φ. | — |
| `IsIsogeny(phi)` | Returns true iff the morphism φ is an isogeny (φY is surjective with finite kernel). | — |
| `IdentityMap(R)` | The identity morphism R → R. | — |
| `IdentityAutomorphism(R)` | The identity automorphism R → R. | — |

*Worked example: H97E31 (fractional morphism from standard A3 (GL4) to adjoint A3 (PGL4) via matrix computation; see also Section 103.11).*

## 97.8 Constants Associated with Root Data

The constants in this section are needed to define Lie algebras and groups of Lie type. The notation follows **[Car72]**, adapted for right actions as in **[CMT04]**.

An **extraspecial pair** (r, s) is one where r is minimal such that αr + αs = αt for some t > n (n = rank). These pairs determine the structure constants.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `ExtraspecialPairs(R)` | The sequence of extraspecial pairs [(rᵢ, sᵢ)]ᴺ⁻ⁿᵢ₌₁ where rᵢ is minimal such that αrᵢ + αsᵢ = αᵢ₊ₙ (see **[Car72, p. 58]**). | Definition from **[Car72]**. |
| `NumExtraspecialPairs(R)` | The number of extraspecial pairs of R. Does not actually compute the pairs; more efficient than `#ExtraspecialPairs(R)` when pairs are not yet computed. | — |
| `ExtraspecialPair(R, r)` | The extraspecial pair (s, t) for the rth root: s is minimal such that αs + αt = αr. | — |
| `ExtraspecialSigns(R)` | The sequence of extraspecial signs of R. | — |
| `LieConstant_p(R, r, s)` | The constant prs: the largest p such that αs − p·αr is a root. Same as `LeftStringLength(R, r, s)`. Requires αs ≠ ±αr. | **[Car72]** |
| `LieConstant_q(R, r, s)` | The constant qrs: the largest q such that αs + q·αr is a root. Same as `RightStringLength(R, r, s)`. Requires αs ≠ ±αr. | **[Car72]** |
| `CartanInteger(R, r, s)` | The Cartan integer ⟨αr, α★s⟩ for R. | — |
| `LieConstant_N(R, r, s)` | The Lie algebra structure constant Nrs for R. Requires αs ≠ ±αr. | **[Car72]** (right-action convention from **[CMT04]**) |
| `LieConstant_epsilon(R, r, s)` | The constant ϵrs = Sign(Nrs) for R. Requires αs ≠ ±αr. | **[Car72, CMT04]** |
| `LieConstant_M(R, r, s, i)` | The constant Mrsi = (1/i!) Ns₀r ··· Nsᵢ₋₁r where αsᵢ = i·αr + αs for R. Requires αs ≠ ±αr. | **[Car72, CMT04]** |
| `LieConstant_C(R, i, j, r, s)` | The Lie group structure constant Cᵢⱼrs for R. Requires αs ≠ ±αr and αr + αs ∈ Φ. | **[Car72, CMT04]** |
| `LieConstant_eta(R, r, s)` | The constant ηrs = (−1)^prs · (ϵr,s−pr ··· ϵr,s−r) / (ϵr,s−pr ··· ϵr,s+(q−p−1)r) for R. Requires αs ≠ ±αr. | **[CMT04]** |
| `StructureConstants(R)` | The Lie algebra structure constants for the reductive Lie algebra with root datum R, in the sparse format of Section 100.2. | **[Car72, CMT04]** |

*Worked example: H97E32 (verifying standard formulas in F4: Cartan matrix vs CartanInteger; LieConstant_p vs LeftString length; LieConstant_q vs RightString length; Cartan integer = prs − qrs; Nrs = ϵrs(prs + 1)).*
