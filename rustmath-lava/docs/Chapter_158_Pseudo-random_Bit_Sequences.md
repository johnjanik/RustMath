# Chapter 158 — Pseudo-random Bit Sequences

**Handbook part:** XXII — Cryptography
**Handbook pages:** 5275–5280 (PDF pages 5406–5415)

---

## Scope and overview

Magma provides some tools for the creation and analysis of pseudo-random bit sequences. The
universe of these sequences is generally **F₂**. However, some functions, such as
`BerlekampMassey`, may be applied to sequences defined over arbitrary finite fields.

The chapter covers four families of tools: **linear feedback shift registers** (LFSRs) —
sequence generation, stepping, and reconstruction of the connection polynomial via the
Berlekamp–Massey algorithm, plus the shrinking generator; **number-theoretic bit generators**
based on the RSA and Blum–Blum–Shub constructions (with helper functions to produce suitable
moduli); **correlation functions** (auto- and cross-correlation of binary sequences); and
**decimation** of binary sequences.

Note on cryptographic use: the moduli generated by Magma (RSA and Blum–Blum–Shub) are
explicitly **not** intended for real-world cryptographic applications, since Magma's method of
seeding may not be sufficiently random to meet cryptographic standards.

## 158.2 Linear Feedback Shift Registers

For a linear feedback shift register (LFSR) of length `L`, initial state `s₀,…,s_{L−1} ∈ F_q`,
and connection polynomial `C(D) = 1 + c₁D + c₂D² + … + c_L D^L` (also over `F_q`), the *j*-th
element of the sequence is computed as `s_j = −Σ_{i=1}^{L} cᵢ s_{j−i}` for `j ≥ L`.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `LFSRSequence(C, S, t)` | Computes the first `t` sequence elements of the LFSR with connection polynomial `C` and initial state the sequence `S` (so the LFSR length is the length of `S`). `C` must be at least degree 1, its coefficients must come from the same finite field as the universe of `S`, and its constant coefficient must be 1. `S` must have at least as many terms as the degree of `C`. | Direct LFSR recurrence `s_j = −Σ cᵢ s_{j−i}`. |
| `LFSRStep(C, S)` | Computes the next state of the LFSR having connection polynomial `C` and current state `S` (the LFSR length is the length of `S`). Same constraints on `C` and `S` as `LFSRSequence`. | Single application of the LFSR recurrence. |
| `BerlekampMassey(S)` / `ConnectionPolynomial(S)` / `CharacteristicPolynomial(S)` | Given a sequence `S` of elements from `F_q`, returns the connection polynomial `C(D)` and the length `L` of an LFSR that generates `S`. Note that `BerlekampMassey` may return a singular LFSR (i.e. deg `C(D)` less than `L`); one must therefore use the first `L` elements of `S` to regenerate the sequence. | **Berlekamp–Massey algorithm**. |
| `ShrinkingGenerator(C1, S1, C2, S2, t)` | Outputs a sequence of `t` bits from the shrinking generator having connection polynomials `C₁` and `C₂` and initial state sequences `S₁` and `S₂` (so the LFSR lengths are the lengths of `S₁` and `S₂`). Bits are elements of **F₂**. Polynomial coefficients and sequence elements must be from **F₂**; the connection polynomials must have degree at least 1 with trailing coefficient 1; each initial state must have at least as many elements as the degree of the corresponding connection polynomial. | Shrinking generator combining two LFSRs. |

*Worked examples: H158E1 (create a sequence, recover its connection polynomial and length via `BerlekampMassey`, then regenerate from the first `L` elements with `LFSRSequence`).*

## 158.3 Number Theoretic Bit Generators

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `RandomSequenceRSA(b, t)` | Generates a sequence of `t` bits using the RSA pseudo-random bit generator with an RSA modulus of approximately `b` bits in length. The modulus `n` is computed by finding (pseudo-)random primes with `RandomPrime`. If `gcd(φ(n), 3)` is 1, the exponent 3 is used; otherwise a (pseudo-)random exponent `e` is chosen with `gcd(φ(n), e) = 1`. The seed is chosen as a (pseudo-)random number modulo `n`. Bits are elements of **F₂**. | RSA pseudo-random bit generator. |
| `RandomSequenceRSA(n, e, s, t)` | Generates a sequence of `t` bits using the RSA pseudo-random bit generator with modulus `n`, exponent `e`, and seed value `s`. Bits are elements of **F₂**. `n` must be larger than 1. | RSA pseudo-random bit generator. |
| `RSAModulus(b)` | Returns an RSA modulus `n` of `b` bits in length, and an exponent `e` such that `Gcd(EulerPhi(n), e) = 1`. The values can be used with `RandomSequenceRSA`. `b` must be at least 16. *Warning:* not for real-world cryptographic use. | Random-prime construction of an RSA modulus. |
| `RSAModulus(b, e)` | Returns an RSA modulus `n` of `b` bits in length such that `Gcd(EulerPhi(n), e) = 1`, for use with the supplied exponent `e` and `RandomSequenceRSA`. `b` must be at least 16; `e` must be odd and in the range `1 < e < 2^b`. *Warning:* not for real-world cryptographic use. | Random-prime construction with fixed exponent. |
| `RandomSequenceBlumBlumShub(b, t)` / `BlumBlumShub(b, t)` | Generates a sequence of `t` bits using the Blum–Blum–Shub pseudo-random bit generator with a modulus of approximately `b` bits in length. The modulus `n` is computed by finding (pseudo-)random primes with `RandomPrime` (with the condition that the primes are congruent to 3 mod 4). The seed is a (pseudo-)random number modulo `n`. Bits are elements of **F₂**. `b` must be at least 16. | Blum–Blum–Shub generator (primes ≡ 3 mod 4). |
| `RandomSequenceBlumBlumShub(n, s, t)` / `BlumBlumShub(n, s, t)` | Generates a sequence of `t` bits using the Blum–Blum–Shub pseudo-random bit generator with modulus `n` and seed value `s`. Bits are elements of **F₂**. `n` must be larger than 1 and `gcd(s, n)` must be 1. | Blum–Blum–Shub generator. |
| `BBSModulus(b)` / `BlumBlumShubModulus(b)` | Returns a Blum–Blum–Shub modulus `b` bits in length, for use with `RandomSequenceBlumBlumShub`. `b` must be at least 16. *Warning:* not for real-world cryptographic use. | Random-prime construction of a Blum–Blum–Shub modulus. |

*Worked examples: H158E2 (count the 1's in a sequence of 1000 bits from a 100-bit RSA modulus via `RandomSequenceRSA`).*

## 158.4 Correlation Functions

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `AutoCorrelation(S, t)` | Computes the autocorrelation of a sequence `S` (universe **F₂**), defined as `C(t) = Σ_{i=1}^{L} (−1)^{S[i]+S[i+t]}`, where `L` is the length of the sequence and the values of `S[i+t]` wrap around to the beginning when `i+t > L`. | Direct evaluation of the autocorrelation sum with wrap-around. |
| `CrossCorrelation(S1, S2, t)` | Computes the crosscorrelation of two binary sequences `S₁` and `S₂` (each with universe **F₂**, and the same length `L`), defined as `C(t) = Σ_{i=1}^{L} (−1)^{S₁[i]+S₂[i+t]}`, with `S₂[i+t]` wrapping around to the beginning when `i+t > L`. | Direct evaluation of the crosscorrelation sum with wrap-around. |

*Worked examples: H158E3 (autocorrelation of a maximal-period LFSR sequence built from a primitive polynomial over GF(2), illustrating the nice autocorrelation property).*

## 158.5 Decimation

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Decimation(S, f, d)` | Given a binary sequence `S` and integers `f` and `d`, returns the decimation of `S`: the sequence containing elements `S[f], S[f+d], S[f+2d], …` where the indices in `S` are interpreted with wrap-around as integers between 1 and `#S`. | Index sampling with stride `d`, offset `f`, wrap-around. |
| `Decimation(S, f, d, t)` | Decimation of `S` returning a new sequence containing the first `t` elements of `S[f], S[f+d], S[f+2d], …`, indices interpreted with wrap-around between 1 and `#S`. | As above, truncated to `t` elements. |

*Worked examples: H158E4 (over GF(7): build a primitive polynomial, scale so the trailing coefficient is 1, generate an LFSR sequence of length 7²−1, decimate by `d` with `gcd(d, 48) = 1`, recover a primitive polynomial via `BerlekampMassey` and confirm with `IsPrimitive`).*

| Decimation (strided index sampling) | `Decimation` |
