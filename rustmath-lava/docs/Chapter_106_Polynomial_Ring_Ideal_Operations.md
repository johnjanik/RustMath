**Handbook part:** XIV — Commutative Algebra
**Handbook pages:** 3225–3269 (PDF pages 3356–3403)

## Scope and overview

Chapter 106 describes Magma's functionality for ideals over multivariate polynomial rings. Most significant operations construct or utilise a Gröbner basis; the monomial ordering attached to the polynomial ring heavily influences speed and memory usage. For ring creation with non-default orderings and for Gröbner basis computation itself (including the powerful `EasyIdeal`/`EasyBasis` intrinsics), see Chapter 105. The default order is lexicographic — a total elimination order well-suited to zero-dimensional systems but tending to produce large bases. For homogeneous ideals with standard weighting the grevlex order is usually optimal; for non-standard weighting, weighted grevlex.

The chapter covers the following broad areas of commutative algebra functionality:

- **Simple ideal arithmetic** — sums, products, powers, and affine-algebra quotients (no Gröbner basis required).
- **Core operations** — colon ideals, saturations, intersection, leading-monomial ideals, Rees ideals, regular sequences.
- **Predicates and membership** — equality, containment, primality, radicality, zero-dimensionality, Jacobian ideals.
- **Varieties** — computing and counting solutions of zero-dimensional systems (and finite-field systems) over exact or approximate fields.
- **Multiplicities** — Milnor number and Tjurina number at the origin of a hypersurface singularity.
- **Elimination** — elimination ideals, univariate generators, relation ideals, variable extension, homogenisation, extension/contraction.
- **Dimension** — Krull dimension via maximally independent sets.
- **Radical and decomposition** — radical, primary decomposition, radical/probabilistic-radical decomposition, minimal decomposition, triangular decomposition, equidimensional decomposition.
- **Normalisation** — Noether normalisation and integral closure (normalisation) of radical ideals.
- **Hilbert series and polynomial** — Hilbert series, numerator, denominator, and polynomial for homogeneous ideals.
- **Syzygies** — syzygy matrix of a polynomial sequence.
- **Maps between rings** — kernel, image membership, surjectivity, extension, implicitisation.
- **Symmetric polynomials** — elementary symmetric polynomials and symmetric decomposition.
- **Module/algebra generators** — minimal algebra generators and homogeneous module membership tests used in invariant theory.

Related chapters: Chapter 24 (multivariate polynomial rings), Chapter 105 (Gröbner bases), Chapter 40 (algebraically closed fields), Chapters 108–110 (affine algebras, modules over affine algebras, invariant rings).

## 106.3 First Operations on Ideals

In the polynomial ring P, the ring P itself is a valid ideal (the ideal containing 1). The following subsections give the basic arithmetic, commutative-algebra operations, predicates, and element-membership tests.

### 106.3.1 Simple Ideal Constructions

The following constructions involve no Gröbner basis computation.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `I + J` | Sum of ideals I and J (same ring P): ideal generated by the generators of both. | Direct; no Gröbner basis. |
| `I * J` | Product of ideals I and J: ideal generated by all pairwise products of generators. | Direct; no Gröbner basis. |
| `I ^ k` | k-th power of ideal I. | Direct; no Gröbner basis. |
| `I / J` | For I, J ideals of P over a field with J ⊂ I: the affine algebra I/J. | Direct quotient construction. |

### 106.3.2 Basic Commutative Algebra Operations

The standard algorithms are as in Chapter 1.8 of **[GP02]** unless otherwise stated.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `QuotientDimension(I)` | Dimension of P/I as a K-vector space. Returns `Infinity` if I is not of Krull dimension 0. Distinct from `Dimension` (which returns Krull dimension). | Gröbner basis; standard **[GP02 §1.8]**. |
| `ColonIdeal(I, J)` / `IdealQuotient(I, J)` | Colon ideal I : J — all f ∈ P such that f·g ∈ I for all g ∈ J. | Gröbner basis; standard **[GP02 §1.8]**. |
| `ColonIdeal(I, f)` / `IdealQuotient(I, f)` | Saturation I : f^∞ — all g ∈ P such that f^i·g ∈ I for some i ≥ 1. Also returns an integer s ≥ 1 with I : f^∞ = I : f^s (only if a second return value is expected; omitting it greatly speeds up the computation). Computed by eliminating variable t from ⟨I, 1 − f·t⟩. | Elimination: **[GP02 §1.8]**. |
| `ColonIdealEquivalent(I, f)` / `Saturation(I, f)` | Returns the saturation C = I : f^∞ and a polynomial g of minimal degree such that C = I : ⟨g⟩; irreducible factors of g are a subset of those of f. | Gröbner + factorisation. |
| `Saturation(I, J)` | Saturation I : J^∞ = {f ∈ P : ∃n > 0, f^n J ⊆ I}. | Gröbner basis. |
| `Saturation(I)` | Saturation of I with respect to the irrelevant ideal (all elements of positive degree). | Gröbner basis. |
| `Generic(I)` | Returns the ambient polynomial ring P of I. | — |
| `LeadingMonomialIdeal(I)` | The leading-monomial ideal of I (ideal generated by all leading monomials). | — |
| `I meet J` | Intersection of ideals I and J in the same ring P. | Gröbner basis; standard **[GP02 §1.8]**. |
| `&meet S` | Intersection of all ideals in set or sequence S. | Iterated `meet`. |
| `RegularSequence(I)` · `Homogeneous BoolElt` (default: `true`) | Computes and returns a maximal regular sequence in I. If `Homogeneous` is true (default) and I is homogeneous w.r.t. variable weights, the sequence is also homogeneous. | Algorithm of Eisenbud–Sturmfels **[ES94]** (sparse regular sequences). |
| `ReesIdeal(P, I)` / `ReesIdeal(P, J, I)` / `ReesIdeal(R, I)` · `a RngMPolElt` (default: `1`) | Computes the Rees ideal K such that R1/K ≅ R(I)/⟨a-torsion⟩, where R(I) = R ⊕ I ⊕ I² ⊕ … is the Rees algebra. For the second/third signature R = P/J or an affine quotient algebra. Parameter `a` specifies a non-zero divisor (default 1); setting a ≠ 1 removes a-torsion, giving the coordinate ring of the maximal flat subscheme of the blow-up. | Rees algebra construction; see **[Har77 Ch. 2 §7]** for the geometric interpretation. |

*Worked example: H106E1 (ideal arithmetic in Q[x,y,z]: product, intersection, equality, `QuotientDimension`, `ColonIdeal`).*

### 106.3.3 Ideal Predicates

All predicates involving equality or containment require a Gröbner basis for one or both ideals.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `I eq J` | True iff I = J (same ring P). | Gröbner basis for each ideal. |
| `I ne J` | True iff I ≠ J. | Gröbner basis for each ideal. |
| `I notsubset J` | True iff I ⊄ J. | Gröbner basis for J. |
| `I subset J` | True iff I ⊆ J. | Gröbner basis for J. |
| `IsZero(I)` | True iff I is the zero ideal. | — |
| `IsProper(I)` | True iff I ≠ P (Gröbner basis does not contain 1). | Gröbner basis. |
| `IsHomogeneous(I)` | True iff I has a basis of homogeneous polynomials (w.r.t. variable weights). Checks current basis first; if not Gröbner, checks an easy Gröbner basis. | Homogeneity check. |
| `IsPrincipal(I)` | True iff I is principal; if so, also returns a generator. True iff any Gröbner basis has a single element. | Gröbner basis. |
| `IsPrimary(I)` | True iff I is primary (ab ∈ I ⟹ a ∈ I or b^n ∈ I for some n ≥ 1). Computes or retrieves primary decomposition and checks it has one element. Same field restrictions as `PrimaryDecomposition`. | Via `PrimaryDecomposition`. |
| `IsPrime(I)` | True iff I is prime. Computes or uses stored primary decomposition. Same restrictions as `PrimaryDecomposition`. | Via `PrimaryDecomposition`. |
| `IsMaximal(I)` | True iff I is maximal. First checks zero-dimensionality; if zero-dimensional, checks primality. | `IsZeroDimensional` then `IsPrime`. |
| `IsRadical(I)` | True iff I = Radical(I). Computes or uses stored radical. Same restrictions as `Radical`. | Via `Radical`. |
| `IsZeroDimensional(I)` | True iff I is zero-dimensional (P/I has finite non-zero dimension as K-vector space). Note: the full ring P as an ideal has dimension −1 and is not zero-dimensional. | Gröbner basis / `Dimension`. |
| `HasGrevlexOrder(I)` | True iff the monomial order of I is grevlex. | — |

### 106.3.4 Element Operations with Ideals

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `f in I` | True iff polynomial f ∈ P lies in ideal I. Computes the normal form of f w.r.t. a Gröbner basis of I and checks for zero. | Normal-form reduction (Gröbner basis). |
| `f notin I` | True iff f ∉ I. As with `in`, uses normal-form computation. | Normal-form reduction. |
| `IsInRadical(f, I)` | True iff f is in the radical of I. Much faster in general than computing the full radical. | Algorithm of **[GP02 §1.8.6]**. |
| `JacobianIdeal(f)` | Returns the ideal generated by all first partial derivatives of polynomial f. | Direct differentiation. |

*Worked example: H106E2 (element operations in Q[x,y,z]: `NormalForm`, `in`, `IsInRadical`, `SPolynomial`).*

## 106.4 Computation of Varieties

"Variety" here means the finite solution set of a zero-dimensional ideal — equivalently, the set of points of a zero-dimensional affine scheme over a specified field extension. Functions also work for higher-dimensional ideals over finite fields (where the solution set is finite). Magma's algebraically closed fields (Chapter 40) may be used to obtain all solutions when no explicit splitting field is known.

The general approach: first compute a triangular or radical decomposition (Section 106.11), then successively find roots of univariate polynomials.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Variety(I)` / `Variety(I, L)` · `Digits RngIntElt` (default: `38`) | For a zero-dimensional ideal I of P over K: returns the variety as a sequence of n-tuples, one per solution. If a superfield L of K is given, the variety is computed over L. Over the free complex field, uses a special root-finding algorithm; `Digits` controls complex precision (see Chapter 25). | Triangular or radical decomposition, then univariate root-finding. |
| `VarietySequence(I)` / `VarietySequence(I, L)` · `Digits RngIntElt` (default: `38`) | As `Variety` but returns a sequence of sequences (instead of tuples); requires the order of P to be of lexicographic type. | Same as `Variety`. |
| `VarietySizeOverAlgebraicClosure(I)` | For a zero-dimensional ideal I over K: returns the size of the variety over the algebraic closure K′ of K, without explicitly computing the variety. Finds the prime radical decomposition and places each component in normal position. | Prime radical decomposition; counting argument. Much faster than computing the full variety. |

*Worked example: H106E3 (ideal in GF(27)[x,y]; `Variety`, `VarietySizeOverAlgebraicClosure`).*

## 106.6 Elimination

Elimination of variables is accomplished by computing a Gröbner basis with respect to a suitable elimination order. All functions in this section may be applied to ideals over general Euclidean rings, not just over fields.

### 106.6.1 Construction of Elimination Ideals

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `EliminationIdeal(I, k: -)` | k-th elimination ideal Iₖ = I ∩ R[xₖ₊₁,…,xₙ] (all polynomials with the first k variables eliminated). If k = n, returns I ∩ R. If R is a field, this is P or the zero ideal. If R is not a field, returns the ideal generated by the normalised smallest element in I∩R. Parameters are as for `Groebner`; setting `Al := "Direct"` can give much better performance. | Gröbner basis with elimination order. If a lex Gröbner basis is already stored, elimination ideals can be read off directly. |
| `EliminationIdeal(I, S)` (S a set of integers or variables) | Elimination ideal IU = I ∩ R[U], where U is the subset of variables specified by S (integer indices or variable elements of P). S = ∅ is equivalent to `EliminationIdeal(I, n)`. | Gröbner basis with elimination order; see **[AL94 Ex. 4.3.8]** for an example over Z[√−5]. |

*Worked example: H106E5 (elimination over Z[√−5] embedded in Z[x,y,S]/(S²+5); `EliminationIdeal` with variable sets).*

### 106.6.2 Univariate Elimination Ideal Generators

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `UnivariateEliminationIdealGenerator(I, i)` | For a zero-dimensional ideal I of K[x₁,…,xₙ] and 1 ≤ i ≤ n: the unique monic generator of I ∩ K[xᵢ]. | Lexicographic Gröbner basis + extraction. |
| `UnivariateEliminationIdealGenerators(I)` | For a zero-dimensional ideal I of K[x₁,…,xₙ]: the sequence of n monic generators, one per variable xᵢ. | As above for all i. |

*Worked example: H106E6 (neural-network ideal in Q[x,y,z]; `UnivariateEliminationIdealGenerator`, `EliminationIdeal`). H106E7 (function `ZRadical` using `UnivariateEliminationIdealGenerators` to compute radical of zero-dimensional ideal; see [BW93 p. 345]).*

### 106.6.3 Relation Ideals

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `RelationIdeal(Q)` / `RelationIdeal(Q, T)` | For a sequence Q of k polynomials in P over S: the relation ideal U ⊆ S[y₁,…,yₖ] of all algebraic relations r with r(Q[1],…,Q[k]) = 0. If T (a polynomial ring of rank k) is given, U is returned as an ideal of T. | Introduces k new variables yᵢ and relations yᵢ − Q[i], then eliminates the original xᵢ variables — image of an affine polynomial map. |

*Worked example: H106E8 (ideal I = ⟨1⟩ in GF(2)[x,y,z]; using `RelationIdeal` to express 1 as an algebraic combination of generators).*

## 106.9 Extension and Contraction of Ideals

See **[BW93 pp. 54–58 and 388–397]** for definitions and theory.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Extension(I, U)` | For ideal I of P = K[x₁,…,xₙ] (K a field) and sequence U = [u₁,…,uₖ] of variable indices: constructs the ring-of-quotients extension Q = K(xu₁,…,xuₖ)[remaining variables] and returns the ideal J of Q together with the map f : P → Q. ## 106.10 Dimension of Ideals

A subset U of variables {x₁,…,xₙ} is **independent modulo I** if I ∩ K[U] = ∅. The **dimension** of I is the maximum cardinality of an independent set modulo I, which equals the Krull dimension of P/I.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Dimension(I)` | For I an ideal of P over a field: returns the dimension d of I and a sorted sequence of d variable indices forming a maximally independent set modulo I. If I = P, dimension is −1 and the second return value is not set. | Algorithm of **[BW93 p. 449]**. |

## 106.11 Radical and Decomposition of Ideals

Currently all algorithms work only for ideals of polynomial rings over fields (Euclidean rings to be supported in the future). See **[BW93 Chapter 8]** for definitions and theory; the Magma implementations are based on the algorithms there.

### 106.11.1 Radical

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Radical(I)` | For I an ideal of P over a field: returns the radical R = {f ∈ P : f^n ∈ I for some n ≥ 1}. Works for any field over which polynomial factorisation is available. | Standard radical algorithm; works via `PrimaryDecomposition` internally or dedicated radical computation. |

*Worked example: H106E9 (radical of a non-zero-dimensional ideal in Q[x,y,z,t,u]; verification via `IsInRadical`).*

### 106.11.2 Primary Decomposition

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `PrimaryDecomposition(I)` | For I an ideal of P over a field: returns two parallel sequences Q (primary components) and P (associated primes) such that: (a) ideals of Q are primary; (b) their intersection is I; (c) P[i] = Radical(Q[i]) is prime; (d) Q is minimal (no redundant components, distinct associated primes); (e) P is always unique and Q is unique if I is zero-dimensional. Works for any field with polynomial factorisation; inseparable extensions handled by **[Ste05]**. | Algorithm of **[BW93 Ch. 8]** (based on Gröbner bases), with a triangular decomposition pre-step (since V2.4). Inseparable field extensions: **[Ste05]**. |
| `RadicalDecomposition(I)` | For I an ideal of P over a field: returns the prime decomposition of the radical of I as a sequence P of minimal prime ideals whose intersection is Radical(I). Equivalent to `PrimaryDecomposition(Radical(I))` but often much more efficient. | As `PrimaryDecomposition` but applied to the radical; may avoid computing primary components. |
| `ProbableRadicalDecomposition(I)` | As `RadicalDecomposition` but probabilistic: the returned ideals may not be prime. Much faster in practice. | Probabilistic variant of radical decomposition. |
| `MinimalDecomposition(S)` | For a set/sequence S of ideals with I = ∩J∈S J: returns a minimal subset M ⊆ S with the same intersection (no redundant ideals). | Redundancy elimination by containment checks. |
| `SetVerbose("Decomposition", v)` | Sets verbose level v (legal values: `true`, `false`, 0, 1, or 2) for the primary/radical decomposition algorithms. | — |

*Worked example: H106E10 (primary decomposition of the Cyclic-5 symmetric ideal in Q[x,y,z,t,u]; examination of embedded primary components and comparison with `RadicalDecomposition`).*

### 106.11.3 Triangular Decomposition

A zero-dimensional ideal T of K[x₁,…,xₙ] is **triangular** if its Gröbner basis has length n and the initial term of the i-th polynomial is of the form xᵢᵉⁱ. Any radical zero-dimensional ideal decomposes as an intersection of triangular ideals. Since V2.4, Magma's primary decomposition first computes a triangular decomposition then decomposes each triangular component, since triangular decomposition is typically fast. See **[Laz92]** for theory.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `TriangularDecomposition(I)` | For I a zero-dimensional ideal of P over a field with lexicographic order: returns a sequence Q of ideals whose intersection equals I, where each radical J ∈ Q is triangular. Second return value indicates whether I is proven radical (if so, all entries are triangular). | Algorithm of **[Laz92]**. |

*Worked example: H106E11 (Cyclic-5 roots ideal; `TriangularDecomposition` vs `PrimaryDecomposition` — 9 triangular components vs 20 prime components).*

### 106.11.4 Equidimensional Decomposition

Assumes I has no embedded associated primes (e.g., when I is radical). An equidimensional decomposition is the set of intersections of all primary components of I associated to primes of the same dimension.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `EquidimensionalPart(I)` | Returns the highest-dimensional equidimensional component of I. | For homogeneous I: module-theoretic method via Noether normalisation (kernel of M → double dual over linear Noether normalisation S). General case: **[GP02]**. |
| `EquidimensionalDecomposition(I)` | Returns the full equidimensional decomposition as a sequence of ideals, one per dimension. | As `EquidimensionalPart`; module method for homogeneous I, **[GP02]** in general. |
| `FineEquidimensionalDecomposition(I)` | Finer decomposition: each equidimensional component is further split so that each factor has a single set of variables constituting a maximally independent set of all its primary components. Returns a sequence of pairs (factor, variable index set). | Same base algorithm; additional splitting for unique maximally independent sets. |

*Worked example: H106E12 (three-component radical ideal in Q[x,y,z]; `RadicalDecomposition` vs `EquidimensionalDecomposition` — timing comparison).*

## 106.12 Normalisation and Noether Normalisation

For I an ideal of P = K[x₁,…,xₙ] with K a field and dim(I) = d: a **Noether normalisation** is a set of d polynomials f₁,…,fₐ ∈ P, algebraically independent over K, with K[f₁,…,fₐ] ∩ I = 0 and K[f₁,…,fₐ] → P/I an integral extension (over infinite K, the fᵢ can be linear).

**Normalisation** (integral closure): if I is radical, the normalisation of P/I in its total ring of fractions. Specified as pairs (Iᵢ, φᵢ) where Iᵢ is a prime ideal with polynomial ring Gᵢ and φᵢ : P → Gᵢ; the product ∏ Gᵢ/Iᵢ with the maps φᵢ is the integral closure.

### 106.12.1 Noether Normalisation

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `NoetherNormalisation(I)` / `NoetherNormalization(I)` | Computes a Noether normalisation of I using linear combinations of variables. Guaranteed to work in characteristic 0; may fail in small characteristic. Returns: (1) the sequence [f₁,…,fₐ]; (2) an automorphism h : P → P (linear change of variables) mapping the fᵢ to the last d variables of P; (3) the inverse of h. | Algorithm of **[GP02]** with a simpler test for homogeneous I (considering subsets of variables before general linear combinations). |

*Worked example: H106E13 (Q[x,y] ideal; `NoetherNormalisation` showing x + y normalises and integrality of x over h(I)).*

### 106.12.2 Normalisation

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Normalisation(I)` / `Normalization(I)` · `UseFF BoolElt` (default: `true`) · `FFMin BoolElt` (default: `true`) · `UseMax BoolElt` (default: `false`) | Computes the normalisation (integral closure) of the radical ideal I. Returns a list of pairs (ideal Iᵢ of generic ring Gᵢ, homomorphism φᵢ : P → Gᵢ). I must be radical; base field K must be perfect. `UseFF` (default true): if rank(P) = 2, uses Magma's function-field machinery (much faster). `FFMin` (default true, when `UseFF` is true): uses a filtration by Riemann–Roch spaces to minimise the number of generators (slower but usually faster than the general algorithm, much nicer output; set false to skip minimisation). `UseMax` (default false, only affects general algorithm): assumes I ⊆ ⟨x₁,…,xₙ⟩ and P/I is locally normal away from this maximal ideal — speeds up the general algorithm when the variety is singular only at the origin. Incorrect if P/I is locally non-normal at other primes. | General algorithm: De Jong, as described in **[GP02]**. Function-field case: Riemann–Roch-based algorithm using Magma's function-field machinery. |

*Worked examples: H106E14 (curve singularity (x − y²)² − xy³ in Q[x,y]; comparison of `UseFF`, `FFMin:=false`, `UseFF:=false`, `UseMax:=true`; singular affine form of modular curve X₁(11)).*

## 106.13 Hilbert Series and Hilbert Polynomial

For a homogeneous ideal I of a graded polynomial ring P = K[x₁,…,xₙ], P/I is a graded vector space with graded components Vd. The **Hilbert series** is Hₚ/ᵢ(t) = Σ dim(Vd) tᵈ, a rational function in t. When all variable weights are 1, the **Hilbert polynomial** F(d) satisfies F(i) = [tⁱ] H(t) for all i ≥ k (the index of regularity).

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `HilbertSeries(I)` | For a homogeneous ideal I of P over a field: the Hilbert series Hₚ/ᵢ(t) as an element of Z(t). Note: equivalent to `HilbertSeries(QuotientModule(I))`; for the Hilbert series of I as a P-module, call `HilbertSeries(Submodule(I))`. | Algorithm of **[BS92]**. |
| `HilbertSeries(I, p)` | As above but returns the Hilbert series as a power series to precision p. | Algorithm of **[BS92]**. |
| `HilbertDenominator(I)` | The unreduced Hilbert denominator D = ∏ᵢ (1 − t^wᵢ), where wᵢ is the weight of the i-th variable (default 1). Returned as a univariate polynomial over Z. | Computed from variable weights. |
| `HilbertNumerator(I)` | The unreduced Hilbert numerator N = D × Hₚ/ᵢ(t), as a univariate polynomial over Z. Often more convenient for computation. | From Hilbert series and denominator. |
| `HilbertPolynomial(I)` | For a homogeneous ideal I with all variable weights 1: returns the Hilbert polynomial H(d) ∈ Q[d] and the index of regularity k (minimum k ≥ 0 such that H(d) agrees with the Hilbert function for all d ≥ k). | Derived from `HilbertSeries`. |

*Worked example: H106E15 (ideal of entries of X² for a 4×4 matrix ring; `HilbertSeries`, `HilbertPolynomial`, verification against power-series coefficients; see [BS92]).*

## 106.14 Syzygies

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `SyzygyMatrix(Q)` | For a sequence Q of k polynomials in P: returns the module of syzygies as an r×k matrix S whose rows span all v with Σ v[i]·Q[i] = 0. The base ring may be a field or a Euclidean ring. | Standard module Gröbner basis with a particular elimination order; see **[GP02 §2.5]**. |

*Worked example: H106E16 (syzygy matrix of [x+y, x−y, xz+yz] in Q[x,y,z]).*

## 106.15 Maps between Rings

For polynomial rings R = K₁[x₁,…,xₙ] and S = K₂[y₁,…,yₘ] and a ring homomorphism f : R → S:

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `PolyMapKernel(f)` | Returns the kernel of f as an ideal in R = {a ∈ R : f(a) = 0}. Computed as the relation ideal for the polynomials defining f; see `RelationIdeal`. | Elimination (as in `RelationIdeal`). |
| `IsInImage(f, p)` | For polynomial p ∈ S: returns whether p is in the image of f. | Algorithm of **[AL94 p. 82]**. |
| `IsSurjective(f)` | Returns whether f is surjective. Checks via `IsInImage` whether each codomain variable lies in the image. | Iterated `IsInImage`. |
| `Extension(phi, I)` | Extension of ideal I by φ (homomorphism from the generic ring of I): the ideal generated by the image of I under φ. | Direct application of φ to generators. |
| `Implicitization(phi)` | For polynomial map φ : Kⁿ → Kᵐ parametrising a variety V (as the image of φ): constructs the ideal of S corresponding to V. If V is not a true variety, returns its Zariski closure. | Algorithm of **[CLO96 p. 97]**: introduce variables, add relations, then eliminate. |

*Worked example: H106E17 (`Implicitization` of φ : Q[x,y] → Q[r,u,v,w], (x,y) ↦ (x⁴,x³y,xy³,y⁴); example from [AL94 Ex. 2.5.4]).*

## 106.16 Symmetric Polynomials

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `ElementarySymmetricPolynomial(P, k)` | For polynomial ring P of rank n and 1 ≤ k ≤ n: returns the k-th elementary symmetric polynomial of P. | Direct construction. |
| `IsSymmetric(f)` / `IsSymmetric(f, S)` | For polynomial f ∈ P of rank n: returns whether f is symmetric in all n variables. If true, also returns g in a new ring of rank n (or in the given ring S of rank n) such that f = g(e₁,…,eₙ), where eᵢ is the i-th elementary symmetric polynomial of P. | Decomposition in terms of elementary symmetric polynomials. |

*Worked example: H106E18 (symmetric polynomial in Q[a,b,c,d]; `IsSymmetric` over a function field F(a,b)).*

## 106.17 Functions for Polynomial Algebra and Module Generators

These functions work with collections of polynomials as generators for subalgebras or submodules of a polynomial ring. They are particularly used in invariant theory.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `MinimalAlgebraGenerators(L)` | For a set/sequence L = {f₁,…,fₖ} ⊆ K[x₁,…,xₙ]: returns a minimal generating set (as a sorted sequence drawn from L) for the subalgebra A = K[f₁,…,fₖ]. | Redundancy elimination by algebraic independence testing. |
| `HomogeneousModuleTest(P, S, F)` | For homogeneous polynomials P = [p₁,…,pₖ] and S = [s₁,…,sᵣ] in R, and F ∈ R: returns whether F lies in the A-module M = A[s₁,…,sᵣ] (where A = K[p₁,…,pₖ]). If true, also returns a sequence C = [c₁,…,cᵣ] with cᵢ ∈ K[t₁,…,tₖ] such that F = Σ cᵢ(p₁,…,pₖ)·sᵢ. Typical use: P = primary invariants, S = secondary invariants, F = arbitrary invariant. | Splits F into homogeneous components; for each degree d, constructs a K-basis for M^d and tests membership by linear algebra. |
| `HomogeneousModuleTest(P, S, L)` | As above but for a sequence L of l homogeneous elements all of the same degree d. Returns parallel sequences B (booleans) and V (coefficient sequences), one per element of L. More efficient than calling the single-element version repeatedly (one echelonisation suffices for the whole batch). | Batch version: single echelonisation of the degree-d basis of M, then linear algebra for all elements of L. |
| `HomogeneousModuleTestBasis(P, S, L)` | For homogeneous P, S (as above) and a sequence L of l homogeneous elements of the same degree d: returns a sequence I of integer indices such that the subsequence of L indexed by I extends any basis of the degree-d part of M = A[s₁,…,sᵣ] to a basis of U + V (U = M^d, V = K-span of L). Used to extend a minimal module generating set while ensuring minimality. | Echelonisation of M^d; extends to U + V by selecting linearly independent residues. |

*Worked examples: H106E19 (simple `HomogeneousModuleTest` in Q[x,y,z]; `HomogeneousModuleTestBasis` to determine extension basis). See also example HomogeneousModuleTest2 in Chapter 110 (invariant rings).*
