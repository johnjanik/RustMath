## Scope and overview

Chapter 101 covers Kac-Moody Lie algebras, an important class of infinite-dimensional Lie algebras that generalise the finite-dimensional semisimple Lie algebras of Chapter 100. The principal reference is Kac's monograph **[Kac90]**.

A **generalized Cartan matrix** is an integral matrix A = (a_ij)^n_{i,j=1} satisfying: a_ii = 2, a_ij < 0 for i ≠ j, and a_ij = 0 implies a_ji = 0. Every ordinary Cartan matrix is a generalized Cartan matrix. To any generalized Cartan matrix A one associates a Kac-Moody Lie algebra g(A), generated by 3n elements e_i, f_i, h_i (i = 1, …, n) subject to standard Serre-type relations including the Serre-Chevalley relations and the Serre relations (ad e_i)^{1−a_ij} e_j = 0 and (ad f_i)^{1−a_ij} f_j = 0 for i ≠ j.

Kac-Moody Lie algebras fall into three classes determined by the generalised Cartan matrix:

- **(a) Finite type:** there exists a positive integer vector θ with Aθ > 0. Then g(A) is finite-dimensional and reductive. These are handled in Chapter 100.
- **(b) Affine type:** there exists a positive integer vector δ with Aδ = 0. Then g(A) is infinite-dimensional but of polynomial growth. These are called **affine Lie algebras** and are the subject of Section 101.3.
- **(c) Indefinite type:** there exists a positive integer vector α with Aα < 0. Then g(A) is infinite-dimensional and of exponential growth. These are **not yet available** in Magma.

Affine Lie algebras admit an explicit construction via an underlying finite-dimensional Lie algebra g_0 and a central extension (see **[Kac90, Chapters 7, 8]**). If A is an affine Cartan matrix of type X̃_n, then

> g(A) ≅ g_0 ⊗ C[t, t⁻¹] ⊕ Cc ⊕ Cd

where g_0 is the finite Lie algebra of Cartan type X_n, C[t, t⁻¹] is the ring of Laurent polynomials, and c, d are formal central/derivation basis elements. Magma represents affine Lie algebras and their elements using the right-hand side of this isomorphism. Affine Lie algebras are of type `AlgKac`; their elements are of type `AlgKacElt`.

## 101.2 Generalized Cartan Matrices

Functions for testing whether a matrix is a generalised Cartan matrix and for classifying its Kac-Moody type.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `IsGeneralizedCartanMatrix(C)` | Returns `true` if the square integral matrix C is a generalized Cartan matrix (a_ii = 2, a_ij ≤ 0 for i ≠ j, a_ij = 0 ⇒ a_ji = 0), `false` otherwise. | Direct verification of the defining conditions. |
| `KacMoodyClass(C)` | For an **indecomposable** generalized Cartan matrix C: returns a string `"a"`, `"b"`, or `"c"` giving the Kac-Moody class (finite, affine, or indefinite, respectively), and a positive integral column vector v such that Cv is positive, zero, or negative (corresponding to θ, δ, α from the introduction). | Classification via the sign of Cv for a canonical positive integral vector v. |
| `KacMoodyClasses(C)` | For a **possibly decomposable** generalized Cartan matrix C: returns three sequences — (1) a sequence of strings `"a"`, `"b"`, `"c"` giving the class of each indecomposable component; (2) a positive integral vector v such that Cv is positive, zero, or negative on each component; (3) a sequence Q of integral sequences Q_i such that the i-th component is formed by taking the rows and columns with index j ∈ Q_i. | Decomposition into indecomposable blocks, then `KacMoodyClass` on each. |

*Worked examples: H101E1 (classification of an indecomposable type-c matrix and a decomposable B2 A~3 matrix via `KacMoodyClass` / `KacMoodyClasses` and `Submatrix`).*

## 101.3 Affine Kac-Moody Lie Algebras

The explicit construction of affine Lie algebras in Magma follows the loop-algebra-plus-central-extension model of **[Kac90, Chapters 7, 8]**. Given affine Cartan type X̃_n, the underlying finite Lie algebra g_0 is of type X_n; multiplication in g(A) is

> [t^k ⊗ x ⊕ λc ⊕ μd, t^{k'} ⊗ y ⊕ λ'c ⊕ μ'd] = (t^{k+k'} ⊗ [x, y] + μk't^{k'} ⊗ y − μ'kt^k ⊗ x) ⊕ kδ_{k,−k'}(x|y)c

where (x|y) is a fixed non-degenerate invariant symmetric bilinear form on g_0. The canonical generators (as in Section 101.1) are e_0 = t ⊗ E_0, f_0 = t⁻¹ ⊗ F_0, and e_i = 1 ⊗ E_i, f_i = 1 ⊗ F_i for i = 1, …, l, where l = rank of the Cartan matrix.

### 101.3.1 Constructing Affine Kac-Moody Lie Algebras

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `AffineLieAlgebra(N, F)` | Construct the affine Kac-Moody Lie algebra of Cartan type N (a string, e.g. `"A~3"`) over the field F. Returns an object of type `AlgKac`. See Section 95.6 for conventions on affine Cartan types. | Loop-algebra-plus-central-extension model **[Kac90]**. |
| `AffineLieAlgebra(C, F)` | Construct the affine Kac-Moody Lie algebra with affine Cartan matrix C over the field F. Returns an object of type `AlgKac`. | As above. |

*Worked examples: H101E2 (construction of the G~2 and A~2 affine Lie algebras using type string and Cartan matrix).*

### 101.3.3 Constructing Elements of Affine Kac-Moody Lie Algebras

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `L . i` | The i-th basis element of the finite-dimensional Lie algebra underlying L, viewed as an element of L. | — |
| `HasAttribute(L, "c")` / `HasAttribute(L, "d")` | Returns `true` and the basis element c or d of L, according to the second argument. | — |
| `elt< L \| <[<p1, y1>, …], λ, µ> >` | For a 3-tuple t where t[1] is a sequence of pairs in C[t, t⁻¹] × g_0, and t[2], t[3] are elements of the coefficient ring: constructs the element Σ_{(p,y) ∈ t[1]} p ⊗ y ⊕ t[2]·c ⊕ t[3]·d in L. | — |
