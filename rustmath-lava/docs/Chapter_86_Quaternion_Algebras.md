## Scope and overview

A quaternion algebra A over a field K is a central simple algebra of dimension four over K. When char(K) ≠ 2 it is generated by elements i, j satisfying i² = a, j² = b, ji = −ij with a, b ∈ K*; in characteristic 2 the relations become x² + x = a, y² = b, yx = (x+1)y. In Magma, quaternion algebras have the specialised type `AlgQuat`, a subtype of `AlgAss`.

Every quaternion algebra A over K not isomorphic to M₂(K) is a division algebra. Finding a zerodivisor in A is computationally equivalent to finding a K-rational point on a conic. Given a zerodivisor, Magma computes an explicit isomorphism A → M₂(K). For quaternion algebras over number fields, a prime place v is ramified if K_v does not split A; the set of ramified places is finite and of even cardinality, and any such set arises. One may compute the set of ramified places and construct an algebra given its ramification set.

The chapter covers algorithms analogous to those for number fields: computation of the ring of integers (maximal order), p-maximal orders, orders with given discriminant, ideal class enumeration, isomorphism testing of ideals and orders, basis reduction via the norm form, and the unit group. Over Q these functions are connected to Brandt modules and modular forms.

**Important type note.** Quaternion orders over Z or F_q[X] have type `AlgQuatOrd`; ideals have type `AlgQuatOrdIdl`. Over other number rings, orders have the general type `AlgAssVOrd` and ideals `AlgAssVOrdIdl`. Since the rationals have Magma type `FldRat` (not a subtype of `FldNum`), many functions require the user to create Q via `RationalsAsNumberField()` to access full number-field functionality.

The main references for this chapter are Vignéras [Vig80] and Kirschmer–Voight [KV10].

## 86.2 Creation of Quaternion Algebras

The general constructor builds a model with generators x, y and relations determined by a, b ∈ K*. Special constructors for Q allow a more general set of quadratic relations so that the default basis {1, i, j, k} may simultaneously be a basis for a maximal order.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `QuaternionAlgebra< K \| a, b >` | Creates the quaternion algebra A over field K with generators i, j satisfying i² = a, j² = b, ji = −ij (char ≠ 2) or ji = (i+1)j (char 2). The third generator is k = ij. K may be any Magma field type. | Standard structure-constant construction. |
| `AssignNames(~A, S)` | Given a quaternion algebra A and a sequence S of 3 strings, assigns the strings as names for the generators (basis elements other than 1). Called automatically by the bracket constructor `< >`. | — |
| `QuaternionAlgebra(N)` | Given a positive squarefree integer N, returns a rational quaternion algebra of discriminant N. Parameters: `Al` (`"TraceValues"` default for odd number of prime factors, computes a basis also spanning a maximal order; `"Random"` uses a faster probabilistic algorithm); `Optimized` (default `true`). | For odd-prime-factor count: trace-value algorithm yielding a maximal-order basis. Probabilistic variant otherwise. |
| `QuaternionAlgebra(N)` | Given a squarefree polynomial N ∈ F_q[x] for odd q, returns a quaternion algebra over F_q(x) of discriminant N. | — |
| `QuaternionAlgebra(I)` | Given an ideal I of a number field F with an even number of prime ideal factors, returns the quaternion algebra over F ramified exactly at the primes dividing I (uses radical of I). | `QuaternionAlgebra(I, S)` | Given an ideal I and a subset S of real places of F such that #prime-factors-of-I ≡ #S (mod 2), returns the algebra ramified exactly at primes dividing I and at real places in S. Parameter: `Optimized` (default `true`). | — |
| `QuaternionAlgebra(S)` | Given an even set S of non-complex places of a number field F, returns the quaternion algebra ramified exactly at S. Parameter: `Optimized` (default `true`). | — |

## 86.3 Creation of Quaternion Orders

An R-order in A is a subring O ⊆ A which is an R-submodule with O·K = A. Maximal orders are not unique: for x ∈ A not in the normalizer of O, x⁻¹Ox ≠ O is another maximal order.

Parameter: `IsBasis` (default `false`; if `true`, uses S directly as a basis). | Lattice closure under multiplication. |
| `QuaternionOrder(R, S)` / `Order(R, S)` | Given a ring R and a sequence S of 4 elements of a quaternion algebra over Q or F_q(X), returns the R-order with basis S. Parameter: `Check` (default `true`). | Direct basis specification. |

## 86.7 Predicates on Algebras

A quaternion algebra A over a number field F with [F:Q] = h is **definite** (totally definite) if F is totally real and A ⊗_Q R ≅ H^h; otherwise A is **indefinite**. Over F_q(X), A is definite if the place corresponding to the degree valuation is ramified.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `IsDefinite(A)` | True iff A over a number field, Q, or F_q(X) with q odd is (totally) definite. | Ramification at infinite places. |
| `IsIndefinite(A)` | True iff A is indefinite. | Complement of above. |

## 86.8 Recognition Functions

A quaternion algebra A over K is isomorphic to M₂(K) iff it has a zerodivisor ε ∈ A. Given ε, Magma exhibits the isomorphism; otherwise a zerodivisor is found by computing a point on a conic (see **[Vig80, Cor. I.2.4]**). There is also an algorithm to recognize whether an arbitrary associative algebra is a quaternion algebra.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `IsMatrixRing(A)` | True iff the quaternion algebra A with base field F ∈ {Q, F_q(X), number field} is isomorphic to M₂(F), i.e. has no ramified places. If `Isomorphism := true` (default `false`) and A ≅ M₂(F), also returns M₂(F) and the isomorphism A → M₂(F). | Zerodivisor search via point on conic **[Vig80, Cor. I.2.4]**. |
| `MatrixRing(A, eps)` / `MatrixAlgebra(A, eps)` | Given a quaternion algebra A and a zerodivisor ε ∈ A, returns M₂(F) and an isomorphism A → M₂(F). | Explicit isomorphism from zerodivisor. |
| `IsQuaternionAlgebra(B)` | True iff the associative algebra B is a quaternion algebra. If true, returns the associated quaternion algebra A in standard form and an algebra homomorphism B → A. | Algorithm 4.2.9 in **[Voi05]**. |
| `MatrixRepresentation(A)` / `MatrixRepresentation(R)` | For a quaternion algebra A over Q or a quaternion order R over Z: returns a 2×2 matrix representation of A defined over a quadratic extension. | Embedding into M₂ of a quadratic extension. |

*Worked examples: H86E14 (MatrixRing from a zerodivisor, minimal polynomials preserved); H86E15 (IsQuaternionAlgebra on scrambled bases, over GF(2), and on non-quaternion algebras).*

## 86.12 Ideal Theory of Orders

Right (or left) ideals of an R-order O fall into finitely many isomorphism classes. For an Eichler order S the algorithms from [KV10] are used.

- **Definite algebras:** a variation of Kneser's neighbouring method together with Eichler's mass formula (see **[Vig80, Chapter 5]** and **[DG88]**) constructs enough ideals to represent all ideal classes, followed by isomorphism testing (§86.14.3).
- **Indefinite algebras:** Eichler's theorem (**[Rei03, Th. 35.14]**) gives a bijection between ideal classes of the order and ideal classes of the base ring (so every ideal of an indefinite order over Z or F_q[X] is principal). Representatives are found via reduced norm conditions.

All orders in this section must be Eichler (which includes maximal orders).

## 86.13 Norm Spaces and Basis Reduction

For definite quaternion orders or ideals one can compute reduced bases and Gram matrices. Over Z or F_q[X] with q odd, Gram matrices can be made unique up to isomorphism and form the basis of isomorphism testing for ideals and orders.

| Intrinsic | Description | Algorithm |

| `GramMatrix(S)` / `GramMatrix(I)` | Gram matrix of the quaternion order S or ideal I over Z or F_q[X] w.r.t. the norm on the basis. | — |
| `ReducedGramMatrix(S)` (over Z) | Gram matrix of the corresponding definite lattice. Produces a unique normalized Minkowski-reduced Gram matrix for any definite quaternion ideal (forms the core of isomorphism testing). | Minkowski basis reduction. |
| `ReducedBasis(S)` (over Z) | A basis B for the definite quaternion order or ideal S, together with its Gram matrix G. The Gram matrix G is unique; the basis B is not. | Minkowski basis reduction. |
| `ReducedGramMatrix(S)` / `ReducedBasis(S)` (over F_q[X]) | Gram matrix and/or basis of order or ideal S over F_q[X] in dominant diagonal form. Gram matrix is unique only when A is definite and `Canonical := true`. Parameter: `Canonical` (default `false`). | Dominant diagonal form **[Ger03]**. |
| `ReducedBasis(O)` / `ReducedBasis(I)` (over number ring) | "Reduced" basis for order O or ideal I over a number ring. Definite algebra: LLL-reduced w.r.t. the norm form. Indefinite algebra: reduced w.r.t. a Minkowski-like embedding, see **[KV10, Section 4]**. | LLL / Minkowski-like embedding **[KV10]**. |
| `OptimizedRepresentation(O)` / `OptimisedRepresentation(O)` | For an order O in a quaternion algebra A over Q or a number field F: returns a new algebra A′ = ((a,b)/F) with a, b small w.r.t. O, and an isomorphism A → A′. | Small-coefficient search relative to O. |
| `OptimizedRepresentation(A)` / `OptimisedRepresentation(A)` | For a quaternion algebra A over Q or a number field F: returns A′ = ((a,b)/F) with a, b small, and an isomorphism A → A′. | Small-coefficient search. |
| `Enumerate(O, A, B)` (over Z) | Sequence of all elements x (up to sign) in the definite quaternion order O or ideal I over Z with reduced norm in [A, …, B] (or [0, …, B] if only B given). | Enumeration via reduced Gram matrix. |
| `Enumerate(O, A, B)` / `Enumerate(O, B)` (over number ring) | Elements x (up to sign) in the definite quaternion order O or ideal I over a number ring with absolute trace of norm in [A, …, B] (or [0, …, B]). | LLL-reduced basis enumeration. |

*Worked example: H86E22 (ReducedGramMatrix applied to left ideal classes, verifying uniqueness of the Gram matrix for isomorphism testing).*

## 86.14 Isomorphisms

### 86.14.1 Isomorphisms of Algebras

Two quaternion algebras A, B over a common field F are isomorphic iff they share the same ramified places. Finding an explicit isomorphism is harder: Magma embeds the first standard generator of A into B and then finds an element perpendicular to that image with the correct minimal polynomial, requiring two points on conics over quadratic extensions.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `IsIsomorphic(A, B)` | For A, B over Q, F_q(X) (q odd) or a number field: true iff A and B are isomorphic. If `Isomorphism := true` (default `false`) and they are isomorphic, also returns an isomorphism A → B. | Comparison of ramified places; explicit isomorphism via two points on conics over quadratic extensions (norm equations). |

*Worked example: H86E23 (two algebras over F_7(x), IsIsomorphic with explicit isomorphism, verification via forall).*

### 86.14.2 Isomorphisms of Orders

Two orders S, T in a quaternion algebra A are isomorphic iff they are conjugate in A. In a definite algebra this conjugation induces an isometry of the norm-form quadratic Z- or F_q[X]-modules. For indefinite algebras, any connecting ideal I with left order S and right order T must be isomorphic to a right ideal of T. See **[KV10]** for details.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `IsIsomorphic(S, T)` / `IsConjugate(S, T)` | For orders S, T over Q, F_q(X) (q odd) or a number field: true iff S and T are isomorphic. Indefinite case currently requires S, T to be maximal. Parameters: `FindElement` (default `false`; if set, second return is an isomorphism S → T, third return is element a with T = a⁻¹Sa; search may fail for indefinite algebras over number fields); `ConnectingIdeal` (for indefinite algebras over number fields, speeds up computation if an ideal with left order S and right order T is provided). | Definite: norm-form isometry via Minkowski/dominant diagonal reduction. Indefinite: connecting ideal + right ideal isomorphism **[KV10]**. |
| `Isomorphism(S, T)` | For two isomorphic definite quaternion orders S, T over Z or F_q[X] (q odd): returns an algebra isomorphism. For orders over number rings, use `IsIsomorphic` with `FindElement`. | Minkowski/dominant diagonal form **[KV10]**. |

*Worked example: H86E24 (ideal classes at disc 37, RightOrder, Isomorphism, conjugation).*

### 86.14.3 Isomorphisms of Ideals

Two right (left) ideals I, J of an order O in A are isomorphic O-modules iff xI = J (resp. Ix = J) for some x ∈ A*. To decide this, Magma tests whether the colon ideal (J:I) = {x ∈ A : xI ⊆ J} is principal.

- Over Z: Minkowski-reduced Gram matrix of (J:I) yields an element of smallest norm.
- Over F_q[X]: dominant diagonal Gram matrix **[Ger03]** yields a suitable element.
- Over other number rings R: search (J:I) for an element of the required norm using a reduced basis.

See **[KV10]**, **[DD08]** for further details.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `IsIsomorphic(I, J)` | For ideals I and J of the same order O over Q, F_q(X) (q odd) or a number field: true iff I and J are isomorphic O-ideals. For definite algebras, also returns x with xI = J (left) or Ix = J (right). For indefinite algebras, a search is made and x is returned if found. | Colon ideal principality via Minkowski/dominant diagonal/reduced basis **[KV10, DD08]**. |
| `IsPrincipal(I)` | For a left or right ideal I over Z, F_q[X] or a number ring: true iff I is principal; if so, returns a generator. | Colon ideal = O principality test. |
| `IsLeftIsomorphic(I, J)` / `IsRightIsomorphic(I, J)` (over Z or F_q[X]) | For two definite ideals with the same left (resp. right) order S: true iff they are isomorphic as S-modules. Returns the isomorphism and the transforming scalar in A. | Minkowski/dominant diagonal reduction **[KV10, Ger03]**. |
| `IsLeftIsomorphic(I, J)` / `IsRightIsomorphic(I, J)` (over number ring) | For two left (resp. right) ideals with the same left order O: true iff isomorphic as O-modules. Returns the isomorphism (given by multiplication) if true. | Reduced basis search **[KV10]**. |
| `LeftIsomorphism(I, J)` | For two isomorphic left ideals over a definite order S over Z or F_q[X]: the S-module isomorphism and the quaternion algebra element defining it by right-multiplication. | From Minkowski/dominant diagonal reduction. |
| `RightIsomorphism(I, J)` | For two isomorphic right ideals over a definite order S over Z or F_q[X]: the S-module isomorphism and the quaternion algebra element defining it by left-multiplication. | From Minkowski/dominant diagonal reduction. |

*Worked examples: H86E25 (non-isomorphic left ideals, isomorphic as right ideals, TwoSidedIdealClasses); H86E26 (isomorphism testing over a number ring).*

## 86.15 Units and Unit Groups

Let S be a definite quaternion order over Z, F_q[X] (q odd), or a number ring. Over Z or F_q[X] the unit group is finite and can be read off any reduced Gram matrix of S. If the base ring is a number ring R, an explicit description of the finite quotient S*/R* is given in **[Vig76]**.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `NormOneGroup(S)` | Returns a group G isomorphic to S¹ (elements of S with reduced norm 1), or if `ModScalars := true` (default `false`), G isomorphic to S¹/{±1}. Also returns a map G → S. | Reduced Gram matrix / **[Vig76]** for number rings. |
| `Units(S)` | For the definite order S: the set of units S*. Over Z or F_q[X]: all units. Over a number field: representatives modulo the unit group of the base ring (since the unit group is infinite in general). | Reduced Gram matrix (over Z/F_q[X]); **[Vig76]** (over number ring). |
| `MultiplicativeGroup(S)` / `UnitGroup(S)` | The unit group S* of the definite quaternion order S: returns an abstract group G and a map G → S. Over Z or F_q[X]: G is the full unit group. Over a number field: G is the unit group modulo the base ring's unit group. | Reduced Gram matrix (over Z/F_q[X]); **[Vig76]** (over number ring). |

*Worked examples: H86E27 (unit groups of orders in (-1,-1)/Q, 24 units for the maximal order corresponding to the Hurwitz quaternions, 8 units for an index-2 suborder); H86E28 (unit group of a definite order over a cubic number ring, permutation group of order 12).*

Note: Unit groups of orders in **indefinite** quaternion algebras are infinite arithmetic groups (twisted analogues of SL₂(Z) and its congruence subgroups), studied via an embedding in GL₂(R) from some isomorphism A ⊗ R ≅ M₂(R).
