# Chapter 61 — Matrix Groups over Infinite Fields

**Handbook part:** IX — Finite Groups
**Handbook pages:** 1761–1777 (PDF pages 1892–1911)

---

## Scope and overview

This chapter provides algorithms for computing with a group G given by a finite set S = {g₁, …, gᵣ} of invertible n × n matrices over an infinite field K. The algorithms are based on special techniques developed for computing in this class of groups (**[DF08, DF09, DFO09, DEF09, DFO12, DFO11]**), which rely on properties of finitely generated linear groups.

The group G is defined over the subring R of K generated by the entries of the matrices gᵢ, gᵢ⁻¹, 1 ≤ i ≤ r. If ρ is an ideal of R, then it induces a congruence homomorphism from GL(n, R) onto GL(n, R/ρ), which replaces every entry of an element in S by its image in R/ρ. The core technique depends on constructing a congruence homomorphism whose kernel Gρ (a congruence subgroup) has the property that all torsion elements are unipotent. The existence of such a normal subgroup of finite index was proved by Selberg and Wehrfritz. When ρ is maximal this reduces computation to a finite field R/ρ. See **[DF08, Section 3]** for a detailed exposition.

Three sets of functions are provided:

**(a) Finiteness testing** — functions testing finiteness of matrix groups over a wide range of infinite domains; implementations of algorithms in **[DF09, DFO09, DFO12]**. If a group is finite an isomorphic copy over a finite field can be constructed for further structural investigation.

**(b) Virtual properties** — functions testing whether G is soluble-by-finite, polycyclic-by-finite, nilpotent-by-finite, abelian-by-finite, or central-by-finite. These are the first publicly available implementations of algorithms to decide the "Tits alternative" for a linear group; implemented from **[DFO11]**.

**(c) Nilpotent matrix groups** — functions for testing nilpotency and computing Sylow systems; implemented from **[DF08]** (which in turn builds on **[DF06]** for the finite-field case). Additional functions by Tobias Rossmann decide irreducibility and primitivity for finite nilpotent matrix groups over number fields and function fields of characteristic 0 (**[Ros10, Ros11]**).

Since G is finitely generated it is defined over a finitely generated subfield of K. The main fields considered are finite-degree extensions of F(x₁, …, xₘ), where x₁, …, xₘ are algebraically independent, m ≥ 0, and the coefficient field F is a number field or a finite field.

Verbose output is available via `SetVerbose("Infinite", 1)`.

## 61.2 Construction of Congruence Homomorphisms

In this section K is a finite-degree extension of F(x₁, …, xₘ), where F is Q, a number field, or a finite field; m ≥ 0 if char F = 0 and m > 0 otherwise.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `CongruenceImage(G : parameters)` | For a finitely generated subgroup G of GL(n, K): constructs a congruence homomorphism from G into GL(n, Fq) for some prime power q. Returns the congruence image H, the homomorphism, and the list of images of generators of G. The kernel N is the normal subgroup of G whose torsion elements are all unipotent (torsion-free when char K = 0). Parameters: `Virtual` (BoolElt, default `false`) — if true, the homomorphism satisfies additional properties from **[DFO11]** enabling the virtual-property tests of §61.4; `Prime` (RngIntElt, default `3`) — when char K = 0 and positive, a lower bound for the characteristic of the congruence image; if 0, constructs an image over a characteristic-0 field; `Limit` (RngIntElt, default `10`) — for groups over rational function fields, limits the degree of field extensions (char K > 0) or the modulus tuples examined (char K = 0); `ExtDegree` (RngIntElt, default `1`) — for algebraic function fields of positive characteristic, the minimum degree of the coefficient field extension. | Congruence homomorphism construction **[DFO12, Section 3]**. |

## 61.3 Testing Finiteness

In this section K is a finite-degree extension of F(x₁, …, xₘ), where F is Q, a number field, or a finite field; m ≥ 0 if char F = 0 and m > 0 otherwise.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `IsFinite(G : parameters)` | For a finitely generated subgroup G of GL(n, K): returns `true` if G is finite, otherwise `false`. Parameters: `NumberRandom` (RngIntElt, default `10`) — number of random elements tested for finite order first; `Presentation` (MonStgElt, default `"CT"`) — how the presentation for the congruence image is constructed: `"CT"` uses `CompositionTreeVerify`, `"PC"` uses `LMGSolubleRadical` (when image is soluble), `"FP"` uses `FPGroup` or `FPGroupStrong`; `Small` (RngIntElt, default `10⁵`) — if image order is below this, use `FPGroup`; `OrderLimit` (RngIntElt, default `10¹²`) — if image order is below this (and above `Small`), use `FPGroupStrong`; `Algebra` (BoolElt, default `true`) — if true and K is a function field, uses the "algebra algorithm" of **[DF09]** (char 0) or **[DFO09]** (char > 0); `Nilpotent` (BoolElt, default `false`) — if true, calls a special procedure for nilpotent groups **[DF08, Section 4.3]**; `UseCongruence` (BoolElt, default `false`) — for K = Q or a number field, forces use of congruence homomorphism machinery; `DetermineOrder` (BoolElt, default `false`) — if true and G is finite, also returns the order of G; `Prime` (RngIntElt, default `3`) — same meaning as in `CongruenceImage`. | Composite: algebra algorithm **[DF09]** / **[DFO09]** or congruence-homomorphism + presentation evaluation **[DFO12, DF09, DFO09, DF08]**. |
| `IsomorphicCopy(G : parameters)` | Input is a finite subgroup G of GL(n, K). If successful, returns `true` and an isomorphic copy of G in GL(n, Fq) for some prime power q; otherwise returns `false`. Always succeeds when char K = 0. If char K > 0, Fq has the same characteristic. Parameters: `Presentation` (MonStgElt, default `"CT"`) — as in `IsFinite`; `Small` (RngIntElt, default `10⁵`) — as above; `OrderLimit` (RngIntElt, default `10¹²`) — as above; `Verify` (BoolElt, default `false`) — if true, first checks that G is finite; `Algebra` (BoolElt, default `false`) — if true and K is a function field, uses the algebra algorithm **[DF09]** / **[DFO09]**; `StartDegree` (RngIntElt, default `1`) and `EndDegree` (RngIntElt, default `5`) — range of extension degrees investigated when char F > 0; `CompletelyReducible` (BoolElt, default `false`) — if true, uses a more efficient algorithm to construct the isomorphic copy. | Proves congruence homomorphism is an isomorphism via presentation evaluation **[DFO12, Section 4.3]**. |
| `Order(G : parameters)` | Given a finite subgroup G of GL(n, K), returns the order of G by applying `IsomorphicCopy`. Parameters: `Verify` (BoolElt, default `false`) — if true, first checks G is finite; `UseCongruence` (BoolElt, default `false`) — for K = Q or a number field, forces use of congruence machinery. | Via `IsomorphicCopy`. |

*Worked examples: H61E1 (3×3 group over Q(t), `IsFinite` true, `IsomorphicCopy` gives GL(3, GF(3)), order 48); H61E2 (6×6 group over GF(5)(t), order 7440000); H61E3 (2×2 group over GF(5²)(t), `IsFinite` false, `IsSolubleByFinite` true, `IsCompletelyReducible` false); H61E6 (2×2 group over a degree-4 number field, `IsFinite` false); H61E7 (3×3 group over an algebraic function field over Q(u), `IsFinite` false, `IsSolubleByFinite` true); H61E8 (2×2 group over GF(4)(t), `IsFinite` true, `IsomorphicCopy`).*

## 61.4 Deciding Virtual Properties of Linear Groups

In this section K is a finite-degree extension of F(x₁, …, xₘ), where F is Q, a number field, or a finite field; m ≥ 0 if char F = 0 and m > 0 otherwise. All algorithms here are implemented from **[DFO11]**. The standard strategy is: construct a congruence homomorphism (with `Virtual := true`), build a presentation for the congruence image, then evaluate its relations to obtain normal generators for the congruence kernel. The `Presentation`, `Small`, and `OrderLimit` parameters behave uniformly across all five functions as described in §61.3.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `IsSolubleByFinite(G : parameters)` | For a finitely generated matrix group G over K: returns `true` if G is soluble-by-finite, otherwise `false`. Currently valid only for p > n when char K = p > 0. Parameters: `Presentation`, `OrderLimit`, `Small` (as in §61.3). | Congruence homomorphism + presentation evaluation **[DFO11, Section 3.2]**. |
| `IsPolycyclicByFinite(G : parameters)` | For a finitely generated matrix group G over Z: returns `true` if G is polycyclic-by-finite, otherwise `false`. Parameters: `Presentation`, `OrderLimit`, `Small`. | **[DFO11, Section 3.2]**. |
| `IsNilpotentByFinite(G : parameters)` | For a finitely generated matrix group G over K (currently K must be Q, a number field, or an algebraic function field with a single indeterminate): returns `true` if G is nilpotent-by-finite, otherwise `false`. Parameters: `Presentation`, `OrderLimit`, `Small`. | Congruence homomorphism + presentation evaluation **[DFO11, Section 5.2]**. |
| `IsAbelianByFinite(G : parameters)` | For a finitely generated matrix group G over K (K as for `IsNilpotentByFinite`): returns `true` if G is abelian-by-finite, otherwise `false`. Parameters: `Presentation`, `OrderLimit`, `Small`. | **[DFO11, Section 5.2]**. |
| `IsCentralByFinite(G : parameters)` | For a finitely generated matrix group G over K (K a finite-degree extension of F(x₁, …, xₘ), F = Q or a number field): returns `true` if G is central-by-finite, otherwise `false`. Parameters: `Presentation`, `OrderLimit`, `Small` (as in §61.3); `CompletelyReducible` (BoolElt, default `false`) — if true, uses a more efficient algorithm. | **[DFO11, Section 5.3]**. |

*Worked examples: H61E3 (`IsSolubleByFinite` on an infinite group over GF(5²)(t)); H61E4 (3×3 group over Z with five generators, `IsSolubleByFinite`, `IsNilpotentByFinite`, `IsCentralByFinite`, `IsAbelianByFinite` all false); H61E5 (2×2 group over a quadratic number field, both tests false); H61E7 (`IsSolubleByFinite` true for a group over an algebraic function field over Q(u)).*

## 61.5 Other Properties of Linear Groups

In this section K is a finite-degree extension of F(x₁, …, xₘ), where F is Q, a number field, or a finite field, and m ≥ 0.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `IsCompletelyReducible(G : parameters)` | For a finitely generated matrix group G over K: returns `true` if G is completely reducible, otherwise `false`. Applies only when G is soluble-by-finite, nilpotent-by-finite, or abelian-by-finite; exactly one of the Boolean parameters `SolubleByFinite`, `NilpotentByFinite`, `AbelianByFinite`, `Nilpotent` (all BoolElt, default `false`) must be set to `true`. When `Nilpotent` is true a more efficient algorithm from **[DF08]** is used. In positive characteristic p, cannot decide complete reducibility if p divides the order of the congruence image. Parameters also include `Presentation`, `OrderLimit`, `Small` (as in §61.3). | **[DFO11, Section 4]**; nilpotent variant from **[DF08]**. |
| `IsUnipotent(G)` | For a finitely generated matrix group G over an exact field F: returns `true` and a change-of-basis matrix c ∈ GL(n, F) such that Gᶜ is upper unitriangular if G is unipotent, otherwise `false`. | **[DF06, Section 2.1]**. |
| `IsNilpotent(G)` | For a finitely generated subgroup G of GL(n, K): returns `true` if G is nilpotent, otherwise `false`. Over a finite K uses **[DF06]**; over an infinite K constructs a homomorphic image via `CongruenceImage` **[DF08]**. | **[DF06]** (finite K); **[DF08]** via `CongruenceImage` (infinite K). |
| `IsSoluble(G : parameters)` | For a finitely generated subgroup G of GL(n, K): returns `true` if G is soluble, otherwise `false`. When char K = p > 0 the algorithm is valid only for p > n. Parameters: `Presentation`, `OrderLimit`, `Small` (as in §61.3); `UseCongruence` (BoolElt, default `false`) — for K = Q or a number field, forces congruence machinery. | **[DFO11, Section 3.2]**. |
| `IsPolycyclic(G : parameters)` | For a finitely generated matrix group G over Z: returns `true` if G is polycyclic, otherwise `false`. Parameters: `Presentation`, `OrderLimit`, `Small`. | Same machinery as `IsSolubleByFinite`. |
| `HasFiniteOrder(g : parameters)` | For an invertible matrix g defined over Z, Q, a number field, a function field, or an algebraic function field: returns `true` and (if known) a multiplicative upper bound for the order of g if g has finite order, otherwise `false`. Parameter: `UseCongruence` (BoolElt, default `false`) — for g over Z, Q, or a number field, forces use of congruence machinery. | — |

*Worked examples: H61E3 (`IsCompletelyReducible` false on an infinite group); H61E10 (`IsNilpotent` true on a 4×4 group over GF(17)); H61E11 (`IsNilpotent` true on a 2×2 group over an algebraic function field over Q(i)).*

## 61.6 Other Functions for Nilpotent Matrix Groups

The first function applies to nilpotent matrix groups over finite fields. The next two were developed and implemented by Tobias Rossmann.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `SylowSystem(G : parameters)` | Given a nilpotent matrix group G over a finite field: constructs one Sylow p-subgroup for each prime p dividing |G|. Parameter: `Verify` (BoolElt, default `false`) — if true, first verifies that G is nilpotent. | **[DF06]**. |
| `IsIrreducibleFiniteNilpotent(G : parameters)` | Let G be a finite nilpotent matrix group over K, where K is a number field or a rational function field over a number field. Returns `true` if G is irreducible, or `false` and a proper submodule of `GModule(G)`. Parameters: `DecideOnly` (BoolElt, default `false`) — if true, suppresses construction of the submodule; `Verify` (BoolElt, default `false`) — if true, checks that G is nilpotent and finite. | Rossmann's irreducibility algorithm **[Ros10]**. |
| `IsPrimitiveFiniteNilpotent(G : parameters)` | Let G be an irreducible finite nilpotent matrix group over K (as above). Returns `true` if G is primitive, or `false` and a system of imprimitivity given as a sequence of subspaces of `RSpace(G)`. Parameters: `DecideOnly` (BoolElt, default `false`) — suppresses construction of the system; `Verify` (BoolElt, default `false`) — checks nilpotency and finiteness. | Rossmann's primitivity algorithm **[Ros11]**. |

*Worked examples: H61E9 (8×8 group over Q(√2), `IsIrreducibleFiniteNilpotent` true, `IsPrimitiveFiniteNilpotent` false with 2 blocks); H61E10 (4×4 group over GF(17), `SylowSystem` returning two subgroups, `Order` = 8704).*
