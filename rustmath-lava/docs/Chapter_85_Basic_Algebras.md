## Scope and overview

A basic algebra is a finite-dimensional algebra A over a field, all of whose simple modules have dimension one (known in the literature as a "split" basic algebra). Every algebra is Morita equivalent to a basic algebra, though a field extension may be necessary to obtain the split form. The Magma type `AlgBas` is optimised for homological calculations.

A basic algebra is generated by elements a₁, …, aₜ where a₁, …, aₛ are the primitive idempotent generators and aₛ₊₁, …, aₜ are the nonidempotent generators. Each nonidempotent generator aₖ satisfies aᵢ ∗ aₖ ∗ aⱼ = aₖ for specific idempotents aᵢ and aⱼ. The indecomposable projective modules are Pᵢ = aᵢ · A and the simple modules are Sᵢ = Pᵢ/Rad(Pᵢ).

The chapter covers: creation of basic algebras (from projective modules and path trees, from generators and relations, from group algebras); special constructions (Morita-equivalent condensed algebras, Hecke algebras, Schur algebras, block algebras, ext-algebras); module theory (projective and injective modules, resolutions, syzygy modules); cohomology (cohomology rings and their generators, Ext-algebras, restriction and inflation); and A∞-algebra structures on group cohomology (Massey products, higher maps, null homotopies).

The type `AlgBasGrpP` is a specialised subtype for modular group algebras of p-groups, optimised for cohomology ring computation with support for restriction and inflation maps.

## 85.2 Basic Algebras

In the Magma implementation the algebra is given as the sequence of projective modules P₁, …, Pₛ together with a path tree for each projective module. Each projective module supplies a matrix for every generator giving its action on the module's vector space. The basis b₁, …, bₙ for Pᵢ is chosen so that each basis element is the image of a basis element of lower index under multiplication by a nonidempotent generator; this structure is recorded in the path tree.

### 85.2.1 Creation

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `BasicAlgebra(Q)` | Given a sequence `[<M₁,T₁>, …, <Mₛ,Tₛ>]` of 2-tuples (module for a matrix algebra, path tree), creates the basic algebra whose projective modules are M₁, …, Mₛ with path trees T₁, …, Tₛ. | Direct construction from user-supplied data; no verification performed. |
| `BasicAlgebra(F,R,s,P)` | Creates the basic algebra from a presentation: `F` a free algebra with generators a₁, …, aₜ (first `s` are the primitive idempotents), `R` the list of relations among the nonidempotent generators, and `P` a sequence of 2-tuples giving the beginning and ending idempotent nodes for each nonidempotent generator. | Constructs projective modules from the quiver-with-relations data. |
| `BasicAlgebra(F,R)` | Creates the basic algebra of a local algebra from `F` (free algebra in nonidempotent generators) and `R` (relations). | Local-algebra variant of the quiver construction. |
| `TensorProduct(A, B)` | The tensor product of basic algebras `A` and `B`. | — |
| `BasicAlgebra(G, k)` / `BasicAlgebra(G, k)` / `BasicAlgebra(G)` | Given a finite p-group `G` and a finite field `k` of characteristic p (or the prime field if omitted), returns the group algebra kG as a basic algebra of type `AlgBasGrpP`. | Group algebra construction; result is optimised for cohomology computations. |

*Worked examples: H85E3 (quiver with three nodes, relation (a∗b)³ = 0 over GF(7)); H85E4 (basic algebra of S₃ over GF(3), tensor product with C₃); H85E5 (basic algebra of A₄ over GF(2) constructed from explicit matrix algebras and path trees).*

## 85.3 Homomorphisms

A homomorphism of a basic algebra has type `Map`; the matrix of φ is retrieved with `Matrix(phi)`. The kernel is returned as a subspace of the vector space of the domain (a two-sided ideal). The image is returned as a basic algebra together with the embedding homomorphism. Magma does not automatically check that a constructed map is an algebra homomorphism.

| `IsAlgebraHomomorphism(A, B, psi)` | Returns true if the matrix ψ represents a homomorphism from basic algebra `A` to basic algebra `B`. | — |

### 85.8.3 Projective Covers and Resolutions

A projective cover of M is a projective module P with a surjective homomorphism φ : P → M, minimal with respect to this property. The main function is `CompactProjectiveResolution`, which stores minimal data to reconstruct the boundary maps (the images of the generators of the indecomposable projective summands) and avoids computing the full terms as algebra modules, making it fast.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `ProjectiveCover(M)` | The projective cover of `M`: returns the projective module P, the surjective homomorphism P → M, the sequences of inclusions and projections from/to the indecomposable direct summands, and the isomorphism type of P as a list of multiplicities of each projective type. | Minimal projective cover via path-tree lifting. |
| `ProjectiveResolution(M, n)` | The minimal projective resolution of `M` out to `n` steps as a complex, together with the augmentation homomorphism from the projective cover into `M`. Constructs the compact resolution if not already computed. | Iterative projective-cover construction; uses `CompactProjectiveResolution`. |
| `CompactProjectiveResolution(M, n)` | Minimal projective resolution of `M` out to `n` steps in compact form, together with the augmentation map (P₀ → M). Records only the images of generators of indecomposable projective summands. Returns a record with fields: `BettiNumbers` (isomorphism types), `ResolutionRecord` (boundary maps), `Module`, `AugmentationMap`, `Typ`. If previously computed to degree m < n, extends by n − m steps; if m ≥ n, returns the previously computed result. | Compact minimal resolution; avoids constructing full module terms. |
| `CompactProjectiveResolutionsOfSimpleModules(A,n)` | Returns a sequence of compact projective resolutions of all simple A-modules computed to degree `n`. | Applies `CompactProjectiveResolution` to each simple module. |
| `SyzygyModule(M, n)` | The n-th syzygy module of `M`, constructed from the compact projective resolution (which is computed if not already available). | Extracted from the compact resolution. |
| `SimpleHomologyDimensions(M)` | The sequence of sequences of dimensions of Torⱼ(Sᵢ, M) for simple modules Sᵢ and module M, to the extent computed. | Derived from the compact resolution data. |

*Worked examples: H85E16 (quiver with four nodes and five generators over GF(8); compact projective resolutions and simple homology dimensions, comparing finite vs. infinite projective dimension); H85E17 (quotient of the group algebra of an extraspecial 3-group by a central element ideal; projective resolution growth comparison).*

## 85.9 Duals and Injectives

The k-dual Hom_k(M,k) for a right B-module M is a right module over the opposite algebra OB. Duals of projective OB-modules are injective B-modules; duals of projective OB-resolutions of M give injective B-resolutions of the dual of M.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Dual(M)` | The dual of module `M` as a module over the opposite of the algebra of `M`. The opposite algebra is created if not already existing. | k-dual construction. |
| `BaseChangeMatrix(A)` | Given `A` with opposite algebra O, returns the change-of-basis matrix B from the vector space of A to the vector space of O, so that (xy)B = (yB)(xB) in O. | — |

### 85.9.1 Injective Modules

Injective hulls and resolutions are computed by taking the projective cover or resolution of the dual module over the opposite algebra, then dualising back. The opposite algebra is created automatically if not yet computed.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `InjectiveModule(B, i)` | The i-th injective module of `B`. | Via dual of projective module of opposite algebra. |
| `InjectiveHull(M)` | The injective hull of `M`: the minimal-dimension injective I with inclusion ι : M → I. Returns I, ι, the sequences of inclusions/projections from/to indecomposable injective summands, and the type sequence [t₁, …, tₛ]. | Dual of projective cover of dual module. |
| `InjectiveResolution(M, n)` | The minimal injective resolution of `M` out to `n` steps as a complex, together with the inclusion M → I₀. Computes the compact injective resolution and builds the complex from it. | Via compact injective resolution. |
| `CompactInjectiveResolution(M, n)` | Minimal injective resolution of `M` out to `n` steps in compact form with the coaugmentation map (M → I₀). Recorded as the compact projective resolution of the dual of M over the opposite algebra. Returns a record with fields: `BettiNumbers`, `ResolutionRecord`, `Module`, `CoaugmentationMap`, `Typ`. | Dual of compact projective resolution of the dual module over the opposite algebra. |
| `InjectiveSyzygyModule(M, n)` | The n-th injective-syzygy module of `M`, constructed from the compact injective resolution. | — |
| `SimpleCohomologyDimensions(M)` | The sequence of sequences of dimensions of Extʲ(Sᵢ, M) for simple modules Sᵢ and module M, to the extent computed. | Derived from the compact injective resolution. |

*Worked examples: H85E18 (two-node quiver over GF(8); periodic injective resolution of the first projective module; decomposition of an injective syzygy module via the endomorphism ring).*

### 85.10.1 Ext-Algebras

The ext-algebra of B is Ext∗_B(S,S) for S = S₁⊕…⊕Sₙ the direct sum of all simple B-modules. When B has finite global dimension, this is a finite-dimensional algebra.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `ExtAlgebra(A, n)` | Computes the ext-algebra of `A` with projective resolutions and cohomology computed to degree `n`. Returns a record carrying: (i) a free algebra F; (ii) relations in F such that the ext-algebra is F/I; (iii) chain maps for the generators; (iv) degrees of generators; (v) bases of Ext∗_A(Sᵢ,Sⱼ) for each pair i,j; (vi) basis of the entire ext-algebra; (vii) number of computed steps; (viii) global dimension computed. | Minimal projective resolutions of all simple modules, then chain-map generators for all Ext groups. |
| `BasicAlgebraOfExtAlgebra(ext)` | Creates the basic algebra from the output of `ExtAlgebra`; errors if not verified finite-dimensional. | — |
| `BasicAlgebraOfExtAlgebra(A)` | Forms the basic algebra from a precomputed ext-algebra of `A`; errors if not yet computed or not finite-dimensional. | — |
| `BasicAlgebraOfExtAlgebra(A, n)` | Creates the basic algebra of the ext-algebra of `A` computed to `n` steps; computes if not yet available; errors if not finite-dimensional. | — |
| `SumOfBettiNumbersOfSimpleModules(A, n)` | Computes Betti numbers of all simple A-modules to degree `n`; the result is the dimension of the ext-algebra computed to degree `n`. Useful for detecting infinite global dimension by monitoring growth. | Applies `CompactProjectiveResolution` to all simple modules. |

*Worked examples: H85E20 (lower-triangular 10×10 matrices over GF(5); global dimension 9; ext-algebra and its double agree up to isomorphism; Koszul duality check).*

## 85.12 A-infinity Algebra Structures on Group Cohomology

An A∞-algebra structure on H∗A is induced by any differential graded algebra A. For R a quiver algebra quotient and S the direct sum of all simple R-modules, Ext∗_R(S,S) carries such a structure that (by a theorem of Keller **[Kel01]**) allows recovery of R from Ext∗_R(S,S). An A∞-algebra consists of higher operations mᵢ : V⊗ⁱ → V satisfying the Stasheff axioms. The implementation uses Kadeishvili's recursive method **[Kad80]** for the special case of Ext∗_{kG}(k,k) with G a p-group and k the prime field of characteristic p.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `AInfinityRecord(G,n)` | Constructs a record carrying all information needed to compute A∞-operations on the cohomology ring of group G computed to n steps. Fields include: the cohomology ring (R), the cohomology ring quotient (S), the projective resolution (P), the simple module resolved (k), and the basic algebra (A). | A∞-structure via Kadeishvili's recursive construction **[Kad80]**. |
| `MasseyProduct(Aoo,terms)` / `HighProduct(Aoo,terms)` | Given an A∞-object Aoo and a list of terms t₁, …, tᵢ, computes the structure map mᵢ(t₁ ⊗ … ⊗ tᵢ). | Higher product mᵢ via Stasheff axioms **[Kad80, Kel01]**. |
| `HighMap(Aoo,terms)` | Given an A∞-object Aoo and terms t₁, …, tᵢ, computes the value of an A∞-quasiisomorphism f at the point t₁ ⊗ … ⊗ tᵢ. | A∞-quasiisomorphism evaluation **[Kad80, Kel01]**. |

*Worked examples: H85E22 (A∞-structure on H∗(C₄, F₂): HighProduct([x,x,x,x]) = y verifying the single nontrivial higher operation m₄); H85E23 (same verification for C₃ in characteristic 3, using Kadeishvili sign conventions).*

### 85.12.1 Homological Algebra Toolkit

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `ActionMatrix(A,x)` | Produces the matrix of the right action of basic algebra element `x` in algebra `A`. | — |
| `CohomologyRingQuotient(CR)` | Computes the actual cohomology ring as a quotient ring of a multivariate polynomial ring from a cohomology ring record. | — |
| `LiftToChainmap(P,f,d)` | Lifts the function described by `f` to a chain map from P to P of degree `d`. | — |
| `NullHomotopy(f)` | Constructs a null homotopy H of the null-homotopic chain map f (so that f = dH − Hd). Throws an error if f is not null-homotopic. | Linear algebra on chain complexes. |
| `IsNullHomotopy(f,H)` | Confirms that H is a null homotopy of f, i.e. that f = dH − Hd. | — |
| `ChainmapToCohomology(f,CR)` | Takes a chain map f and returns the element in the cohomology quotient ring corresponding to f. | — |
