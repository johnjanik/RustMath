## Scope and overview

The number field module in Magma is based on the Kant/Kash system (Kant-V4) **[KAN97, KAN00]**, developed by the group of M. Pohst in Berlin. This chapter covers the basic operations on number fields (type `FldNum`) and their elements (type `FldNumElt`).

A number field in Magma is a finite extension of **Q** or of another number field. Extensions of **Q** are called *absolute* fields; extensions of other number fields are called *relative* fields. Extended types allow indexing by coefficient ring: `FldNum[FldRat]` for absolute extensions, `FldNum[FldNum]` for relative extensions. Internally, `K = k[t]/(f(t))` or the multivariate quotient `k[s₁,…,sₙ]/(f₁(s₁),…,fₙ(sₙ))`.

An important consequence of the quotient-ring representation is that independently created fields — even from the same polynomial — are *not* automatically identified as equal (they may embed into a larger field in more than one way). Number fields are *not* automatically embedded into **C**; use `Conjugates` or the places framework (§34.8) for that.

Arithmetic is fastest in absolute simple extensions. Invariants (Degree, Discriminant, Norm, Trace, etc.) are always *relative* to the current representation. Some operations (subfield computation, class and unit groups) currently require absolute representations. Functions such as `ClassGroup(K)` are shortcuts for the corresponding computations on `MaximalOrder(K)`.

## 34.2 Creation Functions

### 34.2.1 Creation of Number Fields

Algebraic number fields can be created as absolute extensions (one or more irreducible polynomials over **Q**) or as relative extensions (polynomials irreducible over another number field).

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `NumberField(f)` | Given an irreducible polynomial `f` of degree n ≥ 1 over **Q** or a number field `K`, create `L = K(α)` where α is a root of `f`. Parameters: `Check` (BoolElt, default `true` — irreducibility check), `DoLinearExtension` (BoolElt, default `false` — if `true` and deg f = 1, returns a trivial extension of type FldNum), `Global` (BoolElt, default `false` — if `true`, reuses any previously created field with the same polynomial). | Field construction as quotient ring. |
| `RationalsAsNumberField()` / `QNF()` | Creates a number field isomorphic to **Q** (degree-1 FldNum). Supports all number field functions; arithmetic is slower than native **Q**. | Equivalent to `NumberField(x-1 : DoLinearExtension)`. |
| `NumberField(s)` | Given a sequence `s` of nonconstant irreducible polynomials over `K`, create `L = K(α₁,…,αₘ)`. With `Abs := false` (default), builds a tower; with `Abs := true`, returns a non-simple (sparse) extension admitting fields of degree < 10⁶. Parameters: `Check`, `DoLinearExtension`, `Abs`. | Tower of quotient-ring extensions. |
| `ext< F \| s1, ..., sn >` / `ext< F \| s >` | Extend number field `F` by polynomials `sᵢ` or the sequence `s`. Parameters: `Check`, `Global`, `Abs`, `DoLinearExtension`. | Same as `NumberField(S)`. |
| `RadicalExtension(F, d, a)` | For number field `F` and integral element `a` (not an n-th power for any n \| d), returns `F(a^{1/d})`. Parameter: `Check`. | Adjoin d-th root directly. |
| `SplittingField(F)` | Splitting field of the defining polynomial of number field `F`, together with the roots. Parameters: `Abs` (default `true` — absolute extension), `Opt` (default `true` — attempt `OptimizedRepresentation`). | Factorisation over extension fields. |
| `SplittingField(f)` | Splitting field of an irreducible polynomial `f` over **Z**. | Factorisation over extension fields. |
| `SplittingField(L)` | Common splitting field of a sequence `L` of polynomials over a number field or **Q**, together with all roots. Parameters: `Abs` (default `false`), `Opt` (default `false`). | Factorisation over extension fields. |
| `sub< F \| e1, ..., en >` | Subfield of `F` generated by elements `eᵢ` over the coefficient field of `F`; returns the subfield and its embedding into `F`. | — |
| `MergeFields(F, L)` / `CompositeFields(F, L)` | For absolute number fields `F` and `L`, returns a sequence of fields each containing a root of the defining polynomial of both `F` and `L`. Factorises the defining polynomial of the larger field over the smaller, then converts each factor's extension to an absolute extension. | Polynomial factorisation over number fields. |
| `Compositum(K, L)` | For absolute number fields `K` and `L` (at least one normal), finds a smallest common overfield. Essentially unique since one field is normal. | Normality exploited for uniqueness. |
| `quo< FldNum : R \| f >` | Given a polynomial ring `R` in one variable over a number field `K`, create `K(α)` where α is a root of `f`. Replaces `f` by `d·f` if denominators occur. Parameter `Check`. | Quotient ring construction. |
| `OptimizedRepresentation(F)` / `OptimisedRepresentation(F)` | For a number field `F` with ground field **Q**, attempts to find an isomorphic field `L` with a better (smaller coefficients) defining polynomial. Returns `L` if improved, else `F`. | LLL-based polynomial reduction. |

*Worked examples: H34E1 (linear extension of Rationals), H34E2 (creation of Q(α) for x⁴ − 420x² + 40000, towers, Global parameter), H34E3 (CompositeFields to compute normal closure of Q(∛2)), H34E4 (OptimizedRepresentation).*

### 34.2.2 Maximal Orders

The maximal order O_K is the ring of integers of an algebraic field: all elements that are roots of monic integer polynomials. The main algorithms are Round-2 and Round-4 **[Coh93, Bai96, Poh93, PZ89]** for absolute extensions, and **[Coh00, Fri97, Pau01]** for relative extensions.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `MaximalOrder(F)` / `IntegerRing(F)` / `Integers(F)` / `RingOfIntegers(F)` | Create the ring of integers of the algebraic number field `F`. Parameters: `Al` (MonStgElt, default `"Auto"`), `Verbose MaximalOrder` (max 5). | Round-2 / Round-4 **[Coh93, Bai96, Poh93, PZ89]** (absolute); **[Coh00, Fri97, Pau01]** (relative). |

## 34.5 Class and Unit Groups

Brief descriptions of class and unit group functions; full details and algorithm descriptions are in §§37.6 and 37.7. All functions support verbose flag `ClassGroup` (max 5). Ideals are discussed in §37.9.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `ClassGroup(K: parameters)` | The ideal class group of O_K as an abstract abelian group, together with a map to O_K (admitting inverses for discrete logarithms). Parameters: `Bound` (default MinkowskiBound), `Proof` (MonStgElt, default `"Full"` — options: `"GRH"`, `"Bound"`, `"Subgroup"`, `"Full"`, `"Current"`), `Enum` (BoolElt, default `true` — if `false`, uses random linear combinations instead of lattice enumeration), `Al` (default `"Automatic"` — `"Sieve"` or `"NoSieve"` for sieving method), `Verbose`. With `Proof := "Full"`, a guaranteed result is computed (Minkowski bound + verify). | Relation finding via short-element enumeration or LLL random combinations; sieving method **[Bia, Jac99]** for large discriminants (> 10³⁰). |
| `ConditionalClassGroup(K)` | Class group assuming the generalized Riemann hypothesis. | GRH-conditional. |
| `ClassNumber(K: parameters)` | The class number of O_K. Same parameters as `ClassGroup`. | As `ClassGroup`. |
| `BachBound(K)` | An integral upper bound on norms of generators of the class group assuming GRH. | Bach's GRH bound. |

## 34.7 Solving Norm Equations

Norm equations in number fields fall into two categories: *Diophantine* (solution in a specific order) and *field-theoretic* (any element with given norm). The functions here address the field-theoretic case using S-unit methods.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `NormEquation(F, m)` | For number field `F` and element `m` of its base field, determines whether `α ∈ F` exists with `N_{F/L}(α) = m` (field-theoretic), and if so returns a sequence containing a solution. Parameters: `Primes` (sequence of prime ideals of `L` to add to S), `Nice` (BoolElt, default `true` — LLL-reduces the solution). If `F` is relatively normal, the S-unit set is guaranteed to be sufficient. | S-unit group method **[Coh00 §7.5, Fie97, Sim02, Gar80]**: determine S, compute S-unit basis, realise norm as endomorphism, find preimage. |
| `NormEquation(m, N)` | For a map `N` on the multiplicative group of a number field (realised as an endomorphism of S-units), find a preimage for `m` under `N`. Parameters: `Raw` (BoolElt, default `false` — returns an unevaluated power product), `Primes`. Main use: Galois-theoretic constructions where the norm is a product over a fixed subgroup. | S-unit endomorphism preimage. |
| `SimNEQ(K, e, f)` | For number field `K` and subfield elements `e ∈ k₁`, `f ∈ k₂`, find `x ∈ K` satisfying both `N_{K/k₁}(x) = e` and `N_{K/k₂}(x) = f` simultaneously. Parameters: `S` ([RngOrdIdl], default `false` — supplementary prime ideals), `HasSolution` (BoolElt, default `false` — if `true`, keeps adding primes until solution found). | S-unit system: initial `S` contains ramified primes, support of `e` and `f`, and class group generators. Guaranteed for normal `K/Q`. |

*Worked example: H34E15 (N(x) = 3 in a relative quadratic extension; NormEquation via the norm map defined through automorphisms; Raw parameter).*

## 34.8 Places and Divisors

A place of a number field `K` (type `PlcNumElt`) is a class of absolute values inducing the same topology on `K`. By Ostrowski's theorem, places are either finite (one-to-one with nonzero prime ideals of the maximal order) or infinite (real or complex embeddings). Divisors (type `DivNumElt`) form the free group on finite places tensored with the **R**-vector space on infinite places. Parent types: `PlcNum` (places), `DivNum` (divisors).

### 34.9.5 L-functions of Hecke Characters

For a primitive Hecke character ψ, the associated L-function is `L(ψ,s) = ∏_p (1 − ψ(p)/N(p)^s)^{-1}`, satisfying a functional equation with conductor = conductor(ψ) × discriminant(O_K).

*Worked example: H34E20 (L-series of a Hecke character on a degree-5 field; CheckFunctionalEquation).*

### 34.9.6 Hecke Grössencharacters and their L-functions

Grössencharacters (also known as algebraic Hecke characters) are quasi-characters whose image is not restricted to the unit circle.
