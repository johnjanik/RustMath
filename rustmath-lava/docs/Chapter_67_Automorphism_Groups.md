# Chapter 67 — Automorphism Groups

**Handbook part:** IX — Finite Groups
**Handbook pages:** 1995–2010 (PDF pages 2126–2143)

---

## Scope and overview

Chapter 67 describes Magma's facilities for constructing and working with automorphism groups
of finite groups. An automorphism of a group G is a bijective homomorphism from G to itself;
the set of all automorphisms forms the automorphism group of G. Magma represents automorphism
groups as sets of homomorphisms (mappings) of the base group into itself — category `GrpAuto`,
elements of type `GrpAutoElt`. Each automorphism group stores a generating set for its base
group, and every automorphism is described by its action on those generators.

The full automorphism group is computed via **lifting algorithms**: a characteristic series
1 = N_r < N_{r-1} < ... < N_1 = L < G is constructed so that each N_i/N_{i+1} is elementary
abelian and G/L has no non-trivial soluble normal subgroup. The automorphism group is found for
each associated factor group starting at the top and lifting layer by layer. The general
algorithm for non-soluble groups is due to Cannon and Holt **[CH03]**; specialised versions
apply to p-groups (Eick, Leedham-Green and O'Brien **[ELGO02]**) and soluble groups
(Smith **[Smi94]**, as extended by Smith and Slattery).

For non-soluble permutation or matrix groups the algorithm relies on a database of automorphism
groups for the non-cyclic simple factors of G; the non-abelian composition factors must belong
to a restricted list. In V2.11 this list includes all simple groups of order at most 1.6 × 10^7,
alternating groups of degree at most 1000, all groups from several generic families including
PSL(2,q), PSL(3,q), PSL(4,p), PSL(5,p), PSU(3,p) and PSp(4,p), and the sporadic groups M11,
M12, M22, M23, M24, J1, J2, J3, HS, McL, Co3, He and others (list being extended regularly).

The full automorphism group is additionally returned as a finitely presented group, and a
permutation representation can also be constructed. The chapter covers creation, access
functions, order functions, multiple concrete representations, arithmetic on automorphisms,
stored attributes, and the construction of holomorphs.

## 67.2 Creation of Automorphism Groups

An automorphism group of a finite group G may be created in two ways: by computing the full
automorphism group via a lifting algorithm, or by specifying an arbitrary group of automorphisms
through its generators expressed as explicit image maps.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `AutomorphismGroup(G)` | Given a finite group G (permutation group, finite matrix group, or finite soluble group by pc-presentation), construct the full automorphism group F of G as a group of type `GrpAuto`. For permutation or matrix G, F is also computed as a finitely presented group accessible via `FPGroup(F)`. Parameters: `SmallOuterAutGroup` (integer, default 20000 — threshold on outer automorphism group order for choosing backtrack strategy in lifting; if outer aut order ≤ t use regular representation, otherwise find smaller permutation representation), `Print` (integer 0–3, verbose level; default 0), `PrintSearchCount` (integer, default 1000 — print frequency during backtrack search when `Print := 3`). | For non-soluble G: lifting algorithm of Cannon and Holt **[CH03]**. For G of type `GrpPC` that is a p-group: algorithm of Eick, Leedham-Green and O'Brien **[ELGO02]** (see §63.12.2). For G of type `GrpPC` but not a p-group: algorithm of Smith **[Smi94]** as extended by Smith and Slattery (see §63.12). |
| `AutomorphismGroup(G, Q, I)` | Given a finite group G, a sequence Q of generators for G, and a sequence I of length r where the i-th term gives the images of the elements of Q under the i-th generating automorphism φ_i, return the group of automorphisms A of G generated by φ_1, ..., φ_r. | User-specified generators by image maps; no lifting required. |

*Worked examples: H67E1 (automorphism group of a non-soluble 4×4 matrix group over the 8th cyclotomic field, order 92160).*

## 67.3 Access Functions

Functions providing access to basic information stored for an automorphism group A.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Group(A)` | Return the base group G on which the group of automorphisms A acts. | Attribute access. |
| `NumberOfGenerators(A)` / `Ngens(A)` | Return the number of defining generators for A. | Attribute access. |
| `NumberOfPCGenerators(A)` / `NPCGenerators(A)` / `NPCgens(A)` | Return the number of pc-generators for A, provided a pc-representation has been created for A (attribute `PCGenerators` is set). | Attribute access. |
| `Generators(A)` | Return a set containing the defining generators of A. | Attribute access. |
| `PCGenerators(A)` | Return an indexed set containing the pc-generators of A. Requires that a pc-representation has been created for A (attribute `PCGenerators` is set). | Attribute access. |
| `InnerGenerators(A)` | Given the full group of automorphisms A of G, return a sequence of generators for the inner automorphism group of the base group (attribute `InnerGenerators`), if that attribute has been set. | Attribute access. |
| `CharacteristicSeries(A)` | Return the value of the characteristic series of G used to compute A, if the attribute has been set. | Attribute access. |
| `IsSoluble(A)` / `IsSolvable(A)` | Return the value of A's attribute `Soluble` (a boolean), if the attribute has been set. | Attribute access. |
| `IsSolubleAutomorphismGroupPGroup(A)` / `IsSolvableAutomorphismGroupPGroup(A)` | Determine whether the automorphism group A of a p-group G (constructed via `AutomorphismGroup(G)` or an equivalent alias) is soluble; return the result and set the `Soluble` attribute on A. | Tests solubility and caches result. |

## 67.4 Order Functions

Unless the order is already known, each function in this family creates a faithful permutation
representation of the automorphism group in order to compute the order.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Order(A)` / `#A` | Return the order of the group of automorphisms A as an integer. Creates a permutation representation if order is not already known. | Via permutation representation if needed. |
| `FactoredOrder(A)` | Return the factored order of the group of automorphisms A. Creates a permutation representation if not already known. | Via permutation representation if needed. |
| `OuterOrder(A)` | Return the order of the outer automorphism group associated with A. | Derived from the automorphism group structure. |

*Worked examples: H67E2 (G = PGL(2,9): order 1440, factored order [<2,5>,<3,2>,<5,1>], outer order 2, inner generators, characteristic series).*

## 67.5 Representations of an Automorphism Group

Magma uses various concrete representations of an automorphism group for computation.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `PermutationRepresentation(A)` | Construct a faithful permutation representation of A by finding a union of conjugacy classes of the base group G that is closed under the action of A and whose G-normal closure equals G. Returns: the representation as a homomorphism A → P, the image P as a permutation group with standard support, and the set of elements of G used as the support. | Conjugacy-class union construction; faithfulness guaranteed by the normal-closure condition. |
| `PermutationGroup(A)` | Return a permutation group isomorphic to A, as defined by `PermutationRepresentation`. | As `PermutationRepresentation`. |
| `PermutationSupport(A)` | Return the set of elements of G (union of conjugacy classes) used as the support of the permutation group from `PermutationRepresentation`. | As `PermutationRepresentation`. |
| `PCGroupAutomorphismGroupPGroup(A)` | Attempt to directly construct a pc-representation for A, where A is the automorphism group of a conditioned p-group G constructed via `AutomorphismGroup`. Returns: a boolean indicating solubility of A, and if soluble, a homomorphism A → P and its image P as a pc-group. | Direct pc-group construction for p-group automorphism groups. |
| `FPGroup(A)` | Return a finitely presented group F with a presentation for A on the generators of A, together with the isomorphism from F to A. | Presentation derived from the automorphism group structure. |
| `OuterFPGroup(A)` | For A the full automorphism group of G, return a finitely presented group O isomorphic to the outer automorphism group of G, together with the natural epimorphism from `FPGroup(A)` onto O (kernel = inner automorphism group). | Quotient of the FP-group by the inner automorphisms. |

*Worked examples: H67E3 (permutation representation of degree 36 and FP presentation on 4 generators for Aut(PSL(2,9))); H67E4 (Higman-Sims group: automorphism group of order 88704000 with permutation representation on 5775 letters, then reduced to degree 100 via `LowIndexSubgroups`).*

## 67.6 Automorphisms

Elements of a group of automorphisms are of type `GrpAutoElt` and are treated both as
homomorphisms of the base group (applied to elements/subgroups) and as group elements
(multiplied, inverted, raised to powers). Composition of automorphisms in Magma follows the
convention: f * g means first apply f, then apply g.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `A . i` | For A a group of automorphisms with n generators and -n ≤ i ≤ n: return the i-th generator of A. A negative subscript gives the inverse of the generator; `A.0` denotes the identity. | Generator indexing. |
| `Identity(A)` / `Id(A)` / `A ! 1` | Return the identity element of A. | — |
| `A ! f` | Given an automorphism f of G represented as a Magma map, return the element of A corresponding to f. Errors if f is not in the group generated by the generators of A. Uses the permutation representation of A for membership testing. | Membership test via permutation representation. |
| `Order(f)` | Return the order of the automorphism f. | Order computation in the automorphism group. |
| `f * g` | Product (composition) of automorphisms f and g: first apply f, then apply g. | Composition of maps. |
| `f ^ n` | The n-th power of f; n may be positive or negative. | Repeated composition / inversion. |
| `(g1, ..., gr)` | Left-normed commutator of g1, ..., gr; all must belong to a common automorphism group. | Iterated commutator via composition. |
| `g eq h` | Return true if automorphisms g and h (in the same automorphism group) are equal, false otherwise. | Equality via permutation representation. |
| `g ne h` | Return true if g and h are not equal, false otherwise. | Equality via permutation representation. |
| `IsInner(f)` | Return true if f is an inner automorphism of the base group, false otherwise. If inner, also return an element of the base group whose conjugation action equals f. | Inner automorphism test via membership in inner automorphism subgroup. |

*Worked examples: H67E5 (arithmetic on automorphisms of SmallGroup(81,10): order, product, power, identity comparison); H67E6 (computing characteristic subgroups using `IsInner` and `Generators(A)` to identify outer automorphisms).*

## 67.7 Stored Attributes of an Automorphism Group

Automorphism groups have several attributes that may be stored as part of their data structure.
`HasAttribute` tests if an attribute is stored and retrieves its value; `AssertAttribute` sets
attribute values. The user is warned that `AssertAttribute` does not validate data for
correctness beyond simple type checks — incorrect settings will produce errors.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `HasAttribute(A, s)` | Return whether A has the attribute named by string s defined, and if so also return its value. | Attribute lookup. |
| `AssertAttribute(A, s, v)` | Set the attribute of A named by string s to value v. The possible attribute names are: `Group` (the base group, always set); `Order` (integer or factored integer); `OuterOrder` (integer or factored integer); `Soluble` / `Solvable` (boolean); `InnerGenerators` (sequence of inner-automorphism generators); `InnerMap` (homomorphism from base group to automorphism group); `ClassAction` (result of `PermutationRepresentation`); `ClassImage` (result of `PermutationGroup`); `ClassUnion` (result of `ClassUnion`); `FpGroup` (pair <F, m> where F is an fp-group and m : F → A is an isomorphism — the two return values of `FPGroup(A)`); `OuterFpGroup` (pair <O, f> where O is an fp-group and f : F → O is an epimorphism with kernel = inner automorphism group — the two return values of `OuterFPGroup(A)`); `GenWeights`; `WeightSubgroupOrders` (see soluble groups chapter). | Attribute assignment. |

*Worked examples: H67E7 (SmallGroup(904,4): computing automorphism group, testing and setting `FpGroup` attribute, finding characteristic vs non-characteristic normal subgroups); H67E8 (Alt(6): `OuterFPGroup`, outer automorphism group elementary abelian of order 4, constructing four non-conjugate diagonal maximal subgroups of G×G using outer automorphisms).*

## 67.8 Holomorphs

Given a group G with full automorphism group A, the holomorph of G is the semidirect product
G ×_θ A, where θ : A → Aut(G) is the identity map.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Holomorph(G)` / `Holomorph(GrpFP, G)` | For a finite permutation, matrix or pc-group G with full automorphism group A, return the semidirect product E of G by A as a permutation group of degree \|G\| (or as a finitely presented group if `GrpFP` is specified), in which G is a regular normal subgroup and A is the stabiliser of the point 1. Also returns the embedding map G → E and the natural epimorphism E → A. Generators of G appear first in E, followed by those of A. | Semidirect product construction via regular representation of G. |
| `Holomorph(G, A)` / `Holomorph(GrpFP, G, A)` | For a finite permutation, matrix or pc-group G and a specified group of automorphisms A, return the semidirect product E of G by A as a permutation group of degree \|G\| (or as a finitely presented group if `GrpFP` is specified), in which G is a regular normal subgroup and A is the stabiliser of the point 1. Also returns the embedding map G → E and the natural epimorphism E → A. Generators of G appear first in E, followed by those of A. | Semidirect product construction via regular representation of G. |

*Worked examples: H67E9 (holomorph of PGL(2,9): permutation group on 720 points, order 1036800, composition factors including two copies of Alt(6)).*
