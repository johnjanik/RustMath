# Chapter 59 — Matrix Groups over General Rings

**Handbook part:** IX — Finite Groups
**Handbook pages:** 1641–1708 (PDF pages 1770–1841)

---

## Scope and overview

Chapter 59 covers matrix groups defined over arbitrary rings in Magma. A matrix group G may
be defined over any ring R for which Magma can compute matrix inverses; however, the
availability of structural machinery depends heavily on properties of R.

Six cases are distinguished:

1. **Finite field (moderate degree):** If the orbit of a low-dimensional subspace under G is
   bounded by roughly a million, a Base and Strong Generating Set (BSGS) representation
   is constructed analogously to permutation groups **[But76]**, using the Murray–O'Brien
   **[MO95]** strategy to select base points.
2. **Finite field (large degree/size):** When a useful BSGS cannot be constructed, techniques
   based on Aschbacher's classification of maximal subgroups of GL(n,q) are used (see
   Chapter 65).
3. **Z/mZ (Euclidean ring):** If a vector in the natural R-module has a short enough orbit, BSGS
   machinery applies.
4. **Infinite ring, finiteness unknown:** For R = Z, Q, or an algebraic number field (including
   cyclotomic and quadratic fields), Magma can test whether G is finite or infinite. Infinite
   groups created outside the Lie-group framework provide little beyond element arithmetic.
5. **Infinite ring, G finite:** If R is a field or Euclidean Domain, the BSGS approach may still
   be applicable and structural computation is possible.
6. **Lie groups:** Infinite matrix groups creatable as Lie groups are handled by Lie-theoretic
   machinery (Chapter 103).

The chapter covers creation, homomorphisms, element arithmetic, global properties, conjugacy,
subgroups, quotients, actions, normal subgroups, coset tables, presentations, automorphism
groups, representation theory, BSGS construction and access, and soluble matrix groups. The
BSGS framework underpins virtually every structural algorithm in the chapter.

## 59.1 Introduction

### 59.1.1 Introduction to Matrix Groups

Introductory section; no intrinsics.

### 59.1.2 The Support

Matrix groups may be defined over any ring admitting matrix inverses. Structure algorithms
assume the group is finite and defined over a field, Euclidean Domain, or Z/mZ.

### 59.1.3 The Category of Matrix Groups

Matrix groups over a fixed ring R form a category (objects = groups, morphisms =
homomorphisms). The Magma category is `GrpMat`.

### 59.1.4 The Construction of a Matrix Group

Construction is a two-step process: (i) create GL(n,R); (ii) define G as a subgroup. The
`MatrixGroup< >` constructor combines these steps.

## 59.16 Base and Strong Generating Set

### 59.16.1 Introduction

Structural computation for a matrix group G requires a BSGS. A **base** B is a sequence of
distinct elements and submodules of the natural module M such that only the identity fixes B
pointwise. This determines a stabilizer chain G = G^(1) ≥ G^(2) ≥ ⋯ ≥ G^(n+1) = 1. A
**strong generating set** S satisfies G^(i) = ⟨S ∩ G^(i)⟩ for all i.

Unlike permutation groups, basic orbit lengths are not bounded by the degree but by
(q^n−1)/(q−1) for an n-dimensional group over GF(q). Finding short orbits (and hence a
good base) is critical but not guaranteed. The Murray–O'Brien **[MO95]** heuristics are used
when the standard base point would give an orbit exceeding 10,000.

### 59.16.2 Controlling Selection of a Base
