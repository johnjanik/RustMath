# Chapter 96 — Root Systems

**Handbook part:** XIII — Lie Theory
**Handbook pages:** 2829–2848 (PDF pages 2960–2981)

---

## Scope and overview

Chapter 96 describes Magma functions for computing with finite real root systems. A root
system R = (X, Φ, Y, Φ⋆) encodes the reflections of a reflection group (Chapter 99) and
is central to the theories of finite Coxeter groups (Chapter 98) and Lie algebras
(Chapter 100). The theoretical foundation is [Bou68].

A root system is a tuple of two paired vector spaces X (root space) and Y (coroot space)
over a field k, together with finite subsets Φ ⊆ X and Φ⋆ ⊆ Y satisfying: each
corresponding pair (α, α⋆) generates a reflection/coreflection, and both sets are closed
under the respective reflection actions. The base field k must be the rational field, a
number field, or a cyclotomic field; the real field is excluded because it lacks infinite
precision.

Key structural properties: a root system is *crystallographic* if ⟨α, β⋆⟩ is integral for
all roots α and coroots β⋆; *reduced* if αr, βr ∈ Φ with β a scalar multiple of α implies
α = ±β; *semisimple* if rank equals dimension; and *toral* if the root set is empty. The
irreducible nonreduced crystallographic type is BCn (the indivisible subsystem is Bn, and
every remaining root is twice a short root of Bn). The Cartan matrix, Coxeter matrix,
Coxeter diagram, Coxeter group, and Dynkin diagram are the same for a root system and
its indivisible subsystem, so constructors that are determined only by these data accept
an optional `Nonreduced` parameter to distinguish reducedness.

The chapter covers: constructors (from Cartan name strings, Coxeter matrices/graphs,
Cartan matrices, Dynkin digraphs, or explicit simple root/coroot matrices); operators and
structural invariants; properties; access to roots, coroots, reflections, root strings, and
additive orders; subsystem and direct sum constructions; and bridges to related structures
(root data, Coxeter groups, reflection groups, Lie algebras).

## 96.1 Introduction

### 96.1.1 Reflections

Let X and Y be vector spaces over a field k with bilinear pairing ⟨◦, ◦⟩: X × Y → k
identifying Y with the dual of X. For nonzero α ∈ X and α⋆ ∈ Y, the reflection
sα: X → X is defined by xsα = x − ⟨x, α⋆⟩α, and the coreflection s⋆α: Y → Y by
ys⋆α = y − ⟨α, y⟩α⋆. These are reflections iff ⟨α, α⋆⟩ = 2 (equivalently, sα² = 1).
In Magma, X = Y is typically a row space with the standard inner product ⟨x, y⟩ = xyᵀ,
though X and Y may be distinct subspaces. Reflection functions are described in
Section 99.2.

### 96.1.2 Definition of a Root System

The tuple R = (X, Φ, Y, Φ⋆) is a root system if for every α ∈ Φ: (1) sα and s⋆α are
reflections; (2) Φ is closed under sα; and (3) Φ⋆ is closed under s⋆α. The elements of
Φ are roots; the elements of Φ⋆ are coroots.

### 96.1.3 Simple and Positive Roots

A subset ∆ ⊆ Φ is a set of simple roots if ∆ is a basis for the root span kΦ and
Φ = Φ⁺ ∪ Φ⁻ where Φ⁺ consists of linear combinations of ∆ with nonnegative coefficients
and Φ⁻ = −Φ⁺. The rank of R is |∆|; the dimension is dim X. A reduced root system is
determined by the matrix A of simple roots (Aij = ⟨αi, fj⟩) and the matrix B of simple
coroots (Bij = ⟨ej, α⋆i⟩).

### 96.1.4 The Coxeter Group

The group W generated by the reflections sα for simple α is a finite Coxeter group. The
Cartan matrix is C = ABᵀ, with entry Cij = ⟨αi, α⋆j⟩. Crystallographicity of R is
equivalent to integrality of C. The classification of Section 95.6 applies to reduced
semisimple root systems; the isomorphism class is determined by the Coxeter graph and
dimension. The Coxeter form is the W-invariant bilinear form on X normalised so short
roots in each crystallographic component have length one.

### 96.1.5 Nonreduced Root Systems

A root α with 2α ∉ Φ is called reduced (indivisible); a root with ½α ∈ Φ is called
divisible. The indivisible subsystem R0 consists of all indivisible roots. For an
irreducible nonreduced crystallographic root system of rank n, R0 is of type Bn and every
remaining root is twice a short root of R0; the Cartan type of R is BCn. When constructing
a nonreduced root system from a Cartan matrix or diagram, the `Nonreduced` parameter
specifies which simple roots are non-reduced.

## 96.2 Constructing Root Systems

Several optional parameters are common to many constructors:

- `RealInjection` (Any, default `false`): an injection into the real field (for number
  field bases) or into the complex field taking real values on the Cartan entries (for
  cyclotomic bases), used to identify field elements with real numbers.
- `Nonreduced` (SetEnum, default `{}`): indices of simple roots that are non-reduced;
  needed when the input does not uniquely determine reducedness.
- `Symmetric` (BoolElt, default `false`): use the symmetric Cartan matrix (always used
  for types I₂(m), H3, H4 since otherwise the root system would be non-reduced).
- `BaseField` (MonStgElt, default `"NumberField"`): field for Cartan matrix entries;
  `"NumberField"` (Chapter 34), `"Cyclotomic"` / `"SparseCyclotomic"` (sparse
  cyclotomic, Chapter 36), or `"DenseCyclotomic"` (dense cyclotomic, Chapter 36).

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `RootSystem(N)` | Root system with Cartan name given by string `N`. Accepts all names from Section 95.6 plus `"BCn"` (irreducible nonreduced) and `"Tn"` (n-dimensional toral; does not appear in `CartanName` output). Parameters: `Symmetric`, `BaseField`. | Classification lookup by Cartan name. |
| `RootSystem(M)` | Semisimple root system with Coxeter matrix `M` (see Chapter 95). Errors if the corresponding Coxeter group is infinite. Parameters: `Nonreduced`, `Symmetric`, `BaseField`. | — |
| `RootSystem(G)` | Semisimple root system with Coxeter graph `G` (see Chapter 95). Errors if the Coxeter group is infinite. Parameters: `Nonreduced`, `Symmetric`, `BaseField`. | — |
| `RootSystem(C)` | Semisimple root system with Cartan matrix `C` (see Chapter 95). Errors if the Coxeter group is infinite. Parameters: `RealInjection`, `Nonreduced`. | — |
| `RootSystem(D)` | Semisimple crystallographic root system with Dynkin diagram `D` (see Chapter 95). Errors if the Coxeter group is infinite. Parameter: `Nonreduced`. | — |
| `RootSystem(A, B)` | Root system with simple roots as rows of matrix `A` and simple coroots as rows of matrix `B`. Requirements: same number of rows and columns, same base ring (Z, Q, number field, or cyclotomic field); number of columns ≥ rows; ABᵀ is the Cartan matrix of a finite Coxeter group. Parameters: `RealInjection`, `Nonreduced`. | — |
| `IrreducibleRootSystem(X, n)` | Irreducible root system with Cartan name Xn (or I₂(n) if X = `"I"`). Allows `"BCn"` for the irreducible nonreduced system. Parameters: `Symmetric`, `BaseField`. | Classification lookup. |
| `StandardRootSystem(X, n)` | Standard root system with Cartan name Xn (or I₂(n) if X = `"I"`), i.e. the root system whose Coxeter form equals the standard inner product. Allows `"BCn"`. For type An, the standard root system is not semisimple. | — |
| `ToralRootSystem(n)` | The toral root system of dimension n: n-dimensional root system with no roots or coroots. | — |
| `TrivialRootSystem()` | The trivial root system of dimension 0. | — |

*Worked examples: H96E1 (Cartan names "H3 E6" and "A2 T1 I2(5)"); H96E2 (root system from Coxeter matrix, and error for infinite type); H96E3 (nonsemisimple G2 from explicit A, B matrices); H96E4 (crystallographic filter among I2(n) for n = 3..20).*

## 96.5 Roots and Coroots

Roots are stored as the indexed set {@ α₁, …, αN, αN+1, …, α₂N @} where α₁, …, αN are
positive roots in height-compatible order and αN+i = −αi are the corresponding negative
roots. The simple roots are α₁, …, αn where n = rank. Most functions accept an optional
`Basis` parameter: `"Standard"` (default, standard basis for the (co)root space) or
`"Root"` (basis of simple (co)roots).

### 96.5.1 Accessing Roots and Coroots

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `RootSpace(R)` | The vector space X containing the roots of R. | — |
| `CorootSpace(R)` | The vector space Y containing the coroots of R. | — |
| `SimpleRoots(R)` | The simple roots of R as rows of a matrix (matrix A). | — |
| `SimpleCoroots(R)` | The simple coroots of R as rows of a matrix (matrix B). | — |
| `NumberOfPositiveRoots(R)` / `NumPosRoots(R)` | The number of positive roots of R. The total number of (co)roots is twice this. | — |
| `Roots(R)` | The indexed set of all (co)roots {@ α₁, …, α₂N @}. Parameter: `Basis`. | — |
| `Coroots(R)` | The indexed set of all coroots {@ α⋆₁, …, α⋆₂N @}. Parameter: `Basis`. | — |
| `PositiveRoots(R)` | The indexed set of positive roots {@ α₁, …, αN @}. Parameter: `Basis`. | — |
| `PositiveCoroots(R)` | The indexed set of positive coroots {@ α⋆₁, …, α⋆N @}. Parameter: `Basis`. | — |

### 96.5.2 Reflections

The root αr acts on the root space via the reflection sαr; the coroot α⋆r acts on the
coroot space via the coreflection s⋆αr.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `SimpleReflectionMatrices(R)` | Sequence of matrices for the action of simple roots on the root space: sα₁, …, sαn. Parameter: `Basis`. | — |
| `SimpleCoreflectionMatrices(R)` | Sequence of matrices for the action of simple coroots on the coroot space: s⋆α₁, …, s⋆αn. Parameter: `Basis`. | — |
| `ReflectionMatrices(R)` | Sequence of matrices for the action of all roots on the root space: sα₁, …, sα₂N. Parameter: `Basis`. | — |
| `CoreflectionMatrices(R)` | Sequence of matrices for the action of all coroots on the coroot space: s⋆α₁, …, s⋆α₂N. Parameter: `Basis`. | — |
| `ReflectionMatrix(R, r)` | Matrix for the action of the rth root on the root space: sαr. Parameter: `Basis`. | — |
| `CoreflectionMatrix(R, r)` | Matrix for the action of the rth coroot on the coroot space: s⋆αr. Parameter: `Basis`. | — |
| `SimpleReflectionPermutations(R)` | Sequence of permutations for the action of simple (co)roots on the (co)roots. The action is the same for roots and coroots. | — |
| `ReflectionPermutations(R)` | Sequence of permutations for the action of all (co)roots on the (co)roots. | — |
| `ReflectionPermutation(R, r)` | Permutation for the action of the rth (co)root on the (co)roots. | — |
| `ReflectionWords(R)` | Sequence of words in simple reflections for all reflections of R. Each word is a sequence of integers [a₁, …, al] such that sαr = sαa₁ · ⋯ · sαal. | — |
| `ReflectionWord(R, r)` | Word in simple reflections for the rth reflection of R. | — |

*Worked example: H96E12 (B3: consistency check that reflection matrix, permutation, and word all agree on the 4th root; coreflection matrix consistency).*

## 96.6 Building Root Systems

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `sub< R \| a >` | Root subsystem of R generated by the roots {αa₁, …, αak} where a = {a₁, …, ak} is a set of integers. | — |
| `sub< R \| s >` | Root subsystem of R generated by the roots {αs₁, …, αsk} where s = [s₁, …, sk] is a sequence of integers. These roots must be simple in the subsystem (none a summand of another; otherwise an error is signalled). Simple roots appear in the subsystem in the given order. | — |
| `R1 subset R2` | Returns true iff the root system R1 is a subset of R2. If true, also returns an injection as a sequence of roots. | — |
| `R1 + R2` / `DirectSum(R1, R2)` | Direct sum of root systems R1 and R2. The root space of the result is the direct sum of the root spaces. | — |
| `R1 join R2` | Union of root systems R1 and R2. Both must have the same root space, which is also the root space of the result. | — |
| `DirectSumDecomposition(R)` / `IndecomposableSummands(R)` | The set of irreducible direct summands of the semisimple root system R. | — |
| `Dual(R)` | The dual of R, obtained by swapping roots and coroots. | — |
| `IndivisibleSubsystem(R)` | The root system consisting of all indivisible roots of R. | — |

*Worked examples: H96E16 (A1 A1 subsystems, direct sum vs join for same and differing root spaces; A3T2B4T3 + T3G2T4BC3 giving dimension-24 and dimension-12 results); H96E17 (H4 + Dual(B4) = H4 C4; IndivisibleSubsystem of BC2 is B2; subset injection).*
