# Chapter 131 — Arithmetic Fuchsian Groups and Shimura Curves

**Handbook part:** XVII — Modular Arithmetic Geometry
**Handbook pages:** 4363–4383 (PDF pages 4494–4517)

---

## Scope and overview

This chapter documents algorithms for **arithmetic Fuchsian groups**. Let `F` be a totally real
number field and let `A` be a *quaternion algebra* over `F` (a central simple algebra of dimension 4,
see Chapter 86) that is split at exactly one real place, corresponding to the injective map
ι∞ : A → M₂(**R**). Let `O` be a maximal order in `A` (see also Section 81.4), let `O*` denote the
group of elements of `O` of reduced norm 1, and let Γ(1) = ι∞(O*)/{±1} ⊂ PSL₂(**R**). An *arithmetic
Fuchsian group* Γ is a discrete subgroup of PSL₂(**R**) commensurable with Γ(1) (for some choice of
`F` and `A`).

The classical case of the modular groups corresponds to `F = Q`, `A = M₂(Q)`, `O = M₂(Z)`, and
Γ(1) = PSL₂(**Z**); specialized algorithms for that case are treated in Chapter 130. To exclude it,
the chapter assumes throughout that `A` is a division ring, equivalently `A ≇ M₂(Q)`.

The group Γ acts properly and discontinuously on the upper half-plane **H**, and the quotient
Γ\**H** = X(Γ) can be given the structure of a compact Riemann surface, called a **Shimura curve**.
The chapter exhibits methods for computing the basic invariants of Γ and a fundamental domain for
X(Γ), an interface for computing with the Poincaré unit disc (parallel to the upper half-plane
interface of Chapter 130), specialized algorithms for **triangle groups**, and the computation of
**CM points** on Shimura curves.

The algorithm used to compute fundamental domains is described in Voight **[Voi09]**; it relies on a
"reduction theory" with respect to a set of generators of Γ, recursively decreasing the hyperbolic
volume of an intersection of half-spaces until the volume vol(X) is reached. Recommended additional
reading: Katok **[Kat92]** and Beardon **[Bea77]** for Fuchsian groups; Vignéras **[Vig80]** for
their relationship to quaternion algebras; Alsina–Bayer **[AB04]**, Elkies **[Elk98]** and Voight
**[Voi05]** for arithmetic Fuchsian groups and Shimura curves; and Voight **[Voi06]** for triangle
groups.

### 131.1.2 Quaternionic Functions

Functions related to quaternion algebras that underlie the other functions in this chapter. Let `A`
be a quaternion algebra over a totally real field `F` in standard form, generated by α, β with
α² = a, β² = b, βα = −αβ. When `A` has a unique split real place `v` (taken as the identity, viewing
`F ⊂ R`), the embedding ι : A → M₂(**R**) is defined by α ↦ diag(√a, −√a) and
β ↦ ((0, √|b|), (sgn(b)√|b|, 0)). The reduced norm nrd(γ) = x² − ay² − bz² + abw² is not a Euclidean
norm, so one instead uses nrd′(γ) = x² + |a|y² + |b|z² + |ab|w², giving the definite norm
N(γ) = nrd′(γ) + Σ_{σ≠id} σ(nrd(γ)) used in the application to fundamental domains.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `QuaternionOrder(G)` | The order in some quaternion algebra that was used to define the Fuchsian group `G`. | Accessor. |
| `BaseRing(G)` | The order in some quaternion algebra that was used to define the Fuchsian group `G`. | Accessor. |
| `QuaternionAlgebra(G)` | The quaternion algebra used to define the Fuchsian group `G`. | Accessor. |
| `SplitRealPlace(A)` | The unique real place at which `A` is split, if it exists. | Tests the splitting behaviour at each real place. |
| `FuchsianMatrixRepresentation(A)` | The map `A → M₂(R)` (the embedding ι defined above) when `A` has a unique split place. | Embedding ι : A → M₂(**R**) at the unique split place. |
| `DefiniteNorm(gamma)` | The definite norm `N(γ)` of γ ∈ A for `A` a quaternion algebra with a unique split real place. | The definite norm `N(γ) = nrd′(γ) + Σ_{σ≠id} σ(nrd(γ))`. |
| `DefiniteGramMatrix(B)` | The definite Gram matrix for the basis `B` of a quaternion algebra `A` with a unique split real place. | Gram matrix of the definite norm with respect to `B`. |
| `MultiplicativeOrder(gamma)` | The order of the element γ of a quaternion algebra: a finite number, or 0 if γ has infinite order. Parameter `PlusMinus` (default `true`): if `true`, compute the order in the group of units modulo ±1. | Determines the multiplicative order, optionally modulo {±1}. |
| `Quaternion(g)` | For `g` an element of an arithmetic Fuchsian group, the underlying element of the quaternionic order. | Accessor. |

*Worked example:* H131E2 (quaternion algebra over `F = Q(√5)` ramified at the prime 2 and the second
real place ∞₂; `StandardForm`, `SplitRealPlace`, `FuchsianMatrixRepresentation`, `DefiniteNorm`).

### 131.1.3 Basic Invariants

The basic invariants associated to an arithmetic Fuchsian group Γ. The hyperbolic volume vol(X) of
the orbit space X = Γ\**H** is computed via a formula of Shimizu:
vol(X) = (1/2)^{d−2} ζ_F(−1) ∏_{p | disc A} (N(p) − 1), where d = [F : **Q**]; with this
normalization vol(X) is rational and an ideal triangle has volume 1/2. The signature (g; m₁,…,m_t)
records the genus `g` of `X` and the orders m₁,…,m_t of the `t` elliptic cycles (Γ-conjugacy classes
of elliptic points). The number of elliptic cycles of each order is computed by a formula requiring
the relative class group of a CM extension of number fields; the genus then follows from the
Riemann–Hurwitz formula vol(X) = 2g − 2 + Σᵢ (1 − 1/mᵢ).

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `ArithmeticVolume(G)` | The hyperbolic volume of the quotient of the upper half-plane by `G` for an arithmetic Fuchsian group `G`. The volume is normalized arithmetic volume (the "usual" volume divided by 2π), giving an ideal triangle volume 1/2. | Shimizu's volume formula `vol(X) = (1/2)^{d−2} ζ_F(−1) ∏_{p\|disc A}(N(p)−1)`. |
| `EllipticInvariants(G)` | The number of elliptic cycles of `G` as a sequence of elliptic orders and their multiplicities. | Counting formula via the relative class group of a CM extension. |
| `Signature(G)` | The signature `(g; m₁,…,m_t)` of the arithmetic Fuchsian group `G`. | Elliptic-cycle counting plus Riemann–Hurwitz for the genus. |

### 131.1.4 Group Structure

Computes a finite presentation for Γ. If Γ has signature (g; m₁,…,m_t), there exists a standard
presentation generated freely by α₁, β₁,…,α_g, β_g, γ₁,…,γ_t with relations
γ₁^{m₁} = … = γ_t^{m_t} = [α₁, β₁]···[α_g, β_g]γ₁···γ_t = 1, where [αᵢ, βᵢ] = αᵢβᵢαᵢ⁻¹βᵢ⁻¹. When
g = 0 there is an algorithm to reconstruct the standard presentation; for g > 0 only a finite
presentation is obtained, and constructing a standard one may be impractical. The algorithm uses a
fundamental domain `F` for Γ (see Section 131.3): the side-pairing elements are provably generators,
and the relations are the minimal loops in a graph recording the side pairings.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Group(G)` | A presentation `U` for the arithmetic Fuchsian group `G`, a map `U → G`, and a map `U → O` where `O` is the quaternion order corresponding to `G`. | Side-pairing elements of a fundamental domain as generators; relations from minimal loops in the side-pairing graph **[Voi09]**. |

*Worked example:* H131E3 (basic invariants of the group of the discriminant-6 quaternion algebra
over **Q**: `ArithmeticVolume`, `EllipticInvariants`, `Genus`, `Signature`, verification of
Riemann–Hurwitz, and finite presentations via `Group` — including an order-11 elliptic cycle over
`F = Q(ζ₁₁)⁺` and the torsion-free group of discriminant 35).

## 131.2 Unit Disc

Let `D` denote the Poincaré unit disc D = {z ∈ **C** : |z| < 1}, equipped with the hyperbolic metric
d(z, w) = log((|1 − z·w̄| + |z − w|)/(|1 − z·w̄| − |z − w|)). This section mimics the upper half-plane
functionality of Chapter 130 to compute with the geometry of the unit disc (angles, intersections,
areas, and so on).

## 131.3 Fundamental Domains

Let `D` denote the unit disc and Γ an arithmetic Fuchsian group. A *fundamental domain* in `D` for Γ
is a closed, hyperbolically convex region P ⊂ D whose Γ-translates cover `D` with disjoint interiors.
Choosing a point `p` (typically `p = 0`) not fixed by any element of Γ\{1}, one takes
P = {z ∈ D : d(z, p) ≤ d(z, γ(p)) for all γ ∈ Γ}. Defining the *isometric circle* of γ as
C(γ) = {z ∈ **C** : |γ(z)| = |z|}, `P` is the closure of the intersection of half-spaces
∩_{γ ∈ Γ\{1}} C(γ)°, where C(γ)° is the exterior of C(γ). The algorithm recursively finds elements of
Γ that decrease the hyperbolic volume of this intersection until vol(X) is reached, relying on a
reduction theory with respect to a set of generators of Γ **[Voi09]**.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `FundamentalDomain(G, D)` | A fundamental domain in the unit disc `D` for the action of `G`. | Reduction-theoretic intersection of isometric-circle exteriors **[Voi09]**. |
| `FundamentalDomain(G)` | A fundamental domain in the upper half-plane for the action of `G`. | As above, in the upper half-plane model **[Voi09]**. |
| `ShimuraReduceUnit(delta, gammagens, G, D)` | Reduce the unit `delta`, moving `z₀` to `z₁` with respect to the generators `gammagens`, by left/right multiplication by elements of `gammagens` inside `G` to minimize the distance to the origin in `D`. Returns a sequence of triples of reduced elements and the left/right sequences used to obtain them. Parameters: `CreateWord` (BoolElt, default `false`; reduce δ even if it lies in `gammagens`, disallowing the trivial word), `NextSmallest` (BoolElt, default `false`), `z0` (SpcHydElt, default 0), `z1` (SpcHydElt, default 0). | Reduction with respect to the generators by distance-minimizing left/right multiplication. |

*Worked example:* H131E7 (fundamental domain for a quaternion algebra over `Q(ζ₇)⁺` that turns out to
be the (2,3,7)-triangle group; `FundamentalDomain` in `D` and `H`, `ArithmeticVolume`,
`DisplayPolygons`; repeated for the discriminant-10 algebra over **Q** with its presentation via
`Group`).

## 131.4 Triangle Groups

A class of arithmetic Fuchsian groups for which Γ(1) is a *triangle group*, i.e. Γ has signature
(0; p, q, r) for p, q, r ∈ **Z**≥2, with presentation
Γ(1) ≅ ⟨γ_p, γ_q, γ_r | γ_p^p = γ_q^q = γ_r^r = γ_p γ_q γ_r = 1⟩. Since g = 0 there is a map `j` from
X(1)_**C** to the projective line over **C**, ramified only above the three *elliptic points* (fixed
points of γ_p, γ_q, γ_r, taken to be 0, 1, ∞). There are only finitely many such triples (p, q, r);
the constructor yields Γ together with arithmetic data (maximal order `O` and quaternion algebra `A`)
and computes the analytic map `j`, with methods for evaluating the ₂F₁-hypergeometric series to very
high precision at complex arguments.

### 131.4.1 Creation of Triangle Groups

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `ArithmeticTriangleGroup(p, q, r)` | The arithmetic triangle group of signature `(p, q, r)`. | Looks up the quaternion data realizing the triangle group of the given signature. |
| `AdmissableTriangleGroups()` | The list of arithmetic triangle groups currently implemented. | Table of implemented signatures. |
| `IsTriangleGroup(G)` | Returns `true` if and only if `G` was created as an arithmetic triangle group. | Accessor flag. |

### 131.4.2 Fundamental Domain

| Intrinsic | Description |
|-----------|-------------|
| `ReduceToTriangleVertices(G, z)` | Points in the `G`-orbit of `z` which are nearest to the vertices of the fundamental domain, for `G` a triangle group. |

### 131.4.3 CM Points

For triangle groups, CM points are computed analytically. By work of Shimura, X(1) is a moduli space
for certain abelian varieties and has a canonical model over **Q**. For `K` a totally imaginary
quadratic extension of `F` and `O_D ⊂ K` a quadratic order with `K` splitting `A` (so
A ⊗_F K ≅ M₂(K)), there is an embedding ι_K : K ↪ A with ι_K(K) ∩ O = O_D, given by an element
μ ∈ O with **Z**_F[μ] ≅ O_D; the unique fixed point of ι∞(μ) in **H** yields a *CM point* on X(1)
defined over an abelian extension `H` of `F`, with a reciprocity law describing the action of
Gal(H/K). The algorithm computes representatives for the ring class group via the Artin map, then
applies the Shimura reciprocity law (using principalization of ideals of quaternionic orders) to
compute the Gal(H/K)-conjugates; given the points to high enough precision, the CM point is
recognized as a putative algebraic number.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `HypergeometricSeries2F1(A, B, C, z)` | The value of the ₂F₁-hypergeometric function with parameters `(A, B; C)` at the complex number `z`. | High-precision evaluation of the ₂F₁ series. |
| `ShimuraConjugates(mu)` | The set of conjugates of the quaternion order element `μ` under the Shimura reciprocity law. | Shimura reciprocity law via ring-class-group representatives and ideal principalization. |
| `jParameter(G, z)` | The value of the map `j : X(G) → P¹` at `z`, for `G` an arithmetic triangle group. Parameters: `Bound` (RngIntElt, default 200), `Precision` (RngIntElt, default 100). | Analytic uniformizing map evaluated via the ₂F₁-hypergeometric reversion. |
| `CMPoints(G, mu)` | The minimal polynomial of the Galois conjugates of the CM points corresponding to `μ` and their complex values, for `G` a triangle group. `μ` must be Galois-stable (F(μ) Galois over `F`, `F` the defining base field of `G`). The returned polynomial is the "best guess" rational approximation to the polynomial with the CM points as roots. | Shimura reciprocity law (computing Galois conjugates), then rational recognition of the minimal polynomial. |

*Worked examples:* H131E8 (`HypergeometricSeries2F1` evaluated independently at complex arguments and
high precision); H131E9 ((2,3,9)-triangle group, CM point for `K/F` of discriminant −7 with class
number 1: `jParameter`, `BestApproximation`, recognizing j(z) = 3⁵·7·19²/2⁶); H131E10 ((2,3,9)-triangle
group, CM points generating a nontrivial degree-3 extension via `CMPoints`, recognizing the Hilbert
class field of `K` analytically).
