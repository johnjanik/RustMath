# Chapter 90 — K[G]-Modules and Group Representations

**Handbook part:** XII — Representation Theory
**Handbook pages:** 2723–2755 (PDF pages 2854–2889)

---

## Scope and overview

A module over a group algebra K[G], where K is a field and G is a group, is an important special case of modules over an algebra and coincides with the theory of group representations. Magma provides extensive machinery for constructing K[G]-modules. Some advanced functions apply only when K is a finite field. An Euclidean Domain may appear in place of K in many construction functions.

All operations for general A-modules also apply to K[G]-modules and are not repeated in this chapter; only constructions and operations peculiar to the K[G] setting are documented here.

The chapter covers: construction of K[G]-modules (from matrix algebras, natural actions, elementary abelian sections, permutation actions, polynomial rings); extracting the afforded representation; standard algebraic constructions (base-ring change, field minimisation, direct sums, tensor products, induction/restriction, fixed-point spaces, basis change); construction of all irreducible modules via the Burnside algorithm (MeatAxe-based, for non-soluble groups over finite fields), Schur's algorithm (for soluble groups, over finite fields or characteristic-zero fields), and a rational algorithm for arbitrary finite groups; module extensions; projective indecomposable modules with Cartan and decomposition matrices; and cohomological dimension via dimension shifting.

## 90.5 The Construction of all Irreducible Modules

For a **soluble** G, the classical method due to Schur works up a composition series for G, constructing irreducibles for each subgroup by inducing or extending representations from the previous level. This works over finite fields and over characteristic-zero fields.

For a **non-soluble** G, by a theorem of Burnside, all representations can be found by splitting tensor powers of a faithful representation. Magma's implementation, due to Cannon and Holt, uses the **MeatAxe** to split representations and works well over small finite fields. A similar algorithm for rational representations using a different splitting method is under development by Steel. Methods based on the Burnside theorem are called **Burnside algorithms**.

### 90.5.1 Generic Functions for Finding Irreducible Modules

The functions in this section choose the algorithm automatically based on the type of G and the field K. For soluble G, Schur's algorithm is used by default; for non-soluble G, the Burnside method is used. Since V2.16, when K is the rational field, a new rational algorithm is used by default.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `IrreducibleModules(G, K : parameters)` | Given finite group G and field K, construct all irreducible K[G]-modules. If G is soluble, K may be a finite field, the rational field, or a cyclotomic field whose order divides the exponent of G. If G is non-soluble, K is currently restricted to a finite field or the rational field. Parameters: `Alg` (override default algorithm choice), `DimLim` (default 2000; maximum dimension for Burnside splitting — if limit prevents finding all irreducibles, a warning is output and found modules are returned). | Schur's algorithm for soluble G; Burnside/MeatAxe (Cannon–Holt) for non-soluble G over finite fields; rational algorithm (Steel) when K = Q since V2.16. |
| `AbsolutelyIrreducibleModules(G, K : parameters)` | As `IrreducibleModules` but constructs all absolutely irreducible K[G]-modules (over extensions of K as needed). Same field restrictions and parameters. | As above. |

*Worked example: H90E13 (group of order 416 = 2⁵·13; irreducible modules computed over GF(2), GF(13), the rational field (17 modules), and the splitting field Q(ζ₁₀₄) (53 modules = #conjugacy classes)).*

### 90.5.2 The Burnside Algorithm

The Burnside algorithm starts with a faithful permutation module over the given field, splits it into irreducibles using the MeatAxe, then forms tensor products of modules found so far to discover further irreducibles. Restricted to permutation groups and finite fields. A warning is printed if not all irreducibles are found.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `AbsolutelyIrreducibleModulesBurnside(G, K : parameters)` | Given finite permutation group G and finite field K, construct all absolutely irreducible K[G]-modules (over extensions of K). Parameter: `DimLim` (default 2000; maximum dimension considered for splitting). | Burnside algorithm using MeatAxe for splitting (Cannon–Holt); restricted to permutation groups. |
| `IrreducibleModulesBurnside(G, K : parameters)` | Given finite permutation group G and finite field K, construct all irreducible K[G]-modules over K. Parameter: `DimLim` (default 2000). | Burnside algorithm using MeatAxe (Cannon–Holt); restricted to permutation groups. |
| `AbsolutelyIrreducibleConstituents(M)` | Given an irreducible module M, return M if it is already absolutely irreducible; otherwise return the absolutely irreducible modules obtained by finding the constituents of M after extending the base field to a splitting field. | Field extension + MeatAxe constituent splitting. |

*Worked example: H90E14 (all irreducible modules for M₁₁ over GF(2), then all absolutely irreducible modules of characteristic 2; Burnside algorithm used by default).*

### 90.5.4 The Rational Algorithm

Magma V2.16 introduced a new algorithm (selected by default when K = Q) for constructing irreducible rational representations of an arbitrary finite group. Given an irreducible complex character χ, the sum of its Galois orbit gives an irreducible rational character. The Schur index of a rational character χ is the Schur index of an irreducible complex character whose Galois orbit sum is χ. The sequence of all irreducible rational characters (sorted by degree) is the rational character table. The character of the i-th irreducible module L[i] is always sᵢ·C[i], where sᵢ is the Schur index of C[i], so the dimension of L[i] is sᵢ·Deg(C[i]).

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `IrreducibleModules(G, Q : parameters)` | Given finite group G, return a sequence L of all irreducible rational K[G]-modules and the rational character table of G as a sequence C matching L. Parameters: `MaxDegree` (positive integer D; do not spend effort on modules with rational character degree > D, though some larger modules may be returned anyway as side effects), `Characters` (set/sequence S of characters; attempt to construct only modules for characters in S), `CharacterDegrees` (set/sequence I of positive integers; equivalent to setting `Characters` to rational characters with degree in I), `UseInduction` (default true; search for subgroups Hᵢ of G for which inducing rational Hᵢ-modules to G yields G-modules from which irreducible G-modules can be computed; set false if G has many subgroups and induction is slow). | Rational algorithm (Steel); Schur-index computation; induction from subgroups. |
| `RationalCharacterTable(G)` | Given finite group G, return the rational character table of G as a sequence C of irreducible rational characters (sorted by degree), and an index sequence I such that C[i] is the sum of the Galois orbit of T[I[i]], where T is the ordinary character table. | Galois orbit computation on the ordinary character table. |

*Worked examples: H90E16 (PSL(3,3): rational character table matches characters of the 8 irreducible rational modules computed in 0.76 seconds); H90E17 (M₂₃: rational character table with 12 entries; using `MaxDegree := 253` computes 6 small modules plus the 1980-dimensional module as a side effect of tensor product operations; total time 23.4 seconds).*

## 90.6 Extensions of Modules

For K[G]-modules M and N, the K-vector space Ext(M, N) of equivalence classes of K[G]-module extensions 0 → N → L → M → 0 can be computed and corresponding extension modules constructed.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Ext(M, N)` | Given K[G]-modules M and N, construct the K-vector space Ext(M, N) of equivalence classes of K[G]-module extensions of N by M. | Cohomological computation (degree-1 cohomology). |
| `Extension(M, N, e)` | Given K[G]-modules M and N and element e of the vector space E returned by a previous call to `Ext(M,N)`, construct the extension K[G]-module L of N by M corresponding to e. Also returns the injection N → L and projection L → M. | Cocycle construction. |
| `MaximalExtension(M, N, E)` | Given E the vector space from `Ext(M,N)`, construct the largest possible K[G]-module extension L of a direct sum of copies of N by M such that none of the submodules of L isomorphic to N has a complement in L. | Maximally non-split extension construction. |

*Worked example: H90E18 (Alt(5) over GF(2); irreducible modules of dimensions 1 and 4; computing Ext, constructing a 5-dimensional extension, and a maximal 6-dimensional extension with composition factors 1+1+4).*

## 90.7 The Construction of Projective Indecomposable Modules

For a finite group G and finite field K, the projective indecomposable K[G]-modules are in one-to-one correspondence with the irreducible K[G]-modules: the projective indecomposable module P corresponding to irreducible I has Socle(P) ≅ P/JacobsonRadical(P) ≅ I.

The functions described here construct projective indecomposables for finite groups of moderate order (up to around 10⁶, depending on the example). Large-dimensional projective indecomposables can sometimes be constructed using condensation techniques, which carry out computations in condensed modules of significantly smaller dimension. These methods work best for permutation groups and PC-groups. The verbose flag `"KGModule"` may be set to 1 or 2 to show details.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `ProjectiveIndecomposableDimensions(G, K)` | Return the K-dimensions of the projective indecomposable K[G]-modules corresponding to the irreducible K[G]-modules returned by `IrreducibleModules(G,K)`. | Computed quickly from the Brauer characters of the irreducible modules, using the Cartan matrix. |
| `ProjectiveIndecomposableModule(I : parameters)` | Construct and return the projective indecomposable K[G]-module P corresponding to the irreducible K[G]-module I. Socle(P) ≅ P/JacobsonRadical(P) ≅ I. Parameter: `condensation` (default false; if true, attempt to find a subgroup allowing computations in condensed modules). | Condensation-based construction (optional). |
| `ProjectiveIndecomposableModules(G, K)` | Construct the complete list of projective indecomposable K[G]-modules corresponding to all irreducible K[G]-modules from `IrreducibleModules(G,K)`. Parameter: `condensation` (default false). | Condensation-based construction (optional). |
| `CartanMatrix(G, K)` | Let k be the number of irreducible K[G]-modules. Return the k × k Cartan matrix C, where Cᵢⱼ is the number of times the j-th irreducible K[G]-module appears as a constituent of the i-th projective indecomposable K[G]-module. Note: C need not be symmetric. | Brauer character computation. |
| `AbsoluteCartanMatrix(G, K)` | The Cartan matrix of G over an extension L of K large enough for all irreducible L[G]-modules to be absolutely irreducible. Rows and columns correspond to `AbsolutelyIrreducibleModules(G,K)`. This is the symmetric Cartan matrix in characteristic p of K as defined in modular representation theory, and equals the standard textbook Cartan matrix. | Brauer character computation. |
| `DecompositionMatrix(G, K)` | The decomposition matrix D of G in characteristic p of K. Entry Dᵢⱼ is the number of times the j-th absolutely irreducible K[G]-module occurs as a constituent of the i-th ordinary irreducible G-module over C reduced modulo p. Note: DᵀD equals the absolute Cartan matrix. | Brauer character / ordinary character reduction modulo p. |
| `ProjectiveCover(M)` | Compute the projective cover P of K[G]-module M together with a K[G]-module epimorphism P → M returned as a matrix. If Pᵢ corresponds to irreducible Iᵢ and M/JacobsonRadical(M) ≅ ⊕ⱼ Iᵢⱼ, then P ≅ ⊕ⱼ Pᵢⱼ. | Projective cover via Jacobson radical. |
| `CohomologicalDimension(M, n)` | For K[G]-module M (K finite field, G finite group), compute and return the K-dimension of the cohomology group Hⁿ(G, M) for n ≥ 0. For n = 0 and 1, uses functions from Chapter 68. For n ≥ 2, proceeds recursively using projective covers and dimension shifting to reduce to the case n = 1. (For n = 2, the method differs from the Chapter 68 cohomology-module approach.) | Dimension shifting via projective covers, reducing to n = 1; Chapter 68 functions for n ≤ 1. |
| `CohomologicalDimensions(M, n)` | For K[G]-module M (K finite field, G finite group), compute and return the sequence of K-dimensions of cohomology groups Hᵏ(G, M) for 1 ≤ k ≤ n. More efficient than computing them individually due to the shared recursive structure. | Recursive dimension shifting; quicker than repeated `CohomologicalDimension` calls. |

*Worked examples: H90E19 (projective indecomposable modules for Alt(8) over GF(2); 8 irreducibles of dimensions 1, 4, 4, 6, 14, 20, 20, 64; projective indecomposable dimensions 448, 192, 192, 320, 320, 192, 192, 64; composition factors of the first projective module listed); H90E20 (cohomological dimensions H¹ through H⁴ for each irreducible of Alt(8) over GF(2); also H¹–H⁶ for the trivial module using `CohomologicalDimensions`).*
