**Handbook part:** VIII — Modules

## Scope and overview

Chapter 55 covers finitely generated modules over Dedekind domains in Magma — concretely,
modules over the maximal order Ok of a number field or function field (type `ModDed`).
Because the structure theory for modules over arbitrary (non-maximal) orders is
unsatisfactory, Magma restricts to modules over maximal orders only.

The central representation is the **pseudo-matrix**: a column vector of (fractional) ideals
A = (A₁, …, Am)ᵀ paired with a matrix A ∈ kᵐˣʳ, representing the module
M = ∑ᵢ Aᵢαᵢ. The ideals Aᵢ are called **coefficient ideals**. When the sum is direct,
the pair (A | A) is a **pseudo-basis**. A pseudo-matrix is in **Hermite normal form** if
there exist indices 1 ≤ i₁ < i₂ < … < iₛ such that Aj,l = 0 for l < iⱼ, Aj,iⱼ = 1,
and Aj,l is reduced modulo AⱼAₗ⁻¹; all remaining rows are zero. This normal form is
unique given a suitable reduction, and every module is stored in Hermite normal form.
Note: αᵢ ∈ M if and only if 1 ∈ Aᵢ.

General (non-torsion-free) modules are represented as quotients M/S of a torsion-free
module M by a submodule S. Elements of M/S are represented as elements of M, and
arithmetic is reduced modulo the pseudo-basis of S.

The chapter also exposes the **pseudo-matrix** type (`PMat`) directly, with its own
construction, elementary, and operation functions — including the Hermite normal form
algorithm over Dedekind domains.

## 55.2 Creation of Modules

Modules over Dedekind domains can be created from orders of number fields and function
fields, from combinations of ideals and vector space elements, or as submodules and
quotient modules.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Module(O, n)` | Create the free module Oⁿ where O is a Dedekind domain. | — |
| `Module(O)` | Create a relative order O as a module over its coefficient ring. Also returns the map from the resulting module into O. | — |
| `Module(I)` | Create the ideal I of a relative order O as a module over the coefficient ring of the order. Also returns the map from the module into O. | — |
| `Module(S)` *(sequence of tuples)* | Create a module from a sequence of tuples of ideals and `ModElt`s with entries in the Dedekind domain or its field of fractions. The resulting module consists of sums of products of elements of an ideal with the corresponding `ModElt`. Also returns the map from the vector space into the module. | — |
| `Module(S)` *(sequence of ideals)* | Create the module equal to the direct sum of the ideals in the sequence S. | — |
| `Module(S)` *(sequence of ModElts)* | Create the module freely generated by the elements of S. Elements must be `ModElt`s with entries in a Dedekind domain or its field of fractions. Also returns the map from the vector space into the module. | — |
| `sub< M \| m >` / `sub< M \| m1, .., mn >` | Construct the submodule of M generated by the elements in the sequence or list m. Also returns the inclusion map of the submodule into M. | — |
| `quo< M \| S >` / `quo< M \| m >` / `quo< M \| m1, .., mn >` | Construct the quotient of M by the submodule S, or by the submodule generated by the elements in the sequence or list m. Also returns the inclusion map of the quotient module into M. | — |

*Worked examples: H55E1 (creation of free modules and modules from ideals over number fields and function fields); H55E2 (sub and quo constructors for submodules and quotient modules).*

## 55.3 Elementary Functions

Various simple properties of a module can be retrieved using the following functions.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `BaseRing(M)` / `CoefficientRing(M)` | The Dedekind domain which M is a module over. | — |
| `Degree(M)` | The dimension of the vector space M embeds into. | — |
| `Ngens(M)` / `NumberOfGenerators(M)` | The minimum number of vectors and ideals which generate M. | — |
| `M . i` | The vector of the i-th vector-and-ideal pair generating M. | — |
| `Determinant(M)` | The determinant of the module M. Requires the module to be square. | — |
| `Dimension(M)` | The dimension of the vector space spanned by M over its coefficient ring; equals the number of generators of a pseudo-basis of M. | — |
| `Contents(M)` | The contents of M: the gcd of the ideals obtained by multiplying the coefficient ideals by the ideal generated by the coefficients in the corresponding generators. Parameter `UseBasis` (`BoolElt`, default `false`): decides whether a pseudo-basis or pseudo-generators are used. | — |
| `Simplify(M)` | Computes a module of contents 1 by scaling each coefficient ideal by the inverse of the contents of M. Parameter `UseBasis` (`BoolElt`, default `false`): determines if operations are performed on pseudo-generators or the pseudo-basis. | — |
| `EmbeddingSpace(M)` | The canonical vector space containing M, i.e. M tensored with the field of fractions of the coefficient ring. | — |

*Worked examples: H55E3 (coefficient ring, determinant, degree, Ngens for modules over a function field, including a quotient module).*

| `M1 + M2` | The union (sum) of the modules M1 and M2. | — |

|-----------|-------------|-----------|

| `PseudoBasis(M)` | A sequence of tuples containing ideals and vectors which generate M. The vectors are guaranteed to be linearly independent (forming a true pseudo-basis). | Pseudo-basis / Hermite normal form over the Dedekind domain. |
| `PSeudoGenerators(M)` | A sequence of tuples containing ideals and vectors which generate M. Returns the data used to define the module; in contrast to `PseudoBasis`, the vectors will in general not be independent. | — |

Intersections of modules can be taken, and several structural functions are available.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `M1 meet M2` | Return the intersection of the modules M1 and M2. | — |
| `Dual(M)` | The module dual to M. | — |

The Aᵢ are unique if R ⊆ A₁ ⊆ … ⊆ Aₙ and are called elementary divisors (or elementary ideals) of M/N. | Corresponds to the Smith normal form for integral matrices (Smith normal form over Dedekind domains). |

## 55.8 Homomorphisms between Modules

It is possible to create homomorphisms between two modules, take their image and kernel,
verify submodule containment, and construct the Hom-module.

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `hom< M -> N \| T >` | Return a homomorphism from M into N as specified by T, from which images of generators can be inferred. T may be a map between the vector spaces, a matrix over the field of fractions, or a sequence of vectors. Parameter `ModuleBasis` (`BoolElt`, default `true`): if true, the matrix is interpreted as a transformation between modules (size Dimension(M) × Dimension(N)); otherwise as a transformation between vector spaces (size Degree(M) × Degree(N)). | — |
| `Hom(M, N)` | The module of homomorphisms from M to N (over the same Dedekind domain as M and N) and the map from the Hom-module to the collection of maps from M to N (so that given an element of the Hom-module, a homomorphism from M to N is returned). | — |
| `IsSubmodule(M, N)` | Return true if M is a submodule of N, and the map embedding M into N. | — |
| `Morphism(M, N)` | The map giving the morphism from M to N. If M is a submodule of N, returns the embedding of M into N; if N is a quotient module of M, returns the natural epimorphism from M onto N. | — |

*Worked examples: H55E6 (hom constructor with error cases, Image, Kernel, IsSubmodule, Hom and the resulting Hom-module over a function field).*

## 55.10 Pseudo Matrices

A pseudo-matrix (type `PMat`) is a sequence of ideals together with a matrix. Pseudo
matrices arise naturally in the computational theory of finitely generated torsion-free
modules over Dedekind domains, and can be thought of as a natural extension of ordinary
matrices (which are pseudo-matrices with all ideals generated by 1). A pseudo-matrix
represents the module generated by the rows of the matrix scaled by the corresponding
coefficient ideal: a linear combination of rows lies in the module if and only if the
coefficient of the i-th row belongs to the i-th ideal.

### 55.10.1 Construction of a Pseudo Matrix

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `PseudoMatrix(I, m)` | Construct the pseudo-matrix with coefficient ideals the elements of sequence I and matrix m. | — |
| `PseudoMatrix(m)` | Construct the pseudo-matrix with trivial coefficient ideals and matrix m. | — |
| `PseudoMatrix(M)` | Construct the pseudo-matrix described by the pseudo-basis of the module M. Parameter `Generators` (`BoolElt`, default `false`): if true, return the pseudo-matrix described by the pseudo-generators of M instead. | — |

### 55.10.2 Elementary Functions

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `CoefficientIdeals(P)` | Return the coefficient ideals of the pseudo-matrix P. | — |
| `Matrix(P)` | Return the matrix of the pseudo-matrix P. | — |
| `Order(pm)` | Return the order the pseudo-matrix pm is over. | — |
| `Dimension(pm)` | The dimension of pm: the number of columns of the matrix. | — |
| `Length(pm)` | The length (or number of rows) of pm: the number of coefficient ideals. | — |

### 55.10.3 Basis of a Pseudo Matrix

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Basis(P)` | Return a list of sequences of ring elements corresponding to the entries of each row of the matrix of the pseudo-matrix P. | — |

### 55.10.4 Predicates

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `p1 eq p2` | Return whether the pseudo-matrices p1 and p2 are equal: same matrix and same sequence of coefficient ideals. | — |

### 55.10.5 Operations with Pseudo Matrices

| Intrinsic | Description | Algorithm |
|-----------|-------------|-----------|
| `Transpose(P)` | Return the pseudo-matrix with the same coefficient ideals as P but with the transpose of P's matrix. Requires the matrix to be square. | — |
| `HermiteForm(X)` | Return the Hermite normal form H of the pseudo-matrix X, together with a regular transformation matrix T such that the module generated by X equals that generated by H and (for matrix parts) H = TX. | Hermite normal form algorithm over Dedekind domains. |
| `VerticalJoin(X, Y)` | Return the pseudo-matrix whose matrix is the vertical join of the matrices of X and Y, with coefficient ideals the concatenation of those of X and Y. | — |
| `X meet Y` | Return the intersection of the pseudo-matrices X and Y. | — |
| `Module(X)` | Return the module ∑ Cᵢ · mᵢ where Cᵢ are the coefficient ideals and mᵢ are the rows of the matrix of X. | — |
| `I * X` / `X * I` | The pseudo-matrix whose coefficient ideals are those of X multiplied by I and whose matrix is the matrix of X. | — |
